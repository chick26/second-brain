# 一、研究背景

> 大型语言模型在提示生成逐步推理以证明其最终答案时，表现出改善的下游任务性能。这些推理步骤极大地提高了模型的可解释性和可验证性，但在没有可靠的自动评估方法的情况下，客观地研究它们的正确性（与最终答案无关）是困难的。

# 二、 研究方法

> 作者们提出了ROSCOE，这是一套可解释的、无需参考答案的自动评分工具，改进并扩展了先前的文本生成评估指标。与现有的指标相比，ROSCOE可以通过利用逐步解释的属性来测量语义一致性、逻辑性、信息性、流畅性和事实性等特征。ROSCOE将细粒度指标体现在四个方面：
> * 语义对齐定义生成的推理在多大程度上是一致的，并与源上下文相关联；（ROSCOE-SA）
> * 逻辑推理评估生成的推理步骤是否在自身内部一致，并检查逻辑谬误；(ROSCOE-LI)
> * 语义相似性量化生成的推理与上下文或中间步骤之间的相似程度，以捕捉幻觉或重复；(ROSCOE-SS)
> * 语言连贯性评估整个链条是否自然流畅。(ROSCOE-LC)
> **过程细节**：为了评估ROSCOE与现有指标的差异，研究者们首先对推理错误进行了总结，且将本身测评维度分成四个方向，每个方向都给出相应的数值计算方法。以下是该方法的详细介绍：
> * **推理错误分类设计**：设计了一个系统化的推理错误分类法，用于区分多步生成任务中可能发生的推理错误。这包括语义不一致、逻辑谬误、语义相似度差异和语言不连贯等多个方面。通过明确定义各种推理错误，研究者们为后续的评估提供了清晰的标准。
> * **构造数据集**：利用推理错误分类法，研究者们创建了合成数据集，其中包含了各种类型的推理错误。这样的合成数据集有助于系统性地评估ROSCOE在不同推理错误情境下的表现，同时确保了在控制条件下进行评估。
> * **人工评估**：使用设计的推理错误分类法和合成数据集，研究者们进行了人工评估。参与评估的人员根据推理错误的类型对生成的结果进行分类和标注，以提供详细的人工评估数据。
> * **ROSCOE的细粒度评估**：研究者们采用上述设计的分类法和人工评估的数据，对ROSCOE进行了全面的评估。这些指标从四个角度（语义对齐（ROSCOE-SA）、逻辑推理（ROSCOE-LI）、语义相似度（ROSCOE-SS）和语言连贯性（ROSCOE-SS）细致地检查ROSCOE在多个方面的性能表现。
> * **性能提升验证**：在上述四个角度下，研究者们发现ROSCOE相对于基准评估指标在需要对上下文进行推理的所有任务上都表现出性能提升。这表明ROSCOE在细粒度的推理任务上具有更好的适应性和准确性。
> * **额外的敏感性分析**：针对需要逻辑和算术推理的任务，研究者们进行了额外的敏感性分析，揭示了ROSCOE在这些任务中相对于其他指标更为稳健的特性。这强调了ROSCOE在处理具有逻辑和算术复杂性的推理任务时的优越性。

# 三、实验结果

可以看出ROSСOE在六个不同的诊断数据集上在所有参考无关的度量标准上都表现出色，表现优于其他参考无关的方法。在每个数据集中，ROSСOE都取得了最高的相关性分数，显示其在评估生成的推理步骤方面的卓越性能。ROSСOE专注于参考无关的设置，能够在没有参考文本的情况下，对每个生成的步骤进行评估。相比之下，基线度量标准的相关性较低，因为它们旨在捕捉参考文本和假设之间的语义或词汇重叠，而在没有参考文本的情况下，逻辑一致性更难以检测。在人类评估数据集上，ROSСOE指标在无参考答案的情况下表现出色，与其他基线相比，它产生更高的相关性。这表明ROSСOE在评估模型逐步推理生成时，能够提供更为有效的信息，与人类判断的相关性明显更好。

# 四、实验结论

> 在这篇论文中，作者介绍了ROSCOE，这是一套新的可解释的无需参考答案的度量标准，使得在没有参考答案生成的情况下能够评估语言模型的逐步推理生成，并提出了一个用于生成和评估度量标准的推理错误分类法。实验结果来自于对合成数据和人工标注数据集的评估，这些数据集展示了多种类型的推理（常识、算术、逻辑推理等），结果表明相较于先前基于语义和词汇相似性的基线度量标准，ROSCOE表现出卓越的性能。
