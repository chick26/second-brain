# 1. 问题背景

很多人做多数据源混训时，都会遇到同一个问题：

> 已知 `a` 是辅助数据，`b` 也是辅助数据，`c` 是目标任务数据。单独实验发现：
> $a:c = 1:2$ 时效果最好，同时也发现 $b:c = 1:2$ 时效果最好。
> 那三者一起训时，到底应该设成
> $a:b:c = 1:1:2$ 还是 $a:b:c = 1:1:4$ ？

表面上看，`1:1:2` 好像“同时满足”了 `a:c=1:2` 和 `b:c=1:2`。但更深一点看，这个推理其实默认了一个很强的假设：**a 和 b 对 c 的帮助是线性可加、互不冲突的**。研究界这几年对多任务优化、梯度冲突、数据混合优化的结果，基本都在提醒你：这个假设通常并不成立

> Multi-Task Learning as Multi-Objective Optimization：https://arxiv.org/abs/1810.04650

# 2. 到底在调什么

混训里最容易混淆的是两个东西：

1. **sampling ratio**
   也就是 `a:b:c` 这种采样比例，控制的是模型 **“看见多少次哪类数据”**
2. **loss weight**
   也就是不同数据源或不同任务的 loss 系数，控制的是模型 **“看见以后谁的影响更大”**

把它写成统一形式就是：

$\mathcal{L}(\theta)=\sum_{i=1}^k q_i, w_i, \mathbb{E}_{x\sim D_i}[\ell_i(x;\theta)]$

其中 `q_i` 是采样概率，`w_i` 是 loss 权重

这两个量在理想化的全梯度下降里可以通过乘积 `q_i w_i` 互相替代，但在真实 SGD 训练里不完全等价，因为 `q_i` 还会改变 mini batch 组成和梯度方差。2024 年关于 “Upsample or Upweight?” 的[**工作**](https://arxiv.org/abs/2410.04579)给出了更直接的结论：**在 full gradient descent 下，重采样和重加权等价；在 stochastic gradient descent 下，这个等价性会破裂**。而且 upsampling 往往收敛更快，但也更容易过拟合低资源域

所以，讨论 `1:1:2` 还是 `1:1:4`，本质上首先是在讨论 **sampling ratio**，不是在讨论 loss weight

# 3. 为什么 pairwise 最优比例不能直接外推到混训

## 3.1 多任务本质上不是一个简单的“加权和”问题

[Sener 和 Koltun 那篇很经典的工作](https://arxiv.org/abs/1810.04650)，直接把多任务学习建模成 **multi objective optimization**，目标不是拍脑袋选一个加权和，而是去找 Pareto optimal solution。这个视角的核心意思是：当多个任务之间有冲突时，并不存在一个天然正确的固定线性组合

这件事放到这个问题里，就是：已知 `a+c` 的最优点在 `1:2`，`b+c` 的最优点也在 `1:2`，只能说明这两个 **二元问题** 各自的 Pareto tradeoff 在那个位置附近比较好。它不意味着三元问题的最优点还满足一种简单的“守恒关系”。换句话说，二元最优是二元系统的结论，不是三元系统的公理

## 3.2 辅助数据可能互补，也可能互相打架

[PCGrad](https://arxiv.org/abs/2001.06782) 把多任务训练困难的一个核心原因明确成了 **gradient interference**。论文中指出，当任务梯度互相冲突时，会出现明显的负迁移，甚至让联合训练不如单独训练。PCGrad 的做法本身就是在检测到负余弦相似度时，对梯度做投影处理

这意味着：`a` 单独加入 `c` 有帮助，`b` 单独加入 `c` 也有帮助，不代表 `a` 和 `b` 一起加入时帮助会简单相加。它们可能分别都对 `c` 有正作用，但在共享参数上却互相竞争。所以，“`a:c=1:2` 且 `b:c=1:2`，于是 `a:b:c=1:1:2`” 这个推理，默认了 `a` 与 `b` 没有明显冲突，这个默认在研究和经验上都不稳

# 4. 数据 mixture 本身就是一个要单独优化的对象

语言模型训练里，这几年最有价值的一条线索不是 **“找一个万能固定比例”**，而是承认 **data mixture is a first class optimization object**

## 4.1 DoReMi：数据配比可以显著影响性能和训练效率

[**DoReMi**](https://arxiv.org/abs/2305.10429)的结论很直接：预训练数据域的 mixture proportions 会显著影响模型表现。它通过一个小代理模型学习更优的 domain weights，再拿这个 mixture 去训练大模型。在 The Pile 上，DoReMi 相比默认配比提升了平均 few shot 准确率，并且用更少训练步数达到基线效果

这个结果说明，**最优配比不是“数据收集完顺手一拼”出来的，而是值得专门调的超参**

## 4.2 Data Mixing Laws：可以用小规模实验预测更大规模下的优配比

[**Data Mixing Laws**](https://arxiv.org/abs/2403.16952) 更进一步，它认为 mixture 与模型性能之间存在可建模的函数关系。作者展示了可以通过少量样本 mixture 的实验去拟合这种关系，从而预测未实际训练过的 mixture 的表现，甚至还能估计 continual training 里避免 catastrophic forgetting 的临界比例

这条结果特别重要，因为它暗示：**pairwise 最优比例更适合作为先验，而不是作为可直接相加的硬约束**

## 4.3 DynamixSFT：静态比例不一定够，动态 mixture 往往还能继续涨点

[**DynamixSFT**](https://arxiv.org/abs/2508.12116) 把这个思路带到了 instruction tuning。它把每个数据集视作 bandit arm，训练过程中动态更新采样概率，相比原始静态 mixture 在多个 benchmark 上拿到了额外收益。这个结果还比较新，证据等级不如前面几篇经典工作稳定，但方向很清楚：**固定比例只是起点，不是终点**

# 5. 更正式的推导原则

## 原则一：先定义主目标，只围绕目标集 `c` 决策

如果 `c` 是目标任务，那么一切 mixture 的选择都应该围绕 `c` 的 dev/test 指标来定，而不是看总 loss，也不是看辅助任务平均提升。多任务学习里本来就存在 **Pareto tradeoff**，所以不先固定主目标，后面所有配比都可能跑偏

## 原则二：把 pairwise 最优比例解释为“单个辅助源的有效强度”

如果单独实验得到：

$a:c = r_a:1,\qquad b:c = r_b:1$

那更合理的解释不是三元时照搬，而是：

当只有一个辅助源时，`a` 的有效辅助强度约为 `r_a`，`b` 的有效辅助强度约为 `r_b`。

上面的例子中：

$r_a=r_b=\frac{1}{2}$

这说明 `a` 和 `b` 单独加入时，最舒适的强度等级都大概是 `0.5c`

## 原则三：三元初始化时，默认保持“总辅助强度”稳定，而不是直接求和

更稳妥的默认策略是：

1. 先估计总辅助预算 `R_{\text{total}}`
2. 再在多个辅助源之间分配这个预算

一个保守但很实用的初始化是：

$R_{\text{total}} \approx \mathrm{median}(r_1,r_2,\ldots,r_m)$

然后按各自 pairwise 强度占比分配辅助预算：$q_i \propto r_i$

如果 `r_a=r_b=0.5`，那就得到：

1. 总辅助预算仍取 `0.5c`
2. `a` 和 `b` 平分这部分预算

于是有：

$a:b:c = 1:1:4$

这个比例的关键不是看起来整齐，而是它保持了：

$(a+b):c = 2:4 = 1:2$

也就是总辅助强度没有因为辅助源数量增加而突然翻倍

## 原则四：只有在确认“强互补、弱冲突”时，才考虑往 `1:1:2` 推

什么时候可以从 `1:1:4` 往 `1:1:2` 这种更激进的比例走？

至少要满足下面两类证据之一：

1. **梯度证据**
   `a` 与 `b` 在共享参数上的梯度余弦大多数为正，明显负冲突较少。PCGrad 这类工作说明，负余弦往往对应训练中的竞争
2. **性能证据**
   小规模 pilot 中，`a+b+c` 相比 `a+c`、`b+c` 的收益接近可加，而且 `c` 指标没有被稀释

如果这两类证据都没有，那默认直接上 `1:1:2` 是偏激进的

# 6. 什么时候看 loss weight，什么时候看 sampling ratio

## 6.1 优先看 sampling ratio 的场景

如果 `a、b、c` 是三份独立数据池，尤其是在预训练、continued pretraining、SFT 数据混训里，最该先调的是 sampling ratio。因为这时真正控制的是：

1. 模型暴露给各分布的频次
2. 各数据域对表示学习的覆盖程度
3. 目标域是否被辅助域稀释
4. 是否发生遗忘或过拟合

DoReMi、Data Mixing Laws、DynamixSFT 讨论的，基本都属于这一层

## 6.2 优先看 loss weight 的场景

如果是 **同一批样本** 上同时产生多个 loss，比如一个模型同时做分类、回归、对比学习，或者一个样本同时有主任务 loss 和若干正则项，那此时首先要调的是 loss weight，而不是采样比例

[**GradNorm**](https://arxiv.org/abs/1711.02257) 的结论是，可以通过动态平衡各任务梯度范数来自动调节训练速度和权重；Kendall 等人的 **[uncertainty weighting](https://arxiv.org/abs/2410.04579)** 则说明，不同量纲、不同噪声水平的任务，可以用 learned uncertainty 来做更有原则的 loss weighting

所以一句话概括：**不同数据池，先看 sampling ratio，同一数据样本上的多种目标，先看 loss weight**

# 7. 直接结论

现在回到原问题。已知：

$a:c = 1:2,\qquad b:c = 1:2$

那么更合理的解释是：

`a` 和 `b` 各自单独作为辅助源时，最优辅助强度都约等于 `0.5c`

在没有更多证据说明 `a` 与 `b` 高度互补且几乎不冲突的情况下，默认更稳的三元初始化应当是：

$a:b:c = 1:1:4$

而不是：$a:b:c = 1:1:2$

因为 `1:1:2` 等价于把两个辅助源都按原来的单源强度完整叠加，导致总辅助量从 `0.5c` 直接变成 `1.0c`。这会显著增加目标集 `c` 被稀释的风险，也更容易放大辅助源之间的梯度冲突

# 8. 可执行的实验模板

如果不想只停留在直觉上更合理，那就直接做一个小 sweep：

$1:1:6,\quad 1:1:4,\quad 1:1:3,\quad 1:1:2$

建议观察四类指标：

1. `c` 的主指标：这是唯一真正决定配比对不对的核心指标
2. 训练早期收敛速度：有些更激进的比例会前期涨得更快，但后期掉头
3. 泛化和过拟合迹象：尤其注意辅助域过多时，`c` 的验证集是否先升后掉
4. 梯度冲突统计：如果你能记录共享参数上的梯度余弦分布，会非常有用

如果 `1:1:2` 真的比 `1:1:4` 好，那你应该能观察到一个很清楚的现象：`c` 指标持续更优，而且没有明显更强的训练震荡或过拟合。否则，就不要因为逻辑上同时满足两个 pairwise 约束而被它骗过去

# 9. 总结

多数据源混训里，最容易犯的错误不是不会调参，而是把 **pairwise optimal 当成了 compositional law**

但现实是：

1. 多任务本质上是多目标优化，不是简单线性相加
2. 辅助源之间可能互补，也可能互相冲突
3. 数据 mixture 本身就是要单独优化的对象
4. sampling ratio 和 loss weight 只在理想条件下才近似等价

所以，面对 `a:c=1:2`，`b:c=1:2`，那 `a:b:c` 该怎么设 这个问题时，更稳、更符合研究共识的是 **先把 `1:1:4` 当作默认起点，再用小规模 sweep 去验证**
