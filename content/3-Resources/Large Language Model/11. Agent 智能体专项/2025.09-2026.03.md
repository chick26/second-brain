* **AgentRL: Scaling Agentic Reinforcement Learning with a Multi-Turn, Multi-Task Framework**
  **一句话总结**：做的是可扩展的 multi-turn、multi-task agentic RL 框架，重点在异步 rollout-training pipeline、统一 function-call API 和多任务稳定训练。
  **所需资源**：32B 模型训练 1500 steps，约 **32 张 GPU、101 小时、3232 GPU-hours**；按复现经验通常至少需要 **32×A100-80G 或 32×H100-80G** 这一量级。
* **ProRL Agent: Rollout-as-a-Service for RL Training of Multi-Turn LLM Agents**
  **一句话总结**：**4B 约 8×H100 跑 1–2 天（200–400 GPU-hours）**，**8B 约 8–16×H100 跑 2–3 天（400–1000 GPU-hours）**，**14B 约 16×H100 跑 2–4 天（800–1500 GPU-hours）**；另需独立 rollout 服务机。
* **ASTRA: Automated Synthesis of agentic Trajectories and Reinforcement Arenas**
  **一句话总结**：把 agent 训练做成“轨迹自动合成 + 可验证环境自动合成 + SFT + online RL”的闭环。
  **所需资源**：按 7B–32B 级 tool-agent 复现估算：**若做 7B/8B 版，约 8–16×H100、2–4 天（400–1500 GPU-hours）**；**若做 32B 版，约 32×H100、2–4 天（1500–5000 GPU-hours）**。环境生成和代码验证主要吃 CPU/容器资源，不全算在 GPU 里。
* **AutoForge: Automated Environment Synthesis for Agentic Reinforcement Learning**
  **一句话总结**：先自动造高难度、易验证环境，再做 environment-level RL，核心是提升 agentic RL 的环境供给和训练稳定性。
  **所需资源**：**环境合成阶段约 500–2000 GPU-hours**，**RL 阶段若是 7B/8B backbone 约 8–16×H100 跑 2–4 天（400–1500 GPU-hours）**；如果换到 32B，整体大致上浮到 **2000–6000 GPU-hours**。
* **Agent World Model: Infinity Synthetic Environments for Agentic RL**
  **一句话总结**：**环境构建/数据生成约 2000–8000 GPU-hours**，**RL 训练约 32×H100 跑 2–5 天（1500–4000 GPU-hours）**。
* **Reasoning and Tool-use Compete in Agentic RL: From Quantifying Interference to Disentangled Tuning**
  **一句话总结**：证明 reasoning 和 tool-use 联合训练会相互干扰，并提出 DART 用分离 LoRA 来解耦更新。
  **所需资源**：**7B/8B 约 4–8×H100、0.5–2 天（50–300 GPU-hours）**；**32B 约 8–16×H100、1–2 天（150–700 GPU-hours）**。
* **DeepAgent: A General Reasoning Agent with Scalable Toolsets**
  **一句话总结**：以 **QwQ-32B** 为 backbone，做 autonomous thinking、tool discovery、memory folding 和 end-to-end ToolPO。
  **所需资源**：**训练本体约 32–64×H100、2–4 天（2000–6000 GPU-hours）**；如果把工具模拟器和辅助模型在线接入一起算，完整实验常常接近 **4000–8000 GPU-hours**。
* **DeepResearch-9K / DeepResearch-R1: A Challenging Benchmark Dataset of Deep-Research Agent**
  **一句话总结**：构建 **9000 个 deep research 问题**，带搜索轨迹、reasoning chains 和可验证答案，并配套多轮 web 交互训练框架。
  **所需资源**：**数据采集约 1000–4000 GPU-hours**，**8B student 训练约 300–1000 GPU-hours**，**30B 级 student 则约 1500–4000 GPU-hours**。完整复现预算可按 **1500–7000 GPU-hours** 预留。
* **O-Researcher: An Open Ended Deep Research Model via Multi-Agent Distillation and Agentic RL**
  **一句话总结**：先做多 agent 蒸馏生成 deep research 轨迹，再接两阶段训练，把 SFT 和 RL 串起来。
  **所需资源**：**SFT 至少 32–64×H100、1–2 天（1000–3000 GPU-hours）**，**后续 RL 约 64×H100、2–4 天（3000–7000 GPU-hours）**；全流程大致 **5000–12000 GPU-hours**。
* **SynPlanResearch-R1: Encouraging Tool Exploration for Deep Research with Synthetic Plans**
  **一句话总结**：先用 synthetic plans 做 cold-start SFT，再做 RL，重点解决 deep research agent 的工具探索不足。
  **所需资源**：**4B 版约 4–8×H100、1–2 天（80–250 GPU-hours）**；**8B 版约 8×H100、1–3 天（150–500 GPU-hours）**。如果把 plan-guided 轨迹生成也算上，完整预算约 **300–800 GPU-hours**。
* **Search More, Think Less: Rethinking Long-Horizon Agentic Search for Efficiency and Generalization**
  **一句话总结**：用并行证据获取替代顺序深推理，兼顾长链搜索效率和跨任务泛化。
  **所需资源**：**SFT 100–400 GPU-hours**，**RL 约 8–16×H100、2–4 天（500–1500 GPU-hours）**；总预算约 **700–2000 GPU-hours**。
* **MM-DeepResearch: A Simple and Effective Multimodal Agentic Search Baseline**
  **一句话总结**：把 deep research 扩到多模态场景，核心是 Hyper-Search、DR-TTS 和 offline search engine。
  **所需资源**：**8–16×H100、2–4 天（500–1800 GPU-hours）**；若 backbone 上到 32B，通常会到 **2000–5000 GPU-hours**。
* **DeepResearcher: Scaling Deep Research via Reinforcement Learning in Real-world Environments**
  **一句话总结**：在真实 web 环境中做 end-to-end RL，而不是只在静态 RAG 环境里训 deep research agent。
  **所需资源**：**训练本体约 8–16×H100、2–5 天（800–2500 GPU-hours）**；如果把网页访问、解析、缓存、失败重试都算进整体开销，完整复现通常应预留 **1000–3000 GPU-hours**。
* **TOUCAN: Synthesizing 1.5M Tool-Agentic Data from Real-World MCP Environments**
  **一句话总结**：从近 **500 个真实 MCP 环境、2000+ 工具** 中合成 **150 万条** tool-agentic 轨迹。
  **所需资源**：**仅数据合成就可能需要 8000–30000 GPU-hours**；若再做后续 7B/8B SFT，还需额外 **100–500 GPU-hours**。
* **Unlocking Implicit Experience: Synthesizing Tool-Use Trajectories from Text**
  **一句话总结**：从普通文本语料中抽取并生成多轮 tool-use 轨迹，再训练一个专门的 trajectory synthesizer 降低生成成本。
  **所需资源**：**数据构建约 1000–4000 GPU-hours**，**32B SFT 约 500–1500 GPU-hours**；总预算大致 **1500–5000 GPU-hours**。
* **LOGIGEN: Logic-Driven Generation of Verifiable Agentic Tasks**
  **一句话总结**：用逻辑驱动和三智能体协作生成 **2 万个** 严格可验证的 agentic tasks，再做 SFT + RL。
  **所需资源**：按 32B 模型的 verifiable SFT + RL 估算：**SFT 约 300–1000 GPU-hours**，**RL 约 1000–3000 GPU-hours**；总预算可按 **1500–4000 GPU-hours** 预留。
* **KARL: Knowledge Agents via Reinforcement Learning**
  **一句话总结**：面向 enterprise search agent，结合 agentic 数据合成、iterative large-batch off-policy RL 和多任务训练。
  **所需资源**：论文虽然没写具体 backbone 参数量，但它明确强调 **iterative large-batch off-policy RL**、multi-task 训练和 bootstrapped synthesis。按企业搜索 agent 的工业级复现估算：**至少 16–64×H100、3–7 天（1500–10000 GPU-hours）**；如果把多轮 bootstrapping 的合成数据一并算上，整体更接近 **3000–12000 GPU-hours**。
* **Multi-Agent Deep Research: Training Multi-Agent Systems with M-GRPO**
  **一句话总结**：把 GRPO 扩展到主 agent + 子 agent 的层级多智能体 deep research 训练。
  **所需资源**：**合计约 24–64×H100、2–5 天（2000–8000 GPU-hours）**。如果其中主 agent 升到 32B，预算通常会上探到 **5000–12000 GPU-hours**。
* **MARS: Co-evolving Dual-System Deep Research via Multi-Agent Reinforcement Learning**
  **一句话总结**：**16–32×H100、2–4 天（800–3000 GPU-hours）**；如果慢系统用到 32B 级 reasoning model，完整预算更合理的区间是 **2500–7000 GPU-hours**。
