# 金融投研 Agent 工作流

> [!warning] 证据状态
> 当前 Cubox 源文是小红书视频卡片，正文极薄，未做 ASR。这里只保留“用户希望沉淀”的工作流占位，不构成投资建议。

## 可沉淀的工作流骨架

1. 明确研究对象：股票、基金、行业、宏观主题或财报事件。
2. 拉取基础数据：行情、财务指标、公告、研报、新闻和宏观变量。
3. 建立假设：增长、估值、风险、催化剂、反身性因素。
4. 分层验证：先用官方公告和财报，再看市场数据和二级资料。
5. 输出结构化结论：观点、证据、反证、风险、需要继续跟踪的数据。
6. 保留可追溯来源：每个结论都要能回到数据或原文。

## Agent 边界

- Agent 可以做资料收集、表格整理、假设对比和风险清单。
- 不应自动生成买卖建议。
- 涉及投资判断时，必须标注来源、日期和不确定性。
