# AI Agent 可用工具清单

这份清单只记录“可能值得以后试用或研究”的工具线索，不代表已经完成验证。每个条目都应保留用途、适用场景和下一步。

| 工具 / 项目 | 适用场景 | 当前判断 | 下一步 |
|---|---|---|---|
| Scientific Paper Writing Skill | 长文、综述、科研写作；包含调研、找文献、搭框架、草稿迭代、模拟评审 | 值得作为长流程写作 skill 案例观察 | 真正需要科研/长文工作流时再回源验证 |
| OpeniLink Hub | 微信 Bot 管理、消息入口、App 应用市场、Webhook/WebSocket/AI 自动回复 | 可作为个人 Agent Gateway 或消息入口候选 | 若要做微信入口，再评估部署、安全和 iLink 风险 |
| Knowhere | 文档解析后进一步变成 Agent 可导航、可引用、可推理的长期知识 | 适合补充“PDF/文档 -> Agent memory”的工具链认知 | 和 MinerU / 现有文档解析流程对比 |
| Conversational TTS / AudioLLM | 语音交互、TTS、实时数字人或本地语音助手 | 线索较薄，仅保留为后续语音交互候选 | 需要语音入口时再找项目地址和技术细节 |

## 维护规则

- 只保留有明确场景的工具，不把“看起来酷”的项目都放进来。
- 每个工具至少要有一个可执行的下一步，否则归档即可。
- 涉及账号、消息入口、API key 或私有数据的工具，先评估安全边界再试用。
