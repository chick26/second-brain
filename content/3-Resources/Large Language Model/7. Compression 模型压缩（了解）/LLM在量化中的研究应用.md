# QuantaAlpha: An Evolutionary Framework for LLM-Driven Alpha Mining

![LLM在量化中的研究应用-image.png](https://2479e837.cloudflare-imgbed-2q4.pages.dev/file/1782715259707_img-8344380b9725786cfd58.png)

## 动机

QuantaAlpha 的总体目标就是：在市场 **非平稳** 与 **低信噪比** 常态下，把“多轮自动化因子挖掘”做成一种 **可演化、可继承、可约束** 的搜索过程。

* **可控性脆弱**：多轮迭代强依赖噪声很大的回测反馈，容易把更新“带偏”，出现语义漂移，最后因子越来越像在追逐偶然相关。
* **可信性不足**：很多方法每一轮更像“随机再生成”，缺少把已验证的推理与有效步骤显式继承下来的机制，所以难审计、难复现、难信任。
* **探索受限**：搜索常围绕初始 seed 的局部邻域过度 exploit，导致factor crowding，覆盖不了更广的假设空间。

![LLM在量化中的研究应用-image-3.png](https://2479e837.cloudflare-imgbed-2q4.pages.dev/file/1782715242081_img-675275d0dd785e5df25d.png)

## 核心方法

把一次 alpha 挖掘当成一条研究轨迹，用 **轨迹级 mutation + crossover** 替代噪声驱动的反复重生成；同时用符号化中间表示与一致性/复杂度/冗余约束，保证迭代既能探索又不漂移，从而在非平稳市场里得到更稳、更可复用、且可审计的因子发现流程。

![LLM在量化中的研究应用-image-2.png](https://2479e837.cloudflare-imgbed-2q4.pages.dev/file/1782715217116_img-d2815b5631617c9785d2.png)

### 2.1 多样化初始化：先把搜索空间铺开

系统先用初始化 agent 生成一组互补的初始假设，显式要求在 **信号来源**（价/量等）、**时间尺度**、**机制类型**（动量/均值回复/条件触发）上尽量互补，避免一开始就挤在同一类模式里。

### 2.2 可控的因子生成：符号表达式 + AST 作为中间层

团队认为 直接让 LLM 产出因子代码 效果差：会有语法错、依赖错、更会出现 **代码与假设不一致** 的语义漂移。

因此引入：

* 基于标准化 **算子库 O** 的 **符号表达式 f**，并解析为 **AST（抽象语法树）**，把高层市场意图与底层实现绑定起来，做到结构可验证、可编译。
* 流程上：假设 *h* → 结构化语义描述 *d* → 组装符号表达式 *f* 并转 AST → 编译成代码 *c*；若编译失败，再触发“修复”但要求保持 *f* 的语义锚定，而不是自由发挥重写。

### 2.3 一票否决式一致性校验

系统用 `LLM verifier `做两类一致性检查：

1. 假设 *h*、语义描述 *d*、符号表达式 *f* 是否一致；
2. 符号定义 *f* 与实现代码 *c* 是否一致；
   不通过就定点重写不一致部分，直到通过或触发重试上限。

### 2.4 复杂度 & 冗余控制

为抑制过拟合与因子拥挤，论文加了两把结构化约束：

* **复杂度正则**：用符号长度、自由参数数量、使用的原始特征数等组成复杂度打分 $C(f)$。
* **冗余过滤**：用 AST 最大公共同构子树来度量结构相似度，若与已有 alpha zoo 太像就拒绝并重写。

### 2.5 轨迹级进化：Mutation + Crossover

每轮迭代维护轨迹池 $T_i$，并把“更优的轨迹”当作示范，给后续轨迹生成施加一种imitation learning priors，让系统不是每轮从零乱试。

两种进化算子：

* **Mutation**：先自我反思定位导致低回报的关键决策节点 *k*，只对该局部动作/片段做“定点改写”，其余前缀冻结，保证轨迹连贯；改写对象可以是假设、符号表达式或代码实现，甚至引入机制层变化。
* **Crossover**：从高质量父轨迹中识别 稳定贡献高回报 的片段（假设模板、构造模式、修复策略等），将多个父轨迹的强项拼成一条更一致的新轨迹，从而 **显式继承** 已验证决策，强化可追溯性与可信度。

## 实验结论

![LLM在量化中的研究应用-image-1.png](https://2479e837.cloudflare-imgbed-2q4.pages.dev/file/1782715201514_img-1312942e272a62c71fad.png)

### 3.1 主结果：CSI300 上全面胜出

论文在 CSI 300 上做四年评估，并报告因子预测力与策略层指标（IC、Rank IC、ARR、MDD 等）。
主结论是 QuantaAlpha 同时提升预测力与策略表现：在 **GPT-5.2** 作为底座时达到 **IC=0.1501、ARR=27.75%、MDD=7.98%**，作者强调这更像可落生产风控约束的表现，而不是回测噪声幻觉。

此外，相比 RD-Agent，作者把提升归因于 中间表示 + 校验 降低语义漂移、提高实现可靠性；相比 AlphaAgent，则进一步来自轨迹级自进化带来的探索/继承增益。

### 3.2 从 CSI300 零样本搬到 CSI500 / S\&P500

论文做了 **zero-shot transfer**：在 CSI300 挖到并筛选的因子，不做再优化，直接部署到 CSI500 和 S\&P500。结果在评估末期达到 **CSI500 累计超额≈160%**、**S\&P500 超额>137%**，显示对分布漂移更稳。

### 3.3 消融

* 去掉 **Planning**：IC 变化不大，但 **ARR 下降 7.78%、MDD 上升 2.73%**，说明多样化起点主要提升搜索前沿与后续稳定性。
* 去掉 **Mutation**：预测力与收益下降最大（IC、Rank IC、ARR 都显著掉），表明它是主要的探索与修复。
* 去掉 **Crossover**：下降较小但稳定，支持其继承与重组有效片段的作用。
* 去掉 **一致性/复杂度/冗余控制** 任一项都会持续变差；其中复杂度控制对策略层冲击最明显（ARR 大幅下滑、MDD 上升）。
