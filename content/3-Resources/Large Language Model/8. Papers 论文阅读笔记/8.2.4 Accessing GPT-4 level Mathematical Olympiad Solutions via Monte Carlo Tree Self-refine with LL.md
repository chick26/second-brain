# MCTSr：蒙特卡洛树自优化算法增强大模型推理

> 来自复旦大学和上海AIlab的研究人员提出了结合 **蒙特卡洛树搜索（MCTS）和自优化（Self-refine）** 的 MCT自优化（MCTSr）算法，旨在提升 LLMs 在 **复杂数学推理任务**（如数学奥林匹克竞赛问题）中的性能，增强 **决策准确性和可靠性**
> **论文链接: https://arxiv.org/pdf/2406.07394**

# 一、研究背景

> **研究背景：**
> * 大模型在策略、逻辑推理方面存在 **准确性与可靠性问题**，尤其在 **数学推理任务中易产生错误或幻觉输出**。这些输出虽然表面上看似合理，但不相关或事实上不正确，最终对理性过程有害
> * **Self-Refine** 这样的改写技术有助于缓解上述问题，但这种倾向在现实世界的复杂数学问题中 **仍可能导致误导性或错误的结果**

# 二、研究方法

> **方法概述：**
> MCTS作为一种决策工具，通常用于游戏和复杂问题解决环境。本文提出了MCT自优化（MCT Self-Refine,MCTSr）算法，将 **MCTS的系统探索能力与大语言模型的Self-refine和Self-evaluation能力相结合** 来增强LLM的reasoning能力

> **Monte Carlo Tree Search 蒙特卡洛树搜索：**
> MCTS是一种 **启发式搜索算法**，广泛应用于游戏及复杂决策过程，通过构建搜索树并模拟结果来估算action的价值。主要包含四个阶段：**Selection、Expansion、Simulation和Backpropagation**
> * **Selection：** 从根节点开始，**依据特定策略（例如UCT）选择子节点**，持续这一过程直至抵达叶节点
> * **Expansion：** 在选定的叶子节点上扩展，添加一个或多个新的子节点。如果 **叶子节点不是游戏结束状态（即没有明确的胜负结果），则创建一个或多个新的子节点**，每个子节点选择代表一个可能的action
> * **Simulation：** 从扩展的节点开始，进行随机模拟（也称为playout或rollout），**通过随机选择action，直到游戏达到终止状态（如胜利、失败或平局）**，结果（如胜利或失败）用于评估节点的价值。
> * **Backpropagation：** 将模拟的结果从叶子节点反向传播回根节点，更新路径上所有节点的统计信息。**根据模拟的结果，更新路径上每个节点的胜利次数和访问次数**
> **Upper Confidence Bound applied on Trees（UCT）** 对于 MCTS 的Selection阶段至关重要，通过选择最大化下式的action来 **平衡探索exploration和利用exploitation：**
> $UCT_{j}=\overline{X}_{j}+C \sqrt{\frac{2 \ln N_{C}}{N_{j}}}$
> $\overline{X}_j$ 代表节点 $j$ 的平均奖励或价值，**当决策过程有明确的win/loss的时候，例如围棋，可以表示为 $\overline{X}_j=\frac{W_j}{N_j}$，其中 $w_j,n_j$ 分别表示包含当前节点path的获胜次数以及当前节点的总共访问次数，** 这些统计量是需要在Backpropagation阶段更新的（win/loss可以看成0-1reward，所以也是平均奖励）。$N_C$ 代表当前节点的父节点的访问次数，$C$ 是一个系数平衡探索和利用。**可以看出上式，第一项为exploitation，节点的平均价值越高，越鼓励利用这个节点；第二项为exploration，节点的访问次数越小，该项越大，鼓励探索其他节点**

> **Self-refine 自优化：**
> 给定LLM一个Input，先得到初始的Output，然后再将Output给LLM自身，**提示他自己给出修改意见或者反馈Feedback，然后再根据Output、Feedback自己给出Refine方案和修改后的Output**，一直进行迭代直到达到最大迭代次数或者没有改进为止，最后得到经过多轮Refine后的最终的Output

**Self-refine示例**

> **MCT Self-Refine：**
> 本文将数学问题 **解决方案的迭代过程抽象为搜索树结构，节点代表不同版本的答案，边代表refine的尝试**。利用Self-refine来改进答案，Self-evaluation来对答案采样reward值
> 一些标记的含义：问题 $P$，答案节点集合 $A$，每个节点的可以采取的动作集合 $M$(每一个都代表一个可能的self-refine)，对节点采样自奖励的函数 $R$(基于改进的质量和有效性)，节点 $a$ 所有采样的自奖励集合 $R_a$，终止状态函数 $T$，节点 $a$ 的价值函数 $Q(a)$，UCT值 $U(a)$
> **MCTSr流程如下：**
> * **Initialization初始化：** 用模型生成的初始答案或者虚拟响应（如 “我不知道”）建立根节点，减少模型过拟合

![8.2.4 Accessing GPT-4 level Mathematical Olympiad Solutions via Monte Carlo Tree Self-refine with LL-image-8.png](https://2479e837.cloudflare-imgbed-2q4.pages.dev/file/1782698730623_8.2.4_Accessing_GPT-4_level_Mathematical_Olympiad_Solutions_via_Monte_Carlo_Tree_Self-refine_with_LL-image-8.png)

**虚拟响应示例**

> * **Selection选择阶段：** 使用UCT值对还未完全扩展的候选答案节点排名，用贪婪策略选择最高价值节点进行探索和优化
> **未完全扩展：** LLM可以为任何答案状态生成无限数量的改进，每个节点都可能有无限的扩展操作
> * 节点的子节点数量达到预定义的限制，并且
> * 至少有一个子节点的Q值超过该节点的Q值
> * **Self-Refine自优化：** 模型以多轮对话refine prompt为指导，优化答案

![8.2.4 Accessing GPT-4 level Mathematical Olympiad Solutions via Monte Carlo Tree Self-refine with LL-image-4.png](https://2479e837.cloudflare-imgbed-2q4.pages.dev/file/1782698684647_8.2.4_Accessing_GPT-4_level_Mathematical_Olympiad_Solutions_via_Monte_Carlo_Tree_Self-refine_with_LL-image-4.png)

**Self-refine prompt**

> * **Self-Evaluation自评估：** $Q(a)$ 通过对答案进行 **多次Self-reward采样得到**
> $Q(a)=\frac{1}{2}\left(\min R_{a}+\frac{1}{\left|R_{a}\right|} \sum_{i=1}^{\left|R_{a}\right|} R_{a}^{i}\right)$
> **通过平均奖励的最小值和平均值，平衡最坏情况和平均结果**

![8.2.4 Accessing GPT-4 level Mathematical Olympiad Solutions via Monte Carlo Tree Self-refine with LL-image-1.png](https://2479e837.cloudflare-imgbed-2q4.pages.dev/file/1782698655643_8.2.4_Accessing_GPT-4_level_Mathematical_Olympiad_Solutions_via_Monte_Carlo_Tree_Self-refine_with_LL-image-1.png)

**Self-reward prompt**

> * **Backpropagation反向传播：** 将叶子节点奖励值采样和 Q 值更新反向传播到父节点和祖先节点，更新父节点 Q 值时考虑子节点的影响
> $$
> Q'(a)=\frac{1}{2}\left(Q(a)+\max_{i \in \text{Children}(a)} Q(i)\right)$$
> **通过对当前价值及其后续子节点的最佳可能结果求平均值来refine**
> * **UCT更新：** 根据下面的公式更新每个节点的UCT值
> $$
> UCT_{a}=Q(a)+c \sqrt{\frac{\ln N(\text{Father}(a)) + 1}{N(a) + \epsilon}}
> $$
> * **Termination Function终止函数**：搜索终止条件包括提前停止、搜索约束（rollouts数量限制等）和基于语言模型 logits 的高级标准，满足条件后根据 Q 值等获取最佳答案

# 三、实验结果

> **实验设置：** 使用 **LLaMA3 - 8B** 作为基础模型结合 **MCTSr**，在 GSM8K、GSM Hard、MATH、AIME、Math Odyssey 和 OlympiadBench 等数据集上进行实验
> 1. **GSM基准测试：** 在GSM8K和GSM-Hard 测试集上评估，结果显示 MCTSr迭代次数增加成功率显著提升，但GSM-Hard 在高迭代次数下存在性能上限
> 2. **MATH基准测试：** MATH 数据集分五个难度级别，8-rollouts MCTSr 在各级别成功率均有提升，总体成功率达 58.24%，表明算法在不同难度数学问题上的有效性和可扩展性
> 3. **奥林匹克级别基准测试：** 在AIME、Math Odyssey 和 OlympiadBench 数据集上测试，结果显示随着迭代次数增加成功率提高，如 AIME 从 2.26% 提升到 11.79%，体现算法在奥林匹克级别数学问题上的潜力和泛化能力
> **与先进闭源大模型性能比较，MCTSr能提升小参数开源模型数学推理能力至可比水平**

# 四、研究结论

> **贡献：**
> * 开发并验证将LLMs与MCTS集成的推理算法，在奥林匹克级别数学问题上证明其有效性
> * 通过实验揭示LLMs与MCTS协同的潜力，展示在复杂推理任务中的性能提升
> **局限：** MCTSr 算法虽在数学任务中有优势，但研究处于初步阶段。作为通用决策框架，其在不同场景（如黑箱优化问题和大语言模型自驱动对齐）的应用潜力有待探索
