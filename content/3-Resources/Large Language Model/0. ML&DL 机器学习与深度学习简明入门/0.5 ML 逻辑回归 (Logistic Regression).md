# 0.5.1 Sigmoid 函数

线性回归输出的是实数 $(-\infty, +\infty)$，但分类问题需要概率 $[0, 1]$。我们需要一个函数来挤压实数到概率空间。

**Sigmoid 函数** 正是这样的压缩器：

* 输入很大的正数 → 输出接近 1
* 输入很大的负数 → 输出接近 0
* 输入 0 → 输出 0.5

**Sigmoid 函数定义：** $\sigma(z) = \frac{1}{1 + e^{-z}}$

**重要性质：**

1. **值域**: $\sigma(z) \in (0, 1)$
2. **对称性**: $\sigma(-z) = 1 - \sigma(z)$
3) **导数**: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$

**导数推导：** $\sigma'(z) = \frac{d}{dz}\left(\frac{1}{1+e^{-z}}\right) = \frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{1+e^{-z}} \cdot \frac{e^{-z}}{1+e^{-z}} = \sigma(z)(1-\sigma(z))$

```python
def sigmoid(z: np.ndarray) -> np.ndarray:
    """
    Sigmoid 函数（数值稳定版本）。

    Parameters
    ----------
    z : np.ndarray
        输入值

    Returns
    -------
    np.ndarray
        Sigmoid 输出
    """
    # 数值稳定：分正负处理避免 exp 溢出
    result = np.zeros_like(z, dtype=float)
    positive = z >= 0
    negative = ~positive

    # z >= 0: sigmoid(z) = 1 / (1 + exp(-z))
    result[positive] = 1 / (1 + np.exp(-z[positive]))

    # z < 0: sigmoid(z) = exp(z) / (1 + exp(z))
    exp_z = np.exp(z[negative])
    result[negative] = exp_z / (1 + exp_z)

    return result

def sigmoid_derivative(z: np.ndarray) -> np.ndarray:
    """
    Sigmoid 函数的导数。

    Parameters
    ----------
    z : np.ndarray
        输入值

    Returns
    -------
    np.ndarray
        导数值 sigma(z) * (1 - sigma(z))
    """
    s = sigmoid(z)
    return s * (1 - s)
```

# 0.5.2 逻辑回归模型

逻辑回归 = 线性模型 + Sigmoid

1. 先用线性模型计算「分数」: $z = \mathbf{w}^T\mathbf{x} + b$
2. 再用 Sigmoid 转换为概率: $P(y=1|\mathbf{x}) = \sigma(z)$

**为什么叫「逻辑」回归?** 因为 Sigmoid 函数也叫 logistic function，而且我们在做的是回归一个概率值。

* **模型定义：**

$P(y=1|\mathbf{x}; \mathbf{w}, b) = \sigma(\mathbf{w}^T\mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T\mathbf{x} + b)}}$

$P(y=0|\mathbf{x}; \mathbf{w}, b) = 1 - P(y=1|\mathbf{x}) = \sigma(-(\mathbf{w}^T\mathbf{x} + b))$

* **统一形式：**

$P(y|\mathbf{x}; \mathbf{w}, b) = \hat{p}^y (1-\hat{p})^{1-y}$，其中 $\hat{p} = \sigma(\mathbf{w}^T\mathbf{x} + b)$

* **决策边界：** 当 $P(y=1) = 0.5$ 时，即 $\mathbf{w}^T\mathbf{x} + b = 0$，这是一个超平面。

# 0.5.3 最大似然估计与交叉熵损失

我们如何找到最好的参数 $\mathbf{w}, b$？**最大似然估计 (MLE)**: 找到使观测数据「最可能」出现的参数。

假设数据独立同分布，观测到整个数据集的概率是：$L(\mathbf{w}, b) = \prod_{i=1}^{n} P(y^{(i)} | \mathbf{x}^{(i)}; \mathbf{w}, b)$，我们要最大化这个似然函数

* **对数似然：** 为了方便计算，取对数（乘积变求和）：

$\log L = \sum_{i=1}^{n} \log P(y^{(i)} | \mathbf{x}^{(i)})$ $= \sum_{i=1}^{n} \left[ y^{(i)} \log \hat{p}^{(i)} + (1-y^{(i)}) \log(1-\hat{p}^{(i)}) \right]$

* **交叉熵损失：** 最大化对数似然 = 最小化负对数似然，即 **交叉熵损失**：

$\mathcal{L}(\mathbf{w}, b) = -\frac{1}{n}\sum_{i=1}^{n} \left[ y^{(i)} \log \hat{p}^{(i)} + (1-y^{(i)}) \log(1-\hat{p}^{(i)}) \right]$

#### 为什么叫 **交叉熵** ？

信息论中，两个分布 $p$ 和 $q$ 的交叉熵定义为：

$H(p, q) = -\sum_x p(x) \log q(x)$

这里 $p$ 是真实标签分布（0 或 1）， $q$ 是模型预测的概率。

```python
def cross_entropy_loss(y_true: np.ndarray, y_pred: np.ndarray, epsilon: float = 1e-15) -> float:
    """
    计算二分类交叉熵损失。

    Parameters
    ----------
    y_true : np.ndarray
        真实标签 (0 或 1)
    y_pred : np.ndarray
        预测概率
    epsilon : float
        数值稳定的小量

    Returns
    -------
    float
        平均交叉熵损失
    """
    # 裁剪预测值避免 log(0)
    y_pred = np.clip(y_pred, epsilon, 1 - epsilon)

    # 交叉熵
    loss = -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

    return loss
```

交叉熵损失的特点:

1. 正确分类时损失接近 0
2. 错误分类时损失趋向无穷大（强惩罚）
3) 这比简单的 0-1 损失更有利于梯度下降

# 0.5.4 梯度下降训练

* **损失函数对参数的梯度：**

令 $z = \mathbf{w}^T\mathbf{x} + b$，$\hat{p} = \sigma(z)$

对单个样本的损失：

$\ell = -[y\log\hat{p} + (1-y)\log(1-\hat{p})]$

链式法则：

$\frac{\partial \ell}{\partial z} = \frac{\partial \ell}{\partial \hat{p}} \cdot \frac{\partial \hat{p}}{\partial z}$

计算各部分：

$\frac{\partial \ell}{\partial \hat{p}} = -\frac{y}{\hat{p}} + \frac{1-y}{1-\hat{p}}$

$\frac{\partial \hat{p}}{\partial z} = \hat{p}(1-\hat{p})$

合并得到 **优雅的结果**：

$\frac{\partial \ell}{\partial z} = \hat{p} - y$

* **参数梯度：**

$\frac{\partial \ell}{\partial \mathbf{w}} = (\hat{p} - y)\mathbf{x}$

$\frac{\partial \ell}{\partial b} = \hat{p} - y$

* **批量梯度**

$\frac{\partial \mathcal{L}}{\partial \mathbf{w}} = \frac{1}{n}\mathbf{X}^T(\hat{\mathbf{p}} - \mathbf{y})$

$\frac{\partial \mathcal{L}}{\partial b} = \frac{1}{n}\sum_{i=1}^{n}(\hat{p}^{(i)} - y^{(i)})$

```python
class LogisticRegression:
    """
    二分类逻辑回归（从零实现）。

    Parameters
    ----------
    learning_rate : float
        学习率
    n_iterations : int
        迭代次数
    regularization : float
        L2 正则化强度

    Attributes
    ----------
    weights : np.ndarray
        模型权重
    bias : float
        偏置项
    loss_history : list
        训练过程中的损失记录
    """

    def init(self, learning_rate: float = 0.1, n_iterations: int = 1000,
                 regularization: float = 0.0):
        self.learning_rate = learning_rate
        self.n_iterations = n_iterations
        self.regularization = regularization
        self.weights = None
        self.bias = None
        self.loss_history = []
        self.weights_history = []  # 用于可视化决策边界演化

    def _sigmoid(self, z: np.ndarray) -> np.ndarray:
        """Sigmoid 激活函数。"""
        return sigmoid(z)

    def fit(self, X: np.ndarray, y: np.ndarray, record_every: int = 10) -> 'LogisticRegression':
        """
        使用梯度下降训练模型。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            目标标签 (0 或 1)
        record_every : int
            每隔多少步记录参数（用于可视化）

        Returns
        -------
        self
        """
        n_samples, n_features = X.shape

        # 初始化参数（小随机值）
        self.weights = np.random.randn(n_features) * 0.01
        self.bias = 0.0
        self.loss_history = []
        self.weights_history = []

        # 梯度下降
        for i in range(self.n_iterations):
            # 前向传播
            z = X @ self.weights + self.bias
            predictions = self._sigmoid(z)

            # 计算梯度
            error = predictions - y
            dw = (X.T @ error) / n_samples + self.regularization * self.weights
            db = np.mean(error)

            # 更新参数
            self.weights -= self.learning_rate * dw
            self.bias -= self.learning_rate * db

            # 记录损失
            loss = cross_entropy_loss(y, predictions)
            if self.regularization > 0:
                loss += 0.5 * self.regularization * np.sum(self.weights**2)
            self.loss_history.append(loss)

            # 记录参数历史
            if i % record_every == 0:
                self.weights_history.append((self.weights.copy(), self.bias))

        return self

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        """
        预测概率。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            输入数据

        Returns
        -------
        np.ndarray
            P(y=1|X) 的概率
        """
        z = X @ self.weights + self.bias
        return self._sigmoid(z)

    def predict(self, X: np.ndarray, threshold: float = 0.5) -> np.ndarray:
        """
        预测类别。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            输入数据
        threshold : float
            分类阈值

        Returns
        -------
        np.ndarray
            预测类别 (0 或 1)
        """
        return (self.predict_proba(X) >= threshold).astype(int)
```

# 0.5.7 Softmax 多分类

当有多于两个类别时，我们需要：

1. 为每个类别输出一个分数
2. 将分数转换为概率（所有类别概率和为 1）

**Softmax 函数** 正是做这件事的

* **Softmax 函数：** 给定 K 个类别的分数 $z_1, z_2, ..., z_K$：$P(y=k) = \text{softmax}(\mathbf{z})_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$
* **性质：**
  1. $\sum_k P(y=k) = 1$（概率归一化）
  2. 当 K=2 时，softmax 退化为 sigmoid
* **多分类交叉熵损失：** $\mathcal{L} = -\frac{1}{n}\sum_{i=1}^{n}\sum_{k=1}^{K} y_k^{(i)} \log P(y=k|\mathbf{x}^{(i)})$，其中 $y_k^{(i)}$ 是 one-hot 编码的标签。

```python
def softmax(z: np.ndarray) -> np.ndarray:
    """
    Softmax 函数（数值稳定版本）。

    Parameters
    ----------
    z : np.ndarray, shape (n_samples, n_classes)
        输入分数

    Returns
    -------
    np.ndarray
        概率分布
    """
    # 减去最大值避免 exp 溢出
    z_shifted = z - np.max(z, axis=1, keepdims=True)
    exp_z = np.exp(z_shifted)
    return exp_z / np.sum(exp_z, axis=1, keepdims=True)

def one_hot_encode(y: np.ndarray, n_classes: int) -> np.ndarray:
    """
    One-hot 编码。

    Parameters
    ----------
    y : np.ndarray, shape (n_samples,)
        类别标签 (0, 1, ..., n_classes-1)
    n_classes : int
        类别数

    Returns
    -------
    np.ndarray, shape (n_samples, n_classes)
        One-hot 编码矩阵
    """
    n_samples = len(y)
    one_hot = np.zeros((n_samples, n_classes))
    one_hot[np.arange(n_samples), y.astype(int)] = 1
    return one_hot
```

Softmax 的特点:

1. 输出始终是有效的概率分布（和为 1，非负）
2. 分数差异越大，概率分布越「尖锐」
3) 当所有分数相等时，各类概率相等

```python
class SoftmaxRegression:
    """
    多分类 Softmax 回归（从零实现）。

    Parameters
    ----------
    n_classes : int
        类别数
    learning_rate : float
        学习率
    n_iterations : int
        迭代次数
    regularization : float
        L2 正则化强度
    """

    def init(self, n_classes: int, learning_rate: float = 0.1,
                 n_iterations: int = 1000, regularization: float = 0.0):
        self.n_classes = n_classes
        self.learning_rate = learning_rate
        self.n_iterations = n_iterations
        self.regularization = regularization
        self.weights = None
        self.bias = None
        self.loss_history = []

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'SoftmaxRegression':
        """
        训练模型。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            类别标签

        Returns
        -------
        self
        """
        n_samples, n_features = X.shape

        # 初始化参数
        self.weights = np.random.randn(n_features, self.n_classes) * 0.01
        self.bias = np.zeros(self.n_classes)

        # One-hot 编码
        y_one_hot = one_hot_encode(y, self.n_classes)

        # 梯度下降
        for i in range(self.n_iterations):
            # 前向传播
            z = X @ self.weights + self.bias
            probs = softmax(z)

            # 计算梯度
            error = probs - y_one_hot
            dw = (X.T @ error) / n_samples + self.regularization * self.weights
            db = np.mean(error, axis=0)

            # 更新参数
            self.weights -= self.learning_rate * dw
            self.bias -= self.learning_rate * db

            # 记录损失
            loss = -np.mean(np.sum(y_one_hot * np.log(probs + 1e-15), axis=1))
            if self.regularization > 0:
                loss += 0.5 * self.regularization * np.sum(self.weights**2)
            self.loss_history.append(loss)

        return self

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        """
        预测各类别概率。
        """
        z = X @ self.weights + self.bias
        return softmax(z)

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测类别。
        """
        return np.argmax(self.predict_proba(X), axis=1)
```

# 🌟为什么不使用 MSE 作为分类损失?

![[_Attachments/Images/0.5 ML 逻辑回归 (Logistic Regression)-image-2.png]]

为什么交叉熵更适合分类:

1. 当预测严重错误时，交叉熵的梯度更大 → 更快修正
2. MSE 梯度在预测接近 0 或 1 时会变小 → 训练缓慢
3) 交叉熵有明确的概率解释（最大似然）

# 总结

1. **Sigmoid 函数**: 将实数压缩到 (0,1)，作为概率解释
2. **最大似然估计**: 推导出交叉熵损失的来源
3) **交叉熵损失**: 比 MSE 更适合分类任务
4) **梯度下降**: 优雅的梯度公式 $\hat{p} - y$
5. **Softmax 多分类**: 将二分类推广到多类
> "逻辑回归是线性模型与概率分类的完美结合。它简单、可解释、且常常有效。"
