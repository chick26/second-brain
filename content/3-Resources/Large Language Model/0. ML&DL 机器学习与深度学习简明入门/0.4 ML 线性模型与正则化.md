# 0.4.1 普通最小二乘法 (OLS)

> 想象你有一堆散落的点，你想找一条直线（或超平面）来"最好地"穿过它们。什么叫"最好"？OLS 的回答：使所有点到直线的 **垂直距离平方和** 最小

为什么用平方？

1. 惩罚大偏差（远离的点权重更大）
2. 数学上更容易处理（可微、有闭式解）
3) 与高斯噪声假设一致（最大似然估计）

***线性模型***

$\hat{y} = \mathbf{X}\mathbf{w} + b = \mathbf{X}_{aug}\mathbf{w}_{aug}$,其中 $\mathbf{X}_{aug} = [\mathbf{X}, \mathbf{1}]$ 包含偏置项。

***损失函数***

$\mathcal{L}(\mathbf{w}) = \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2 = (\mathbf{y} - \mathbf{X}\mathbf{w})^T(\mathbf{y} - \mathbf{X}\mathbf{w})$

***正规方程***

对 $\mathbf{w}$ 求导并令其为零：$\frac{\partial \mathcal{L}}{\partial \mathbf{w}} = -2\mathbf{X}^T(\mathbf{y} - \mathbf{X}\mathbf{w}) = \mathbf{0}$

得到 **正规方程**：$\mathbf{X}^T\mathbf{X}\mathbf{w} = \mathbf{X}^T\mathbf{y}$

当 $\mathbf{X}^T\mathbf{X}$ 可逆时，**闭式解** 为：$\hat{\mathbf{w}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$

```python
class LinearRegression:
    """
    普通最小二乘线性回归。

    Attributes
    ----------
    weights : np.ndarray
        模型权重（包含偏置）
    """

    def __init__(self):
        self.weights = None

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'LinearRegression':
        """
        使用正规方程拟合模型。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            目标值

        Returns
        -------
        self
        """
        # 添加偏置项
        n_samples = X.shape[0]
        X_aug = np.column_stack([X, np.ones(n_samples)])

        # 正规方程解
        # w = (X^T X)^(-1) X^T y
        XTX = X_aug.T @ X_aug
        XTy = X_aug.T @ y

        self.weights = np.linalg.solve(XTX, XTy)

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            输入数据

        Returns
        -------
        np.ndarray
            预测值
        """
        n_samples = X.shape[0]
        X_aug = np.column_stack([X, np.ones(n_samples)])
        return X_aug @ self.weights

    @property
    def coef_(self) -> np.ndarray:
        """返回特征系数（不含偏置）。"""
        return self.weights[:-1]

    @property
    def intercept_(self) -> float:
        """返回偏置项。"""
        return self.weights[-1]
```

## OLS 的几何解释

$ŷ = Xw$ 是 y 在 X 列空间上的正交投影，残差 $(y - ŷ)$ 垂直于列空间，投影矩阵 $H = X(X'X)^{-1}X'$ 是帽子矩阵

# 0.4.2 Ridge 回归 (L2 正则化)

当特征数量多或存在多重共线性时，OLS 的解可能不稳定（方差大）。

Ridge 回归通过添加"惩罚项"来约束权重：

* 不让权重变得太大
* 在偏差和方差之间做权衡
* ***Ridge 损失函数：*** $\mathcal{L}_{Ridge}(\mathbf{w}) = \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2 + \lambda \|\mathbf{w}\|^2$，其中 $\lambda > 0$ 是正则化参数。
* ***闭式解：*** $\hat{\mathbf{w}}_{Ridge} = (\mathbf{X}^T\mathbf{X} + \lambda \mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}$，注意：即使 $\mathbf{X}^T\mathbf{X}$ 奇异，加上 $\lambda \mathbf{I}$ 后也变得可逆
* ***贝叶斯解释：***Ridge 回归等价于在权重上加高斯先验：$\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \sigma_w^2 \mathbf{I})$，其中 $\lambda = \sigma^2 / \sigma_w^2$（ $$
  \sigma^2$$ 是噪声方差）

```python
class RidgeRegression:
    """
    Ridge 回归 (L2 正则化)。

    Parameters
    ----------
    alpha : float
        正则化强度
    fit_intercept : bool
        是否拟合截距
    """

    def __init__(self, alpha: float = 1.0, fit_intercept: bool = True):
        self.alpha = alpha
        self.fit_intercept = fit_intercept
        self.weights = None
        self.intercept = 0.0
        self._X_mean = None
        self._y_mean = None

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'RidgeRegression':
        """
        拟合 Ridge 回归。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            目标值

        Returns
        -------
        self
        """
        n_samples, n_features = X.shape

        # 中心化数据（如果拟合截距）
        if self.fit_intercept:
            self._X_mean = np.mean(X, axis=0)
            self._y_mean = np.mean(y)
            X_centered = X - self._X_mean
            y_centered = y - self._y_mean
        else:
            X_centered = X
            y_centered = y

        # Ridge 闭式解
        # w = (X'X + λI)^(-1) X'y
        XTX = X_centered.T @ X_centered
        XTy = X_centered.T @ y_centered

        # 添加正则化项
        I = np.eye(n_features)
        self.weights = np.linalg.solve(XTX + self.alpha * I, XTy)

        # 计算截距
        if self.fit_intercept:
            self.intercept = self._y_mean - self._X_mean @ self.weights

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测。
        """
        return X @ self.weights + self.intercept

    @property
    def coef_(self) -> np.ndarray:
        return self.weights

    @property
    def intercept_(self) -> float:
        return self.intercept
```

# 0.4.3 Lasso 回归 (L1 正则化)

Lasso 使用 L1 惩罚而非 L2。关键区别：

* **L1 产生稀疏解**：许多权重会被精确地设为零
* **自动特征选择**：Lasso 会"挑选"重要的特征
* ***Lasso 损失函数：*** $\mathcal{L}_{Lasso}(\mathbf{w}) = \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2 + \lambda \|\mathbf{w}\|_1$，其中 $\|\mathbf{w}\|_1 = \sum_i |w_i|$。
* ***没有闭式解：***由于 L1 范数在零点不可微，Lasso 没有闭式解。常用求解方法：
  * **坐标下降 (Coordinate Descent)**
  * **ISTA / FISTA**
  * **次梯度方法**
* ***贝叶斯解释：***Lasso 等价于在权重上加拉普拉斯先验：$p(w_i) \propto \exp(-\lambda |w_i|)$

```python
class LassoRegression:
    """
    Lasso 回归 (L1 正则化)，使用坐标下降求解。

    Parameters
    ----------
    alpha : float
        正则化强度
    max_iter : int
        最大迭代次数
    tol : float
        收敛容差
    """

    def __init__(self, alpha: float = 1.0, max_iter: int = 1000, tol: float = 1e-4):
        self.alpha = alpha
        self.max_iter = max_iter
        self.tol = tol
        self.weights = None
        self.intercept = 0.0

    def _soft_threshold(self, z: float, gamma: float) -> float:
        """
        软阈值函数（近端算子）。

        S(z, γ) = sign(z) * max(|z| - γ, 0)
        """
        if z > gamma:
            return z - gamma
        elif z < -gamma:
            return z + gamma
        else:
            return 0.0

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'LassoRegression':
        """
        使用坐标下降拟合 Lasso。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            目标值

        Returns
        -------
        self
        """
        n_samples, n_features = X.shape

        # 中心化
        X_mean = np.mean(X, axis=0)
        y_mean = np.mean(y)
        X_centered = X - X_mean
        y_centered = y - y_mean

        # 预计算 X^T X 的对角线
        X_col_norms_sq = np.sum(X_centered**2, axis=0)

        # 初始化权重
        self.weights = np.zeros(n_features)

        # 坐标下降
        for iteration in range(self.max_iter):
            weights_old = self.weights.copy()

            for j in range(n_features):
                # 计算残差（排除第 j 个特征）
                residual = y_centered - X_centered @ self.weights + X_centered[:, j] * self.weights[j]

                # 计算 rho_j = X_j^T * residual
                rho_j = X_centered[:, j] @ residual

                # 软阈值更新
                if X_col_norms_sq[j] > 0:
                    z_j = rho_j / X_col_norms_sq[j]
                    gamma_j = self.alpha / X_col_norms_sq[j]
                    self.weights[j] = self._soft_threshold(z_j, gamma_j)

            # 检查收敛
            if np.max(np.abs(self.weights - weights_old)) < self.tol:
                break

        # 计算截距
        self.intercept = y_mean - X_mean @ self.weights

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测。
        """
        return X @ self.weights + self.intercept

    @property
    def coef_(self) -> np.ndarray:
        return self.weights

    @property
    def intercept_(self) -> float:
        return self.intercept
```

### L1 vs L2 的几何解释

为什么 L1 产生稀疏？看几何图！

![](<../images/0.4 ML 线性模型与正则化-image-4.png>)

关键洞察：

* L2 约束区域是圆形 → 解通常不在坐标轴上 → 非稀疏
* L1 约束区域是菱形 → 解很可能在顶点 → 稀疏（某些 $w_i = 0$）

# 0.4.4 ElasticNet (L1 + L2)

**ElasticNet** 结合了 L1 和 L2 正则化：$\mathcal{L}_{ElasticNet}(\mathbf{w}) = \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2 + \lambda_1 \|\mathbf{w}\|_1 + \lambda_2 \|\mathbf{w}\|^2$

或者用另一种参数化（更常用）：$\mathcal{L}(\mathbf{w}) = \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2 + \alpha \left( \rho \|\mathbf{w}\|_1 + \frac{1-\rho}{2} \|\mathbf{w}\|^2 \right)$，其中 $\rho \in [0, 1]$ 控制 L1 和 L2 的比例

```python
class ElasticNetRegression:
    """
    ElasticNet 回归 (L1 + L2 正则化)。

    Parameters
    ----------
    alpha : float
        总正则化强度
    l1_ratio : float
        L1 惩罚的比例 (0 = Ridge, 1 = Lasso)
    max_iter : int
        最大迭代次数
    tol : float
        收敛容差
    """

    def __init__(self, alpha: float = 1.0, l1_ratio: float = 0.5,
                 max_iter: int = 1000, tol: float = 1e-4):
        self.alpha = alpha
        self.l1_ratio = l1_ratio
        self.max_iter = max_iter
        self.tol = tol
        self.weights = None
        self.intercept = 0.0

    def _soft_threshold(self, z: float, gamma: float) -> float:
        """
        软阈值函数。
        """
        if z > gamma:
            return z - gamma
        elif z < -gamma:
            return z + gamma
        else:
            return 0.0

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'ElasticNetRegression':
        """
        使用坐标下降拟合 ElasticNet。
        """
        n_samples, n_features = X.shape

        # 分解 alpha
        l1_penalty = self.alpha * self.l1_ratio
        l2_penalty = self.alpha * (1 - self.l1_ratio)

        # 中心化
        X_mean = np.mean(X, axis=0)
        y_mean = np.mean(y)
        X_centered = X - X_mean
        y_centered = y - y_mean

        # 预计算
        X_col_norms_sq = np.sum(X_centered**2, axis=0)

        # 初始化
        self.weights = np.zeros(n_features)

        # 坐标下降
        for iteration in range(self.max_iter):
            weights_old = self.weights.copy()

            for j in range(n_features):
                residual = y_centered - X_centered @ self.weights + X_centered[:, j] * self.weights[j]
                rho_j = X_centered[:, j] @ residual

                # ElasticNet 更新（带 L2 修正）
                denominator = X_col_norms_sq[j] + l2_penalty
                if denominator > 0:
                    z_j = rho_j / denominator
                    gamma_j = l1_penalty / denominator
                    self.weights[j] = self._soft_threshold(z_j, gamma_j)

            if np.max(np.abs(self.weights - weights_old)) < self.tol:
                break

        self.intercept = y_mean - X_mean @ self.weights

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        return X @ self.weights + self.intercept

    @property
    def coef_(self) -> np.ndarray:
        return self.weights
```

# 0.4.5 正则化路径与贝叶斯线性回归视角

* 正则化路径展示了随着 $\lambda$ 变化，系数如何变化。
![](<../images/0.4 ML 线性模型与正则化-image-3.png>)

观察：

* Ridge: 所有系数平滑地趋向零，但永远不会精确为零
* Lasso: 系数逐渐变为精确的零（稀疏解）
![](<../images/0.4 ML 线性模型与正则化-image-2.png>)

贝叶斯解释：

* Ridge = 高斯先验 → 权重可以任意大，但被惩罚
* Lasso = 拉普拉斯先验 → 先验在零处有尖峰，鼓励稀疏

# 总结

1. **OLS**：最小化残差平方和，几何上是投影
2. **Ridge (L2)**：防止过拟合，稳定解，贝叶斯 = 高斯先验
3) **Lasso (L1)**：稀疏解，自动特征选择，贝叶斯 = 拉普拉斯先验
4) **ElasticNet**：结合 L1 和 L2 的优点
5. **正则化路径**：可视化系数随 λ 的变化
> "正则化是在复杂性和拟合能力之间做权衡。L1 给你稀疏，L2 给你稳定。"
