> "从回归到分类，从二分类到多分类，Softmax是关键的一步。

## 1. 从回归到分类

### 1.1 多分类问题的数学建模

#### 1.1.1 问题定义

**输入**: 特征向量 $\mathbf{x} \in \mathbb{R}^d$

**输出**: 类别标签 $y \in \{1, 2, \ldots, K\}$（ $K$ 是类别数）

**训练数据**: $\mathcal{D} = \{(\mathbf{x}^{(i)}, y^{(i)})\}_{i=1}^{n}$

**目标**: 学习一个分类器 $f: \mathbb{R}^d \rightarrow \{1, 2, \ldots, K\}$ 使得 $f(\mathbf{x}) \approx y$

#### 1.1.2 从线性回归到线性分类器

**线性回归**（单输出）:

$\hat{y} = \mathbf{w}^T\mathbf{x} + b \in \mathbb{R}$

**线性分类器**（多输出）:

$\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b} \in \mathbb{R}^K$

其中：

* $\mathbf{W} \in \mathbb{R}^{K \times d}$: 权重矩阵，第 $k$ 行 $\mathbf{w}_k^T$ 对应第 $k$ 个类别的权重
* $\mathbf{b} \in \mathbb{R}^K$: 偏置向量，$b\_k$ 对应第 $k$ 个类别的偏置

$\mathbf{z} = [z_1, z_2, \ldots, z_K]^T$ **得分向量**(logits)，$z\_k$ 表示样本属于第 $k$ 类的"原始得分"

**矩阵形式展开**:

$\mathbf{z} = \begin{bmatrix} \mathbf{w}_1^T\mathbf{x} + b_1 \\ \mathbf{w}_2^T\mathbf{x} + b_2 \\ \vdots \\ \mathbf{w}_K^T\mathbf{x} + b_K \end{bmatrix} = \begin{bmatrix} z_1 \\ z_2 \\ \vdots \\ z_K \end{bmatrix}$

每个 $z_k = \mathbf{w}_k^T\mathbf{x} + b_k$ 可以看作是第 $k$ 个类别的"投票得分"。

#### 1.2.3 核心问题：得分 → 概率

**问题**: 得分 $\mathbf{z}$ 可以是任意实数，如何转换为概率分布？

**要求**: 概率分布 $\hat{\mathbf{y}} = [\hat{y}_1, \ldots, \hat{y}_K]^T$ 必须满足：

1\. **非负性**: $\hat{y}_k \geq 0, \forall k$

2\. **归一化**: $\sum_{k=1}^{K} \hat{y}_k = 1$

3\. **保序性**: 若 $z_i > z_j$，则 $\hat{y}_i > \hat{y}_j$（得分高的类别概率也高）

**解决方案**: **Softmax函数**！

$\hat{\mathbf{y}} = \text{softmax}(\mathbf{z})$

这是从得分空间 $\mathbb{R}^K$ 到概率单纯形 $\Delta^{K-1} = \{\mathbf{p} \in \mathbb{R}^K \mid p_k \geq 0, \sum_k p_k = 1\}$ 的映射。

### 1.3 标签表示：One-hot编码

**原始标签**: $y \in \{1, 2, \ldots, K\}$（类别索引）

**One-hot编码**: $\mathbf{y} \in \{0, 1\}^K$，只有第 $\mathbf{y} \in \{0, 1\}^K$ 个位置为1，其余为0

$\mathbf{y} = [\underbrace{0, \ldots, 0}_{y-1}, 1, \underbrace{0, \ldots, 0}_{K-y}]^T$

**例子**（ $K=4$）:

* 类别1: $\mathbf{y} = [1, 0, 0, 0]^T$
* 类别2: $\mathbf{y} = [0, 1, 0, 0]^T$
* 类别3: $\mathbf{y} = [0, 0, 1, 0]^T$
* 类别4: $\mathbf{y} = [0, 0, 0, 1]^T$

**优势**:

* 统一表示：所有类别用相同维度的向量
* 便于计算：可以用向量运算
* 对称性：没有类别之间的顺序关系（避免模型误解为有序）

### 1.4 完整的Softmax回归模型

**前向传播**:

$\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b} \quad \text{(线性变换)}$

$\hat{\mathbf{y}} = \text{softmax}(\mathbf{z}) \quad \text{(归一化为概率)}$

**预测类别**:

$\hat{y} = \arg\max_{k} \hat{y}_k = \arg\max_{k} z_k$

注意：由于Softmax是单调的， $\arg\max$ 对`logits`和概率给出相同结果。

**决策边界**: 类别 $i$ 和类别 $j$ 的决策边界是超平面：

$z_i = z_j \Leftrightarrow (\mathbf{w}_i - \mathbf{w}_j)^T\mathbf{x} + (b_i - b_j) = 0$

这是一个线性决策边界！

## 2. Softmax函数

### 2.1 定义与直观理解

**定义**: Softmax函数将任意实数向量 $\mathbf{z} \in \mathbb{R}^K$ 映射到概率分布 $\hat{\mathbf{y}} \in \Delta^{K-1}$：

$\text{softmax}(\mathbf{z})_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}} = \frac{\exp(z_k)}{\sum_{j=1}^{K} \exp(z_j)}$

**向量形式**:

$\hat{\mathbf{y}} = \text{softmax}(\mathbf{z}) = \frac{1}{\sum_{j=1}^{K} e^{z_j}} \begin{bmatrix} e^{z_1} \\ e^{z_2} \\ \vdots \\ e^{z_K} \end{bmatrix}$

**直观理解**:

1\. **指数化**: $e^{z_k}$ 将得分映射到正数，且放大差异

2\. **归一化**: 除以总和使得概率之和为1

3\. **概率解释**: $\hat{y}_k = P(y = k \mid \mathbf{x})$ 表示样本属于类别 $k$ 的概率

### 2.2 核心性质与证明

#### 性质1: 非负性

$\text{softmax}(\mathbf{z})_k = \frac{e^{z_k}}{\sum_{j} e^{z_j}} > 0, \quad \forall k$

**证明**: 指数函数 $e^{z\_k} > 0$ 对所有实数 $z\_k$ 成立，分母也是正数之和，因此整个表达式为正。□

#### 性质2: 归一化

$\sum_{k=1}^{K} \text{softmax}(\mathbf{z})_k = 1$

**证明**:

$\sum_{k=1}^{K} \text{softmax}(\mathbf{z})_k = \sum_{k=1}^{K} \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}} = \frac{\sum_{k=1}^{K} e^{z_k}}{\sum_{j=1}^{K} e^{z_j}} = 1$

#### 性质3: 保序性（单调性）

若 $z_i > z_j$，则 $\text{softmax}(\mathbf{z})_i > \text{softmax}(\mathbf{z})_j$

**证明**: 设 $S = \sum_{k=1}^{K} e^{z_k}$，则：

$\frac{\text{softmax}(\mathbf{z})_i}{\text{softmax}(\mathbf{z})_j} = \frac{e^{z_i}/S}{e^{z_j}/S} = \frac{e^{z_i}}{e^{z_j}} = e^{z_i - z_j}$

由于 $z_i > z_j \Rightarrow z_i - z_j > 0 \Rightarrow e^{z_i - z_j} > 1$，因此 $\text{softmax}(\mathbf{z})_i > \text{softmax}(\mathbf{z})_j$。

#### 性质4: 平移不变性

$\text{softmax}(\mathbf{z} + c\mathbf{1}) = \text{softmax}(\mathbf{z}), \quad \forall c \in \mathbb{R}$

**证明**:

$\text{softmax}(\mathbf{z} + c\mathbf{1})_k = \frac{e^{z_k + c}}{\sum_{j} e^{z_j + c}} = \frac{e^c \cdot e^{z_k}}{e^c \cdot \sum_{j} e^{z_j}} = \frac{e^{z_k}}{\sum_{j} e^{z_j}} = \text{softmax}(\mathbf{z})_k$

**数值稳定性应用**: 实践中，为避免 $e^{z_k}$ 溢出（当 $z_k$ 很大时），使用：

$\text{softmax}(\mathbf{z})_k = \frac{e^{z_k - \max_j z_j}}{\sum_{j} e^{z_j - \max_j z_j}}$

减去最大值使得所有指数项 $\leq 1$，避免数值溢出。

### 2.3 为什么叫"Soft"max？

**Hard Max**（argmax）:

$\text{hardmax}(\mathbf{z})_k = \begin{cases} 1, & \text{if } k = \arg\max_j z_j \\ 0, & \text{otherwise} \end{cases}$

**Soft Max**:

$\text{softmax}(\mathbf{z})_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$

**关键区别**:

* **Hard Max**: 不可微，只有最大值为1，其余为0
* **Soft Max**: 可微，最大值概率最高，但其他类别也有非零概率
* **"软化"**: Softmax给所有类别分配一定概率，而不是硬性决策

**为什么需要"软化"**:

1\. **可微性**: 梯度下降需要可微函数

2\. **不确定性**: 表达模型的置信度（概率接近1表示很确定）

3\. **梯度信息**: 即使预测错误，所有类别都能获得梯度更新

4\. **正则化效果**: 防止模型过度自信

### 2.4 Softmax的概率解释

#### 2.4.1 从线性模型到概率模型

**线性判别分析**: 假设每个类别的条件概率为：

$P(y = k \mid \mathbf{x}) \propto \exp(\mathbf{w}_k^T\mathbf{x} + b_k)$

这是 **指数族分布** 的形式。归一化后得到：

$P(y = k \mid \mathbf{x}) = \frac{\exp(\mathbf{w}_k^T\mathbf{x} + b_k)}{\sum_{j=1}^{K} \exp(\mathbf{w}_j^T\mathbf{x} + b_j)} = \text{softmax}(\mathbf{z})_k$

其中 $z_k = \mathbf{w}_k^T\mathbf{x} + b_k$。

**结论**: Softmax回归是 **多类别逻辑回归** 的自然推广！

#### 2.4.2 与二分类Sigmoid的关系

对于二分类问题（ $K=2$），Softmax退化为Sigmoid函数。

**Softmax形式**:

$P(y=1 \mid \mathbf{x}) = \frac{e^{z_1}}{e^{z_1} + e^{z_2}}$

令 $z = z_1 - z_2$，则：

$P(y=1 \mid \mathbf{x}) = \frac{e^{z_1}}{e^{z_1} + e^{z_2}} = \frac{1}{1 + e^{z_2 - z_1}} = \frac{1}{1 + e^{-z}} = \sigma(z)$

这正是 **Sigmoid函数**！

**结论**: Sigmoid是Softmax在二分类时的特例。

### 2.5 Softmax的导数

Softmax的导数在反向传播中至关重要。

**定理**: Softmax函数的`Jacobian`矩阵为：

$\frac{\partial \text{softmax}(\mathbf{z})_i}{\partial z_j} = \text{softmax}(\mathbf{z})_i (\delta_{ij} - \text{softmax}(\mathbf{z})_j)$

其中 $\delta_{ij}$ 是Kronecker delta（ $i=j$ 时为1，否则为0）。

**证明**:

设 $\hat{y}_k = \text{softmax}(\mathbf{z})_k = \frac{e^{z_k}}{S}$，其中 $S = \sum_{j} e^{z_j}$。

**情况1**: $i = j$（对角元素）

$\frac{\partial \hat{y}_i}{\partial z_i} = \frac{\partial}{\partial z_i}\left(\frac{e^{z_i}}{S}\right) = \frac{e^{z_i} \cdot S - e^{z_i} \cdot e^{z_i}}{S^2} = \frac{e^{z_i}}{S} \cdot \frac{S - e^{z_i}}{S} = \hat{y}_i(1 - \hat{y}_i)$

**情况2**: $i \neq j$（非对角元素）

$\frac{\partial \hat{y}_i}{\partial z_j} = \frac{\partial}{\partial z_j}\left(\frac{e^{z_i}}{S}\right) = \frac{0 \cdot S - e^{z_i} \cdot e^{z_j}}{S^2} = -\frac{e^{z_i}}{S} \cdot \frac{e^{z_j}}{S} = -\hat{y}_i \hat{y}_j$

**统一形式**:

$\frac{\partial \hat{y}_i}{\partial z_j} = \hat{y}_i(\delta_{ij} - \hat{y}_j)$

**Jacobian矩阵**:

$\mathbf{J} = \text{diag}(\hat{\mathbf{y}}) - \hat{\mathbf{y}}\hat{\mathbf{y}}^T$

这个导数形式在计算交叉熵损失的梯度时会产生极其优雅的结果！□

### 2.6 温度参数的影响

**温度Softmax**: 引入温度参数 $T > 0$：

$\text{softmax}_T(\mathbf{z})_k = \frac{e^{z_k/T}}{\sum_j e^{z_j/T}}$

这个实验展示了 **温度参数** T 如何影响Softmax的输出分布。

给定logits $[1.0, 2.0, 3.0, 4.0]$，我们计算 $\text{softmax}(\mathbf{z}/T)$：

**数学分析**:

当 $T \to 0$ 时：

$\lim_{T \to 0} \text{softmax}_T(\mathbf{z}) = \text{one-hot}(\arg\max_k z_k)$

当 $T \to \infty$ 时：

$\lim_{T \to \infty} \text{softmax}_T(\mathbf{z}) = \left[\frac{1}{K}, \ldots, \frac{1}{K}\right]^T$

### 2.7 Softmax vs Sigmoid

对于二分类问题，Softmax退化为Sigmoid。

**Sigmoid函数**:

$\sigma(z) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}$

**Softmax（二分类）**:

$P(y=1 \mid \mathbf{x}) = \frac{e^{z_1}}{e^{z_1} + e^{z_2}}$

令 $z = z_1 - z_2$，则：

$P(y=1 \mid \mathbf{x}) = \frac{e^{z_1}}{e^{z_1} + e^{z_2}} = \frac{1}{1 + e^{z_2 - z_1}} = \frac{1}{1 + e^{-z}} = \sigma(z)$

## 3. 交叉熵损失

### 3.1 损失函数的设计原理

#### 3.1.1 最大似然估计的视角

**概率模型**: Softmax回归定义了一个条件概率模型：

$P(y = k \mid \mathbf{x}; \mathbf{W}, \mathbf{b}) = \text{softmax}(\mathbf{W}\mathbf{x} + \mathbf{b})_k$

**似然函数**: 给定参数，观测到训练数据 $\mathcal{D} = \{(\mathbf{x}^{(i)}, y^{(i)})\}_{i=1}^{n}$ 的概率：

$P(\mathcal{D} \mid \mathbf{W}, \mathbf{b}) = \prod_{i=1}^{n} P(y^{(i)} \mid \mathbf{x}^{(i)}; \mathbf{W}, \mathbf{b})$

**对数似然**:

$\log P(\mathcal{D} \mid \mathbf{W}, \mathbf{b}) = \sum_{i=1}^{n} \log P(y^{(i)} \mid \mathbf{x}^{(i)}; \mathbf{W}, \mathbf{b})$

**最大似然估计** (MLE): 最大化对数似然等价于 **最小化负对数似然**：

$\mathbf{W}^*, \mathbf{b}^* = \arg\min_{\mathbf{W}, \mathbf{b}} -\sum_{i=1}^{n} \log P(y^{(i)} \mid \mathbf{x}^{(i)}; \mathbf{W}, \mathbf{b})$

#### 3.1.2 交叉熵的定义

**单个样本的损失**:

设真实标签为 $\mathcal{D} = \{(\mathbf{x}^{(i)}, y^{(i)})\}_{i=1}^{n}$（类别索引），预测概率为 $\hat{\mathbf{y}} = [\hat{y}_1, \ldots, \hat{y}_K]^T$。

**负对数似然形式**:

$\ell(\hat{\mathbf{y}}, y) = -\log \hat{y}_y$

**One-hot形式**: 将标签 y 编码为one-hot向量 $\mathbf{y}$：

$\ell(\hat{\mathbf{y}}, \mathbf{y}) = -\sum_{k=1}^{K} y_k \log \hat{y}_k$

由于 $\mathbf{y}$ 是one-hot（只有第 $y$ 个位置为1），这两种形式等价。

**批量损失**（平均）:

$L(\mathbf{W}, \mathbf{b}) = \frac{1}{n}\sum_{i=1}^{n} \ell(\hat{\mathbf{y}}^{(i)}, \mathbf{y}^{(i)}) = -\frac{1}{n}\sum_{i=1}^{n}\sum_{k=1}^{K} y_k^{(i)} \log \hat{y}_k^{(i)}$

**直觉**:

* 最小化 $-\log \hat{y}_c$ = 最大化正确类别 $c$ 的预测概率
* 当 $\hat{y}_c \to 1$ 时，损失 $\to 0$（完美预测）
* 当 $\hat{y}_c \to 0$ 时，损失 $\to \infty$（严重惩罚）

### 3.2 信息论视角

#### 3.2.1 信息论基础

**熵**(Entropy): 衡量随机变量的不确定性

$H(P) = -\sum_{k=1}^{K} p_k \log p_k$

* 熵越大，分布越不确定
* 均匀分布熵最大：$H = \log K$
* 确定性分布熵最小：$H = 0$

**交叉熵**(Cross-Entropy): 用分布 $Q$ 编码分布 $P$ 所需的平均比特数

$H(P, Q) = -\sum_{k=1}^{K} p_k \log q_k$

**KL散度**(Kullback-Leibler Divergence): 衡量两个分布的差异

$D_{KL}(P \| Q) = \sum_{k=1}^{K} p_k \log \frac{p_k}{q_k} = H(P, Q) - H(P)$

**关系**:

$H(P, Q) = H(P) + D_{KL}(P \| Q)$

#### 3.2.2 在分类问题中的应用

* $P$: 真实分布（one-hot，确定性分布，$H(P) = 0$）
* $Q$: 预测分布（Softmax输出，$\hat{\mathbf{y}}$）

$L = H(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_k y_k \log \hat{y}_k$

由于 $H(\mathbf{y}) = 0$（真实标签是确定的），有：

$L = H(\mathbf{y}, \hat{\mathbf{y}}) = D_{KL}(\mathbf{y} \| \hat{\mathbf{y}})$

**最小化交叉熵** $\Leftrightarrow$ **最小化KL散度** $\Leftrightarrow$ **使预测分布接近真实分布**

### 3.3 梯度推导：Softmax + 交叉熵的优雅性

#### 3.3.1 完整的梯度推导

**目标**: 计算损失 L 关于logits $\mathbf{z}$ 的梯度。

**前向传播**:

$\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}$

$\hat{\mathbf{y}} = \text{softmax}(\mathbf{z})$

$L = -\sum_{k=1}^{K} y_k \log \hat{y}_k$

**反向传播**（链式法则）:

$\frac{\partial L}{\partial z_i} = \sum_{k=1}^{K} \frac{\partial L}{\partial \hat{y}_k} \cdot \frac{\partial \hat{y}_k}{\partial z_i}$

**步骤1**: 计算 $\frac{\partial L}{\partial \hat{y}_k}$

$\frac{\partial L}{\partial \hat{y}_k} = \frac{\partial}{\partial \hat{y}_k}\left(-\sum_j y_j \log \hat{y}_j\right) = -\frac{y_k}{\hat{y}_k}$

**步骤2**: 使用Softmax的导数

$\frac{\partial \hat{y}_k}{\partial z_i} = \hat{y}_k(\delta_{ki} - \hat{y}_i)$

**步骤3**: 代入链式法则

$$\begin{align}
\frac{\partial L}{\partial z_i} &= \sum_{k=1}^{K} \left(-\frac{y_k}{\hat{y}_k}\right) \cdot \hat{y}_k(\delta_{ki} - \hat{y}_i) \\
&= -\sum_{k=1}^{K} y_k (\delta_{ki} - \hat{y}_i) \\
&= -\sum_{k=1}^{K} y_k \delta_{ki} + \sum_{k=1}^{K} y_k \hat{y}_i \\
&= -y_i + \hat{y}_i \sum_{k=1}^{K} y_k \\
&= -y_i + \hat{y}_i \cdot 1 \quad \text{(因为 $\sum_k y_k = 1$)} \\
&= \hat{y}_i - y_i
\end{align}$$

**神奇的结果**:

$\boxed{\frac{\partial L}{\partial \mathbf{z}} = \hat{\mathbf{y}} - \mathbf{y}}$

#### 3.3.2 梯度的向量形式

**关于logits的梯度**:

$\nabla_{\mathbf{z}} L = \hat{\mathbf{y}} - \mathbf{y}$

**关于权重矩阵的梯度**:

$\nabla_{\mathbf{W}} L = \frac{\partial L}{\partial \mathbf{z}} \cdot \frac{\partial \mathbf{z}}{\partial \mathbf{W}} = (\hat{\mathbf{y}} - \mathbf{y}) \mathbf{x}^T$

对于批量数据：

$\nabla_{\mathbf{W}} L = \frac{1}{n}(\hat{\mathbf{Y}} - \mathbf{Y})\mathbf{X}^T$

**关于偏置的梯度**:

$\nabla_{\mathbf{b}} L = \frac{1}{n}\sum_{i=1}^{n}(\hat{\mathbf{y}}^{(i)} - \mathbf{y}^{(i)})$

#### 3.3.3 为什么这个梯度如此优雅？

**三个原因**:

1\. **形式简洁**: $\nabla_{\mathbf{z}} L = \hat{\mathbf{y}} - \mathbf{y}$，只是预测减去真实标签

* 没有复杂的指数、对数或分式
* 易于理解和实现
* 计算高效

2\. **误差驱动**: 梯度正比于预测误差

* 误差越大，梯度越大，更新越快
* 预测正确时（ $\hat{\mathbf{y}} = \mathbf{y}$），梯度为零
* 自适应学习速度

3\. **避免梯度消失**: 即使Softmax饱和，梯度仍然有意义

* 对比Sigmoid+MSE：在饱和区梯度接近0，学习停滞
* Softmax+交叉熵：梯度始终与误差成正比
* 这是深度学习能够训练的关键

**数学原因**: Softmax导数中的 $\hat{y}_k$ 项与交叉熵导数中的 $\frac{1}{\hat{y}_k}$ 项 **恰好抵消。**

### 3.4 为什么不用MSE？

#### 3.4.1 MSE用于分类的问题

**MSE定义**（用于分类）:

$L_{MSE} = \frac{1}{2}\sum_{k=1}^{K}(\hat{y}_k - y_k)^2$

**与交叉熵对比**:

$L_{CE} = -\sum_{k=1}^{K} y_k \log \hat{y}_k$

这个实验对比了交叉熵和MSE在二分类问题上的表现

**左图 (损失函数对比)**:

* **绿色虚线**: 真实类别概率为1的位置
* **红色曲线 (交叉熵)**: $L_{CE} = -\log \hat{y}$
  * 当 $\hat{y} \to 0$ 时，损失 $\to \infty$（严厉惩罚）
  * 当 $\hat{y} \to 1$ 时，损失 $\to 0$（完美预测）
  * 曲线呈指数增长

\- **蓝色曲线 (MSE)**: $L_{MSE} = \frac{1}{2}(\hat{y} - 1)^2$

* 增长较缓慢，呈二次增长
* 对严重错误的惩罚不够

**右图 (梯度对比)**:

* **交叉熵梯度**: $\frac{\partial L_{CE}}{\partial \hat{y}} = -\frac{1}{\hat{y}}$
  * 当 $\hat{y}$ 很小时（预测错误），梯度很大
  * 快速纠正错误，学习效率高
* **MSE梯度**: $\frac{\partial L_{MSE}}{\partial \hat{y}} = \hat{y} - 1$
  * 梯度与误差线性相关
  * 当 $\hat{y}$ 很小时，梯度也小，学习慢

#### 3.4.2 Softmax + MSE的梯度消失问题

**问题**: 如果使用MSE损失，梯度会是什么？

**MSE损失**:

$L_{MSE} = \frac{1}{2}\sum_{k=1}^{K}(\hat{y}_k - y_k)^2$

**关于logits的梯度**（使用链式法则）:

$\frac{\partial L_{MSE}}{\partial z_i} = \sum_k \frac{\partial L_{MSE}}{\partial \hat{y}_k} \cdot \frac{\partial \hat{y}_k}{\partial z_i} = \sum_k (\hat{y}_k - y_k) \cdot \hat{y}_k(\delta_{ki} - \hat{y}_i)$

这个表达式 **非常复杂**，且包含 $\hat{y}_k$ 项，导致：

**梯度消失**: 当Softmax饱和时（某个 $\hat{y}_k \approx 1$，其他 $\approx 0$），如果预测错误：

* 正确类别的 $\hat{y}_c \approx 0$
* 梯度中包含 $\hat{y}_c$ 项，导致梯度接近0
* 学习停滞，无法纠正错误

**对比交叉熵**: $\nabla_{\mathbf{z}} L_{CE} = \hat{\mathbf{y}} - \mathbf{y}$

* 不包含 $\hat{y}_k$ 的乘积项
* 即使Softmax饱和，梯度仍然与误差成正比
* 学习不会停滞

#### 3.4.3 概率意义上的最优性

**交叉熵**: 等价于最大似然估计

* 有明确的概率解释
* 最小化预测分布和真实分布的KL散度
* 理论上最优

**MSE**: 假设高斯噪声

* 适用于回归问题（连续输出）
* 不适合分类问题（离散输出）
* 没有概率意义

### 5.1 完整的Softmax回归类

```python
import numpy as np

class SoftmaxRegression:
    """Softmax回归模型：从零实现

    模型: z = Wx + b, ŷ = softmax(z)
    损失: L = -sum(y * log(ŷ)) (交叉熵)
    优化: 梯度下降
    """

    def __init__(self, learning_rate=0.01, n_iterations=1000, n_classes=None):
        """
        参数:
            learning_rate: 学习率 η
            n_iterations: 最大迭代次数
            n_classes: 类别数量 K
        """
        self.lr = learning_rate
        self.n_iterations = n_iterations
        self.n_classes = n_classes
        self.W = None  # 权重矩阵 (K, d)
        self.b = None  # 偏置向量 (K, 1)
        self.losses = []  # 记录训练损失
        self.accuracies = []  # 记录训练准确率

    def _initialize_parameters(self, n_features):
        """初始化参数

        参数:
            n_features: 特征维度 d
        """
        # 权重矩阵：Xavier初始化
        std = np.sqrt(2.0 / (n_features + self.n_classes))
        self.W = np.random.randn(self.n_classes, n_features) * std

        # 偏置向量：初始化为0
        self.b = np.zeros((self.n_classes, 1))

    def softmax(self, z):
        """Softmax函数（数值稳定版本）

        softmax(z)_k = exp(z_k) / sum(exp(z_j))

        参数:
            z: logits (K, n)
        返回:
            probs: 概率分布 (K, n)
        """
        # 减去最大值，避免数值溢出
        z_shifted = z - np.max(z, axis=0, keepdims=True)

        # 计算exp
        exp_z = np.exp(z_shifted)

        # 归一化
        probs = exp_z / np.sum(exp_z, axis=0, keepdims=True)

        return probs

    def _one_hot_encode(self, y):
        """将类别标签转换为one-hot编码

        参数:
            y: 类别标签 (n,) 或 (n, 1), 取值 0, 1, ..., K-1
        返回:
            Y: one-hot矩阵 (K, n)
        """
        if y.ndim == 2:
            y = y.flatten()

        n_samples = y.shape[0]
        Y = np.zeros((self.n_classes, n_samples))
        Y[y, np.arange(n_samples)] = 1

        return Y

    def _compute_loss(self, Y_pred, Y_true):
        """计算交叉熵损失

        L = -(1/n) sum(Y_true * log(Y_pred))

        参数:
            Y_pred: 预测概率 (K, n)
            Y_true: one-hot标签 (K, n)
        返回:
            loss: 标量损失值
        """
        n_samples = Y_true.shape[1]

        # 交叉熵（加小常数避免log(0)）
        loss = -(1 / n_samples) * np.sum(Y_true * np.log(Y_pred + 1e-10))

        return loss

    def _compute_gradients(self, X, Y_pred, Y_true):
        """计算梯度

        ∇W L = (1/n) (ŷ - y) X^T
        ∇b L = (1/n) sum(ŷ - y, axis=1)

        参数:
            X: 特征矩阵 (d, n)
            Y_pred: 预测概率 (K, n)
            Y_true: one-hot标签 (K, n)
        返回:
            grad_W: 权重梯度 (K, d)
            grad_b: 偏置梯度 (K, 1)
        """
        n_samples = X.shape[1]

        # 梯度：ŷ - y（优雅的形式！）
        error = Y_pred - Y_true  # (K, n)

        # 权重梯度
        grad_W = (1 / n_samples) * error @ X.T  # (K, n) @ (n, d) = (K, d)

        # 偏置梯度
        grad_b = (1 / n_samples) * np.sum(error, axis=1, keepdims=True)  # (K, 1)

        return grad_W, grad_b

    def _compute_accuracy(self, Y_pred, Y_true):
        """计算准确率

        参数:
            Y_pred: 预测概率 (K, n)
            Y_true: one-hot标签 (K, n)
        返回:
            accuracy: 准确率
        """
        # 预测类别：概率最大的类
        y_pred_labels = np.argmax(Y_pred, axis=0)
        y_true_labels = np.argmax(Y_true, axis=0)

        accuracy = np.mean(y_pred_labels == y_true_labels)

        return accuracy

    def fit(self, X, y, verbose=True):
        """训练模型

        参数:
            X: 训练特征 (n, d)
            y: 训练标签 (n,) 或 (n, 1), 取值 0, 1, ..., K-1
        """
        # 转置为 (d, n) 格式（方便矩阵运算）
        X = X.T

        # 确定类别数
        if self.n_classes is None:
            self.n_classes = len(np.unique(y))

        # One-hot编码
        Y = self._one_hot_encode(y)  # (K, n)

        n_features = X.shape[0]

        # 初始化参数
        self._initialize_parameters(n_features)

        # 梯度下降
        for iteration in range(self.n_iterations):
            # 前向传播
            z = self.W @ X + self.b  # (K, d) @ (d, n) + (K, 1) = (K, n)
            Y_pred = self.softmax(z)  # (K, n)

            # 计算损失和准确率
            loss = self._compute_loss(Y_pred, Y)
            accuracy = self._compute_accuracy(Y_pred, Y)

            self.losses.append(loss)
            self.accuracies.append(accuracy)

            # 计算梯度
            grad_W, grad_b = self._compute_gradients(X, Y_pred, Y)

            # 更新参数
            self.W -= self.lr * grad_W
            self.b -= self.lr * grad_b

            # 打印进度
            if verbose and (iteration + 1) % 100 == 0:
                print(f'Iteration {iteration+1}/{self.n_iterations}, '
                      f'Loss: {loss:.4f}, Accuracy: {accuracy:.4f}')

        return self

    def predict_proba(self, X):
        """预测概率

        参数:
            X: 特征矩阵 (n, d)
        返回:
            probs: 概率矩阵 (n, K)
        """
        X = X.T  # (d, n)
        z = self.W @ X + self.b  # (K, n)
        Y_pred = self.softmax(z)  # (K, n)
        return Y_pred.T  # (n, K)

    def predict(self, X):
        """预测类别

        参数:
            X: 特征矩阵 (n, d)
        返回:
            y_pred: 预测类别 (n,)
        """
        probs = self.predict_proba(X)  # (n, K)
        y_pred = np.argmax(probs, axis=1)
        return y_pred

    def score(self, X, y):
        """计算准确率

        参数:
            X: 特征矩阵 (n, d)
            y: 真实标签 (n,)
        返回:
            accuracy: 准确率
        """
        y_pred = self.predict(X)
        accuracy = np.mean(y_pred == y.flatten())
        return accuracy
```

def softmax_with_temperature(z, temperature=1.0):
    """带温度参数的Softmax

    参数:
        z: logits (K, n)
        temperature: 温度参数 T > 0
    返回:
        probs: 概率分布 (K, n)
    """
    # 除以温度
    z_scaled = z / temperature

    # 数值稳定的softmax
    z_shifted = z_scaled - np.max(z_scaled, axis=0, keepdims=True)
    exp_z = np.exp(z_shifted)
    probs = exp_z / np.sum(exp_z, axis=0, keepdims=True)

    return probs

    probs = softmax_with_temperature(logits, temperature=T)
    print(f'T={T}: {probs.flatten()}')
