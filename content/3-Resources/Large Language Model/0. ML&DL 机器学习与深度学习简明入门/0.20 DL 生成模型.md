### 6.1 变分自编码器 (VAE)

**ELBO 目标函数**：

$\log p(x) \geq \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{KL}(q(z|x) \| p(z))$

**重参数化技巧**：

$z = \mu + \sigma \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$

#### 理论推导：ELBO 的推导

**目标**：最大化边缘似然 $\log p(x)$（困难，需要积分）

**变分推断**：引入近似后验 $q(z|x)$

**Jensen 不等式**：

$\log p(x) = \log \int p(x, z) dz = \log \mathbb{E}_{q(z|x)}\left[\frac{p(x, z)}{q(z|x)}\right] \geq \mathbb{E}_{q(z|x)}\left[\log \frac{p(x, z)}{q(z|x)}\right]$

**展开 ELBO**：

$\mathcal{L} = \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{KL}(q(z|x) \| p(z))$

**两项解释**：

1\. **重构项**： $\mathbb{E}[\log p(x|z)]$（解码器质量）

2\. **正则项**： $D_{KL}(q \| p)$（编码器接近先验）

#### 重参数化技巧的必要性

**问题**： $z \sim q(z|x)$ 是随机采样，无法反向传播。

**解决**：将随机性外化

$z = \mu(x) + \sigma(x) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$

现在梯度可以通过 $\mu$ 和 $\sigma$ 反向传播！

#### 核心实现

```python
class VAE(Module):
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super().__init__()
        # Encoder
        self.fc1 = Linear(input_dim, hidden_dim)
        self.fc_mu = Linear(hidden_dim, latent_dim)
        self.fc_logvar = Linear(hidden_dim, latent_dim)

        # Decoder
        self.fc3 = Linear(latent_dim, hidden_dim)
        self.fc4 = Linear(hidden_dim, input_dim)

    def encode(self, x):
        h = relu(self.fc1(x))
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar

    def reparameterize(self, mu, logvar):
        """重参数化技巧"""
        std = np.exp(0.5 * logvar)
        eps = np.random.randn(*std.shape)
        z = mu + std * eps
        return z

    def decode(self, z):
        h = relu(self.fc3(z))
        return sigmoid(self.fc4(h))

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        x_recon = self.decode(z)
        return x_recon, mu, logvar

def vae_loss(x, x_recon, mu, logvar):
    """ELBO 损失"""
    # 重构损失（负对数似然）
    recon_loss = np.sum((x - x_recon) ** 2)
    # KL 散度
    kl_loss = -0.5 * np.sum(1 + logvar - mu**2 - np.exp(logvar))
    return recon_loss + kl_loss

def relu(x):
    return np.maximum(0, x)
```

### 6.2 扩散模型 (Diffusion)

**前向扩散过程**：

$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t I)$

**反向去噪过程**：

$p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t))$

**训练目标**：

$L = \mathbb{E}_{t, x_0, \epsilon} \left[ \| \epsilon - \epsilon_\theta(x_t, t) \|^2 \right]$

#### 理论推导：前向过程的闭式解

**递推关系**：

$x_t = \sqrt{1-\beta_t} x_{t-1} + \sqrt{\beta_t} \epsilon_{t-1}$

**关键性质**：可以直接从 $x_0$ 采样 $x_t$（无需逐步）

令 $\alpha_t = 1 - \beta_t$， $\bar{\alpha}_t = \prod_{i=1}^{t} \alpha_i$：

$x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$

**证明**（归纳法）：利用高斯分布的性质，两个独立高斯噪声的和仍是高斯。

#### 反向过程与贝叶斯公式

**目标**：学习 $p(x_{t-1} | x_t)$（去噪）

**贝叶斯定理**：

$p(x_{t-1} | x_t, x_0) = \frac{q(x_t | x_{t-1}) q(x_{t-1} | x_0)}{q(x_t | x_0)}$

通过配方可得均值和方差的闭式解，训练神经网络 $\epsilon_\theta$ 预测噪声。

**简化目标**：预测噪声 $\epsilon$ 等价于预测均值（数学上可证明等价）。

#### 核心实现

```python
class DiffusionModel:
    def __init__(self, model, timesteps=1000):
        self.model = model  # 噪声预测网络（如 UNet）
        self.timesteps = timesteps

        # 定义噪声调度
        self.betas = np.linspace(1e-4, 0.02, timesteps)
        self.alphas = 1 - self.betas
        self.alphas_cumprod = np.cumprod(self.alphas)

    def q_sample(self, x0, t, noise=None):
        """前向扩散：从 x0 直接采样 x_t"""
        if noise is None:
            noise = np.random.randn(*x0.shape)

        sqrt_alphas_cumprod_t = np.sqrt(self.alphas_cumprod[t])
        sqrt_one_minus_alphas_cumprod_t = np.sqrt(1 - self.alphas_cumprod[t])

        return sqrt_alphas_cumprod_t * x0 + sqrt_one_minus_alphas_cumprod_t * noise

    def p_sample(self, x_t, t):
        """反向去噪：从 x_t 采样 x_{t-1}"""
        # 预测噪声
        eps_pred = self.model(x_t, t)

        # 计算均值
        alpha_t = self.alphas[t]
        alpha_cumprod_t = self.alphas_cumprod[t]
        beta_t = self.betas[t]

        mean = (x_t - beta_t / np.sqrt(1 - alpha_cumprod_t) * eps_pred) / np.sqrt(alpha_t)

        # 添加噪声（t > 0 时）
        if t > 0:
            noise = np.random.randn(*x_t.shape)
            sigma_t = np.sqrt(beta_t)
            return mean + sigma_t * noise
        else:
            return mean

    def sample(self, shape):
        """从噪声生成样本"""
        x_t = np.random.randn(*shape)

        for t in reversed(range(self.timesteps)):
            x_t = self.p_sample(x_t, t)

        return x_t

    def train_loss(self, x0):
        """训练损失：预测噪声"""
        t = np.random.randint(0, self.timesteps)
        noise = np.random.randn(*x0.shape)
        x_t = self.q_sample(x0, t, noise)

        noise_pred = self.model(x_t, t)
        loss = np.mean((noise - noise_pred) ** 2)
        return loss
```
