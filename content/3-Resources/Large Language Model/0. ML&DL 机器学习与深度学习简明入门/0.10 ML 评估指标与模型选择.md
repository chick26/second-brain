> > "In God we trust; all others must bring data." — W. Edwards Deming
> 选择正确的评估指标是机器学习成功的关键。不同的指标反映了对模型性能的不同关注点，错误的指标可能导致模型在实际应用中失败

# 0.10.1 评估指标的问题

**为什么准确率不够？** 考虑一个垃圾邮件检测系统：

* 总共 1000 封邮件
* 990 封正常邮件，10 封垃圾邮件

如果模型 **永远预测"正常"**：

* 准确率 = 990/1000 = **99%**！

但这个模型 **完全没用** —— 它漏掉了所有垃圾邮件。

**不同错误的代价不同：**

| 应用场景 | 更严重的错误 | 原因 |
| ---- | --------- | ------ |
| 癌症检测 | 漏诊 (FN) | 错过治疗时机 |
| 垃圾邮件 | 误判 (FP) | 重要邮件被删 |
| 欺诈检测 | 漏检 (FN) | 资金损失 |
| 司法系统 | 冤假错案 (FP) | 无辜者入狱 |

# 0.10.2 混淆矩阵 (Confusion Matrix)

对于二分类问题，混淆矩阵是一个 $2 \times 2$ 的矩阵：

$\mathbf{C} = \begin{pmatrix} TP & FN \\ FP & TN \end{pmatrix}$

其中：

* **TP (True Positive)**：正确预测为正类
* **TN (True Negative)**：正确预测为负类
* **FP (False Positive)**：错误预测为正类（第一类错误，"虚报"）
* **FN (False Negative)**：错误预测为负类（第二类错误，"漏报"）

```python
def compute_confusion_matrix(y_true: np.ndarray, y_pred: np.ndarray) -> np.ndarray:
    """
    计算混淆矩阵。

    Parameters
    ----------
    y_true : np.ndarray
        真实标签 (0 或 1)
    y_pred : np.ndarray
        预测标签 (0 或 1)

    Returns
    -------
    np.ndarray, shape (2, 2)
        混淆矩阵 [[TP, FN], [FP, TN]]
    """
    # 计算四个基本量
    tp = np.sum((y_true == 1) & (y_pred == 1))
    tn = np.sum((y_true == 0) & (y_pred == 0))
    fp = np.sum((y_true == 0) & (y_pred == 1))
    fn = np.sum((y_true == 1) & (y_pred == 0))

    return np.array([[tp, fn], [fp, tn]])
```

# 0.10.3 评估指标

* **准确率 (Accuracy)**

$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$

**问题**：在不平衡数据集上可能误导。

* **精确率 (Precision)**

$\text{Precision} = \frac{TP}{TP + FP}$

**含义**：预测为正的样本中，有多少是真正的正样本？

**关注**：减少 FP（假阳性）

* **召回率 (Recall / Sensitivity / TPR)**

$\text{Recall} = \frac{TP}{TP + FN}$

**含义**：所有正样本中，有多少被正确识别？

**关注**：减少 FN（假阴性）

* **F1 分数**

$F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$

**含义**：精确率和召回率的调和平均数

```python
def compute_metrics(y_true: np.ndarray, y_pred: np.ndarray) -> dict:
    """
    计算所有分类指标。

    Parameters
    ----------
    y_true : np.ndarray
        真实标签
    y_pred : np.ndarray
        预测标签

    Returns
    -------
    dict
        包含所有指标的字典
    """
    cm = compute_confusion_matrix(y_true, y_pred)
    tp, fn = cm[0]
    fp, tn = cm[1]

    # 基本指标
    accuracy = (tp + tn) / (tp + tn + fp + fn)

    # 精确率（处理除零）
    precision = tp / (tp + fp) if (tp + fp) > 0 else 0

    # 召回率
    recall = tp / (tp + fn) if (tp + fn) > 0 else 0

    # F1 分数
    f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0

    # 特异度 (Specificity)
    specificity = tn / (tn + fp) if (tn + fp) > 0 else 0

    # 假阳性率 (FPR)
    fpr = fp / (fp + tn) if (fp + tn) > 0 else 0

    return {
        'accuracy': accuracy,
        'precision': precision,
        'recall': recall,
        'f1': f1,
        'specificity': specificity,
        'fpr': fpr,
        'confusion_matrix': cm
    }
```

关键洞察：

* 提高阈值 → 更高精确率，更低召回率（更保守，漏检增加）
* 降低阈值 → 更低精确率，更高召回率（更激进，误报增加）
* 最优 F1 阈值: 0.713
* **F-beta 分数：** $F_\beta = (1 + \beta^2) \cdot \frac{\text{Precision} \cdot \text{Recall}}{\beta^2 \cdot \text{Precision} + \text{Recall}}$
  * $\beta < 1$：更重视精确率（如垃圾邮件检测）
  * $\beta = 1$：精确率和召回率同等重要（F1）
  * $\beta > 1$：更重视召回率（如癌症检测）

```python
def f_beta_score(precision: float, recall: float, beta: float = 1.0) -> float:
    """
    计算 F-beta 分数。

    Parameters
    ----------
    precision : float
        精确率
    recall : float
        召回率
    beta : float
        beta 参数

    Returns
    -------
    float
        F-beta 分数
    """
    if precision + recall == 0:
        return 0.0
    beta_sq = beta ** 2
    return (1 + beta_sq) * precision * recall / (beta_sq * precision + recall)
```

* β=0.5 偏向精确率，分数较高
* β=2.0 偏向召回率，分数较低

# 0.10.4 ROC 曲线与 AUC

**ROC (Receiver Operating Characteristic)** 曲线展示了在不同阈值下：

* **x 轴**：假阳性率 (FPR) = FP / (FP + TN)
* **y 轴**：真阳性率 (TPR) = TP / (TP + FN) = Recall

**AUC (Area Under the Curve)**：ROC 曲线下的面积

* AUC = 1.0：完美分类器
* AUC = 0.5：随机猜测
* AUC < 0.5：比随机还差（把预测反过来就好）

```python
def compute_roc_curve(y_true: np.ndarray, y_scores: np.ndarray,
                       n_thresholds: int = 100) -> dict:
    """
    计算 ROC 曲线。

    Parameters
    ----------
    y_true : np.ndarray
        真实标签
    y_scores : np.ndarray
        预测分数
    n_thresholds : int
        阈值数量

    Returns
    -------
    dict
        包含 fpr, tpr, thresholds 的字典
    """
    # 使用排序后的分数作为阈值
    thresholds = np.sort(np.unique(y_scores))[::-1]
    # 添加边界
    thresholds = np.concatenate([[thresholds[0] + 1], thresholds, [thresholds[-1] - 1]])

    fprs = []
    tprs = []

    for thresh in thresholds:
        y_pred = (y_scores >= thresh).astype(int)
        m = compute_metrics(y_true, y_pred)
        fprs.append(m['fpr'])
        tprs.append(m['recall'])

    return {
        'fpr': np.array(fprs),
        'tpr': np.array(tprs),
        'thresholds': thresholds
    }

def compute_auc(fpr: np.ndarray, tpr: np.ndarray) -> float:
    """
    计算 AUC（使用梯形法则）。

    Parameters
    ----------
    fpr : np.ndarray
        假阳性率数组
    tpr : np.ndarray
        真阳性率数组

    Returns
    -------
    float
        AUC 值
    """
    # 按 FPR 排序
    sorted_indices = np.argsort(fpr)
    fpr_sorted = fpr[sorted_indices]
    tpr_sorted = tpr[sorted_indices]

    # 梯形法则积分 (numpy 2.x 使用 trapezoid 替代 trapz)
    auc = np.trapezoid(tpr_sorted, fpr_sorted)

    return auc
```

# 0.10.5 交叉验证 (Cross-Validation)

**为什么需要交叉验证？**

* **问题**：单次训练-测试划分可能导致：
  * 估计方差大（取决于划分的运气）
  * 浪费数据（一部分数据只用于测试）
* **解决方案**：K-Fold 交叉验证

## K-Fold 交叉验证

1. 将数据分成 K 份
2. 每次用 K-1 份训练，1 份测试
3) 重复 K 次，每份轮流作为测试集
4) 取 K 次结果的平均

```python
def k_fold_split(n_samples: int, n_folds: int = 5, shuffle: bool = True,
                  random_state: int = None) -> list:
    """
    生成 K-Fold 交叉验证的索引。

    Parameters
    ----------
    n_samples : int
        样本总数
    n_folds : int
        折数
    shuffle : bool
        是否打乱
    random_state : int, optional
        随机种子

    Returns
    -------
    list of tuples
        每个元素是 (train_indices, val_indices)
    """
    if random_state is not None:
        np.random.seed(random_state)

    indices = np.arange(n_samples)
    if shuffle:
        np.random.shuffle(indices)

    fold_sizes = np.full(n_folds, n_samples // n_folds)
    fold_sizes[:n_samples % n_folds] += 1  # 分配余数

    folds = []
    current = 0

    for fold_size in fold_sizes:
        val_indices = indices[current:current + fold_size]
        train_indices = np.concatenate([indices[:current], indices[current + fold_size:]])
        folds.append((train_indices, val_indices))
        current += fold_size

    return folds
```

K-Fold 交叉验证优点：

1. 每个样本都被用于验证一次
2. 每个样本被用于训练 K-1 次
3) 充分利用数据，估计更稳定

```python
def cross_validate(X: np.ndarray, y: np.ndarray, model_class,
                    n_folds: int = 5, metric: str = 'accuracy',
                    **model_params) -> dict:
    """
    执行 K-Fold 交叉验证。

    Parameters
    ----------
    X : np.ndarray
        特征数据
    y : np.ndarray
        标签
    model_class : class
        模型类
    n_folds : int
        折数
    metric : str
        评估指标

    Returns
    -------
    dict
        包含各折分数和统计信息的字典
    """
    n_samples = len(X)
    folds = k_fold_split(n_samples, n_folds, shuffle=True, random_state=42)

    scores = []

    for fold_idx, (train_idx, val_idx) in enumerate(folds):
        X_train, X_val = X[train_idx], X[val_idx]
        y_train, y_val = y[train_idx], y[val_idx]

        # 训练模型
        model = model_class(**model_params)
        model.fit(X_train, y_train)

        # 预测
        y_pred = model.predict(X_val)

        # 计算指标
        metrics_result = compute_metrics(y_val, y_pred)
        scores.append(metrics_result[metric])

    return {
        'scores': np.array(scores),
        'mean': np.mean(scores),
        'std': np.std(scores),
        'n_folds': n_folds
    }
```

## 分层 K-Fold (Stratified K-Fold)

在不平衡数据集上，普通 K-Fold 可能导致某些折没有足够的正类样本

**分层 K-Fold**：保证每折中正负类比例与整体一致

```python
def stratified_k_fold_split(y: np.ndarray, n_folds: int = 5,
                             random_state: int = None) -> list:
    """
    分层 K-Fold 划分。

    Parameters
    ----------
    y : np.ndarray
        标签
    n_folds : int
        折数
    random_state : int, optional
        随机种子

    Returns
    -------
    list of tuples
        每个元素是 (train_indices, val_indices)
    """
    if random_state is not None:
        np.random.seed(random_state)

    # 按类别分组
    classes = np.unique(y)
    class_indices = {c: np.where(y == c)[0] for c in classes}

    # 打乱每个类别的索引
    for c in classes:
        np.random.shuffle(class_indices[c])

    # 为每个类别分配到各折
    fold_indices = [[] for _ in range(n_folds)]

    for c in classes:
        indices = class_indices[c]
        n_per_fold = len(indices) // n_folds
        remainder = len(indices) % n_folds

        current = 0
        for fold_idx in range(n_folds):
            fold_size = n_per_fold + (1 if fold_idx < remainder else 0)
            fold_indices[fold_idx].extend(indices[current:current + fold_size])
            current += fold_size

    # 转换为 (train, val) 元组
    folds = []
    all_indices = np.arange(len(y))

    for fold_idx in range(n_folds):
        val_indices = np.array(fold_indices[fold_idx])
        train_indices = np.setdiff1d(all_indices, val_indices)
        folds.append((train_indices, val_indices))

    return folds
```

# 0.10.6 校准曲线 (Calibration Curve)

* **什么是概率校准？**

一个校准良好的分类器：当它预测 "70% 概率是正类" 时，在所有这样的预测中，确实有 70% 是正类。

$P(Y=1 | \hat{P} = p) = p$

* **校准曲线**
  * **x 轴**：预测概率（分箱后的平均）
  * **y 轴**：该箱中的真实正类比例
  * **完美校准**：沿对角线

```python
def compute_calibration_curve(y_true: np.ndarray, y_proba: np.ndarray,
                               n_bins: int = 10) -> dict:
    """
    计算校准曲线。

    Parameters
    ----------
    y_true : np.ndarray
        真实标签
    y_proba : np.ndarray
        预测概率
    n_bins : int
        分箱数量

    Returns
    -------
    dict
        包含 mean_predicted_value, fraction_of_positives, bin_counts
    """
    bin_edges = np.linspace(0, 1, n_bins + 1)

    mean_predicted = []
    fraction_positives = []
    bin_counts = []

    for i in range(n_bins):
        # 找出在该箱内的样本
        in_bin = (y_proba >= bin_edges[i]) & (y_proba < bin_edges[i + 1])
        if i == n_bins - 1:  # 最后一个箱包含右边界
            in_bin = (y_proba >= bin_edges[i]) & (y_proba <= bin_edges[i + 1])

        if np.sum(in_bin) > 0:
            mean_predicted.append(np.mean(y_proba[in_bin]))
            fraction_positives.append(np.mean(y_true[in_bin]))
            bin_counts.append(np.sum(in_bin))

    return {
        'mean_predicted_value': np.array(mean_predicted),
        'fraction_of_positives': np.array(fraction_positives),
        'bin_counts': np.array(bin_counts)
    }
```

## Brier 分数

$\text{Brier Score} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{p}_i)^2$

* 越低越好（0 是完美）
* 综合考虑准确性和校准

```python
def brier_score(y_true: np.ndarray, y_proba: np.ndarray) -> float:
    """
    计算 Brier 分数。

    Parameters
    ----------
    y_true : np.ndarray
        真实标签
    y_proba : np.ndarray
        预测概率

    Returns
    -------
    float
        Brier 分数
    """
    return np.mean((y_true - y_proba) ** 2)
```

# 对于以下场景，选择最重要的评估指标并解释原因

场景1：癌症筛查系统

  最重要指标：召回率 (Recall)
  原因：漏诊 (FN) 的代价极高，可能导致延误治疗。
        宁可有些假阳性（再做进一步检查），也不能漏掉真正的患者。

场景2：垃圾邮件过滤

  最重要指标：精确率 (Precision)
  原因：误判正常邮件为垃圾 (FP) 可能导致重要邮件丢失。
        宁可让一些垃圾邮件漏网，也不能误删重要邮件。

场景3：欺诈交易检测

  最重要指标：F1 或 AUC
  原因：需要在召回率（检测到欺诈）和精确率（减少误报）之间平衡。
        误报会影响用户体验，漏报会造成损失。

场景4：推荐系统

  最重要指标：AUC 或 NDCG
  原因：关注排序质量而非具体阈值的预测。
        好的推荐应该把用户可能喜欢的内容排在前面。

场景5：自动驾驶障碍物检测

  最重要指标：召回率 (Recall)
  原因：漏检 (FN) 可能导致严重事故。
        安全是最高优先级，误报只会导致不必要的刹车。

# 手动计算 AUC

```python
# 验证：通过采样估计 AUC
def estimate_auc_by_sampling(y_true, y_scores, n_pairs=10000):
    """
    通过随机采样估计 AUC。
    """
    pos_scores = y_scores[y_true == 1]
    neg_scores = y_scores[y_true == 0]

    count = 0
    for _ in range(n_pairs):
        pos_sample = np.random.choice(pos_scores)
        neg_sample = np.random.choice(neg_scores)
        if pos_sample > neg_sample:
            count += 1
        elif pos_sample == neg_sample:
            count += 0.5

    return count / n_pairs

# 比较两种计算方法
roc = compute_roc_curve(y_true, y_scores)
auc_trapz = compute_auc(roc['fpr'], roc['tpr'])
auc_sample = estimate_auc_by_sampling(y_true, y_scores)
```

AUC 等于：随机选取一个正样本和一个负样本，正样本的预测分数高于负样本的概率。

数学表示：

AUC = P(score(positive) > score(negative))

    \= E\[I(s+ > s-)]

其中 I 是指示函数。

验证：

  梯形法则计算的 AUC: 0.9711
  采样估计的 AUC: 0.9716
  两者应该接近！

# 总结

1. **混淆矩阵**：TP, TN, FP, FN 是所有指标的基础
2. **核心指标**：
   * 精确率：预测为正中真正为正的比例
   * 召回率：真正为正中被正确预测的比例
   * F1：精确率和召回率的调和平均
3) **ROC 和 AUC**：
   * ROC 曲线展示不同阈值下的 TPR-FPR 权衡
   * AUC 是阈值无关的综合性能指标
4) **交叉验证**：
   * K-Fold CV 提供稳定的性能估计
   * 分层 K-Fold 保持类别比例
5. **概率校准**：
   * 校准曲线检验概率预测的可靠性
   * Brier 分数综合评估准确性和校准
> "选择评估指标时，首先考虑不同错误的代价，再选择相应的指标。"
