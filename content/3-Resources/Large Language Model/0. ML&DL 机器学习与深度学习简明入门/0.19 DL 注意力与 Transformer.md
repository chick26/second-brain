### 5.1 自注意力机制

**Scaled Dot-Product Attention**：

$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$

**Multi-Head Attention**：

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) W^O \\
\text{where } \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

#### 理论推导：Attention 作为软字典查询

**直觉**：Attention 是可微分的字典查询操作。

给定查询 $q$，在键值对 $(K, V)$ 中查找：

1. 计算相似度：$\text{score}_i = q \cdot k_i$
2. 归一化权重：$\alpha_i = \frac{\exp(\text{score}_i)}{\sum_j \exp(\text{score}_j)}$
3) 加权求和：$\text{output} = \sum_i \alpha_i v_i$

**矩阵形式**（批量查询）：

$\text{Attention}(Q, K, V) = \text{softmax}(QK^T) V$

#### 理论推导： $\sqrt{d_k}$ **缩放的必要性**

**问题**：为什么要除以 $\sqrt{d_k}$？

**方差分析**：

假设 $q, k \in \mathbb{R}^{d_k}$ 的元素独立同分布， $q_i, k_i \sim \mathcal{N}(0, 1)$。

点积 $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的方差：

$\text{Var}(q \cdot k) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = \sum_{i=1}^{d_k} \text{Var}(q_i) \text{Var}(k_i) = d_k$

**后果**：当 $d_k$ 很大时， $q \cdot k$ 的方差很大，导致 softmax 进入饱和区（梯度消失）。

**解决方案**：归一化点积

$\frac{q \cdot k}{\sqrt{d_k}} \quad \Rightarrow \quad \text{Var}\left(\frac{q \cdot k}{\sqrt{d_k}}\right) = \frac{d_k}{d_k} = 1$

**数值验证**： $d_k = 64$

* 无缩放： $q \cdot k \in [-50, 50] → softmax$ 饱和
* 有缩放： $\frac{q \cdot k}{\sqrt{64}} \in [-6, 6] → softmax$ 平滑

#### Multi-Head Attention 的表达能力

**单头局限**：只能学习一种注意力模式（如：关注相邻词）

**多头优势**：不同头学习不同模式

* Head 1：关注语法关系（主谓）
* Head 2：关注语义关系（同义词）
* Head 3：关注位置关系（距离）

**参数量**：

$\text{Params} = h \times (3 d_{\text{model}} \times \frac{d_{\text{model}}}{h}) + d_{\text{model}}^2 = 4 d_{\text{model}}^2$

与单头相同，但表达能力更强！

#### 复杂度分析

**时间复杂度**： $O(n^2 d)$

* $QK^T$：$O(n^2 d)$
* Softmax：$O(n^2)$
* 乘 $V$：$O(n^2 d)$

**空间复杂度**： $O(n^2)$（存储注意力矩阵）

**瓶颈**：序列长度 $n$ 的平方关系（长序列问题）

#### 核心实现

```python
class MultiHeadAttention(Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads

        self.W_q = Linear(d_model, d_model)
        self.W_k = Linear(d_model, d_model)
        self.W_v = Linear(d_model, d_model)
        self.W_o = Linear(d_model, d_model)

    def forward(self, x, mask=None):
        batch_size, seq_len, d_model = x.shape

        # 线性投影并分割为多头
        Q = self.W_q(x).reshape(batch_size, seq_len, self.num_heads, self.d_k).transpose(0, 2, 1, 3)
        K = self.W_k(x).reshape(batch_size, seq_len, self.num_heads, self.d_k).transpose(0, 2, 1, 3)
        V = self.W_v(x).reshape(batch_size, seq_len, self.num_heads, self.d_k).transpose(0, 2, 1, 3)
        # Q, K, V: (batch, num_heads, seq_len, d_k)

        # Scaled Dot-Product Attention
        scores = Q @ K.transpose(0, 1, 3, 2) / np.sqrt(self.d_k)  # (batch, heads, seq, seq)

        if mask is not None:
            scores = scores + mask * -1e9  # 掩码位置设为负无穷

        attn_weights = softmax(scores, axis=-1)
        attn_output = attn_weights @ V  # (batch, heads, seq, d_k)

        # 合并多头
        attn_output = attn_output.transpose(0, 2, 1, 3).reshape(batch_size, seq_len, d_model)
        output = self.W_o(attn_output)

        return output

def softmax(x, axis=-1):
    exp_x = np.exp(x - np.max(x, axis=axis, keepdims=True))
    return exp_x / np.sum(exp_x, axis=axis, keepdims=True)
```

### 5.2 位置编码

**正弦位置编码**：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right) \\
PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

#### 理论推导：相对位置的线性表示

**问题**：Attention 是置换不变的，如何编码位置信息？

**正弦编码的优势**：可以表示相对位置

**线性组合性质**：利用三角恒等式

$\sin(\alpha + \beta) = \sin\alpha \cos\beta + \cos\alpha \sin\beta$

对于位置 $pos + k$：

$PE_{pos+k} = \text{LinearTransform}(PE_{pos})$

这意味着模型可以学习"向前/向后 $k$ 步"的关系。

**频率选择**：不同维度使用不同频率

* 低频（i 大）：更适合表示长距离、缓慢变化的位置关系，即捕捉长距离依赖
* 高频（i 小）：更敏感于局部、小范围位置变化，即捕捉短距离依赖

**对比可学习位置编码**：

* 优点：可以适应特定任务
* 缺点：无法外推到训练时未见过的长度

#### 核心实现

```python
def positional_encoding(seq_len, d_model):
    """生成正弦位置编码"""
    pe = np.zeros((seq_len, d_model))
    position = np.arange(seq_len)[:, np.newaxis]
    div_term = np.exp(np.arange(0, d_model, 2) * -(np.log(10000.0) / d_model))

    pe[:, 0::2] = np.sin(position * div_term)
    pe[:, 1::2] = np.cos(position * div_term)

    return pe
```

### 5.3 Transformer 架构 (GPT)

**Transformer Block**：

$$\begin{aligned}
\text{Attn}_{\text{out}} &= \text{LayerNorm}(x + \text{MultiHeadAttn}(x)) \\
\text{FFN}_{\text{out}} &= \text{LayerNorm}(\text{Attn}_{\text{out}} + \text{FFN}(\text{Attn}_{\text{out}}))
\end{aligned}$$

**Feed-Forward Network**：

$\text{FFN}(x) = \text{GELU}(xW_1 + b_1)W_2 + b_2$

#### 理论推导：Pre-Norm vs Post-Norm

**Post-Norm**（原始 Transformer）：

$y = \text{LayerNorm}(x + \text{Sublayer}(x))$

**Pre-Norm**（GPT 风格）：

$y = x + \text{Sublayer}(\text{LayerNorm}(x))$

**Pre-Norm 优势**：

* 梯度流更稳定（类似 ResNet）
* 无需 warm-up 学习率
* 可训练更深网络（100+ 层）

#### FFN 的作用

**直觉**：FFN 是逐位置的两层 MLP，为每个 token 独立变换。

**参数量**：

$\text{Params}_{\text{FFN}} = 2 \times d_{\text{model}} \times d_{\text{ff}} = 2 \times d_{\text{model}} \times 4d_{\text{model}} = 8d_{\text{model}}^2$

通常占 Transformer 参数的 $\approx 2/3$！

**功能假设**：

* Attention：信息聚合（token 间交互）
* FFN：特征变换（增加非线性）

#### 核心实现

```python
class TransformerBlock(Module):
    def __init__(self, d_model, num_heads, d_ff=2048, dropout=0.1):
        super().__init__()
        self.attn = MultiHeadAttention(d_model, num_heads)
        self.ffn = Sequential(
            Linear(d_model, d_ff),
            GELU(),
            Linear(d_ff, d_model)
        )
        self.ln1 = LayerNorm(d_model)
        self.ln2 = LayerNorm(d_model)

    def forward(self, x, mask=None):
        # Pre-Norm: LayerNorm before sub-layer
        x = x + self.attn(self.ln1(x), mask)
        x = x + self.ffn(self.ln2(x))
        return x

class GPT(Module):
    def __init__(self, vocab_size, d_model, num_heads, num_layers, max_seq_len):
        super().__init__()
        self.token_embedding = Embedding(vocab_size, d_model)
        self.pos_encoding = positional_encoding(max_seq_len, d_model)
        self.blocks = [TransformerBlock(d_model, num_heads) for _ in range(num_layers)]
        self.ln_f = LayerNorm(d_model)
        self.lm_head = Linear(d_model, vocab_size)

    def forward(self, x):
        seq_len = x.shape[1]
        # Token + Position Embedding
        x = self.token_embedding(x) + self.pos_encoding[:seq_len]

        # Causal mask (下三角)
        mask = np.triu(np.ones((seq_len, seq_len)), k=1).astype(bool)

        # Transformer blocks
        for block in self.blocks:
            x = block(x, mask)

        x = self.ln_f(x)
        logits = self.lm_head(x)
        return logits

class GELU(Module):
    def forward(self, x):
        return 0.5 * x * (1 + np.tanh(np.sqrt(2/np.pi) * (x + 0.044715 * x**3)))
```
