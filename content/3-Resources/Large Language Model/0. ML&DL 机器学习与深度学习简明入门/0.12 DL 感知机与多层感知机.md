# 0.12.1 感知机 (Perceptron)

感知机是最简单的神经网络单元，模拟生物神经元的基本功能：

1. **接收输入**：从多个来源收集信号（树突）
2. **加权求和**：对输入进行加权组合（细胞体）
3) **激活判断**：超过阈值则激活输出（轴突）

想象一个简单的决策过程：

* 输入：天气好？($x\_1$)，有空？($x\_2$)，朋友来？($x\_3$)
* 权重：每个因素的重要性
* 输出：是否出门？

**核心思想**：感知机将输入空间用一个超平面分割成两部分。

## 感知机模型

给定输入 $\mathbf{x} = [x_1, x_2, \ldots, x_n]^T$，感知机计算：

$z = \mathbf{w}^T \mathbf{x} + b = \sum_{i=1}^{n} w_i x_i + b$

$\hat{y} = \text{sign}(z) = \begin{cases} +1 & \text{if } z \geq 0 \\ -1 & \text{if } z < 0 \end{cases}$

其中：

* $\mathbf{w} \in \mathbb{R}^n$：权重向量
* $b \in \mathbb{R}$：偏置项
* $\text{sign}(\cdot)$：符号函数（阶跃激活）

**几何解释：** 决策边界是超平面 $\mathbf{w}^T \mathbf{x} + b = 0$：

* $\mathbf{w}$ 是超平面的法向量
* $|b|/\|\mathbf{w}\|$ 是超平面到原点的距离

**感知机学习规则：** 对于误分类样本 $(\mathbf{x}^{(i)}, y^{(i)})$：

$\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot y^{(i)} \cdot \mathbf{x}^{(i)}$

$b \leftarrow b + \eta \cdot y^{(i)}$

**收敛定理**：如果数据线性可分，感知机算法在有限步内收敛。

```python
class Perceptron:
    """
    感知机分类器的手写实现。

    Parameters
    ----------
    learning_rate : float
        学习率，控制每次更新的步长
    max_iter : int
        最大迭代次数

    Attributes
    ----------
    weights : np.ndarray
        权重向量
    bias : float
        偏置项
    history : list
        训练过程中的权重和偏置历史
    """

    def init(self, learning_rate: float = 0.1, max_iter: int = 1000):
        self.learning_rate = learning_rate
        self.max_iter = max_iter
        self.weights = None
        self.bias = None
        self.history = []

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'Perceptron':
        """
        训练感知机模型。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            标签，取值为 {-1, +1}

        Returns
        -------
        self : Perceptron
            训练好的模型
        """
        n_samples, n_features = X.shape

        # 初始化权重为零向量
        self.weights = np.zeros(n_features)
        self.bias = 0.0

        # 记录初始状态
        self.history = [(self.weights.copy(), self.bias)]

        for epoch in range(self.max_iter):
            errors = 0

            for i in range(n_samples):
                # 计算预测值
                z = np.dot(self.weights, X[i]) + self.bias
                y_pred = 1 if z >= 0 else -1

                # 如果误分类，更新权重
                if y_pred != y[i]:
                    self.weights += self.learning_rate * y[i] * X[i]
                    self.bias += self.learning_rate * y[i]
                    errors += 1

                    # 记录更新后的状态
                    self.history.append((self.weights.copy(), self.bias))

            # 如果没有误分类样本，提前终止
            if errors == 0:
                print(f"收敛于第 {epoch + 1} 轮")
                break

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测新样本的类别。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            待预测数据

        Returns
        -------
        np.ndarray, shape (n_samples,)
            预测标签
        """
        z = np.dot(X, self.weights) + self.bias
        return np.where(z >= 0, 1, -1)

    def decision_function(self, X: np.ndarray) -> np.ndarray:
        """
        计算决策函数值（到决策边界的有符号距离）。
        """
        return np.dot(X, self.weights) + self.bias
```

# 0.12.3 激活函数

激活函数是神经网络的"魔法"所在：

1. **引入非线性**：没有激活函数，多层网络退化为单层
2. **信息压缩**：将无限范围的输入映射到有限输出
3) **生物类比**：模拟神经元的激活阈值

#### Sigmoid 函数

$\sigma(z) = \frac{1}{1 + e^{-z}}$

**导数**：$\sigma'(z) = \sigma(z)(1 - \sigma(z))$

**特点**：

* 输出范围 $(0, 1)$
* 饱和区梯度接近 0（梯度消失问题）
* 输出非零中心化

#### Tanh 函数

$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1$

**导数**：$\tanh'(z) = 1 - \tanh^2(z)$

**特点**：

* 输出范围 $(-1, 1)$
* 零中心化输出
* 仍有梯度消失问题

#### ReLU 函数

$\text{ReLU}(z) = \max(0, z)$

**导数**：$\text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$

**特点**：

* 计算简单高效
* 缓解梯度消失
* 存在"死亡 ReLU"问题

```python
class ActivationFunctions:
    """
    常用激活函数的手写实现。

    提供前向计算和导数计算。
    """

    @staticmethod
    def sigmoid(z: np.ndarray) -> np.ndarray:
        """
        Sigmoid 激活函数。

        Parameters
        ----------
        z : np.ndarray
            输入值

        Returns
        -------
        np.ndarray
            激活后的值，范围 (0, 1)
        """
        # 数值稳定的实现
        return np.where(z >= 0,
                        1 / (1 + np.exp(-z)),
                        np.exp(z) / (1 + np.exp(z)))

    @staticmethod
    def sigmoid_derivative(z: np.ndarray) -> np.ndarray:
        """Sigmoid 的导数。"""
        s = ActivationFunctions.sigmoid(z)
        return s * (1 - s)

    @staticmethod
    def tanh(z: np.ndarray) -> np.ndarray:
        """
        Tanh 激活函数。

        Parameters
        ----------
        z : np.ndarray
            输入值

        Returns
        -------
        np.ndarray
            激活后的值，范围 (-1, 1)
        """
        return np.tanh(z)

    @staticmethod
    def tanh_derivative(z: np.ndarray) -> np.ndarray:
        """Tanh 的导数。"""
        return 1 - np.tanh(z) ** 2

    @staticmethod
    def relu(z: np.ndarray) -> np.ndarray:
        """
        ReLU 激活函数。

        Parameters
        ----------
        z : np.ndarray
            输入值

        Returns
        -------
        np.ndarray
            激活后的值，范围 [0, +inf)
        """
        return np.maximum(0, z)

    @staticmethod
    def relu_derivative(z: np.ndarray) -> np.ndarray:
        """ReLU 的导数。"""
        return (z > 0).astype(float)

    @staticmethod
    def leaky_relu(z: np.ndarray, alpha: float = 0.01) -> np.ndarray:
        """
        Leaky ReLU 激活函数。

        Parameters
        ----------
        z : np.ndarray
            输入值
        alpha : float
            负区间斜率

        Returns
        -------
        np.ndarray
            激活后的值
        """
        return np.where(z > 0, z, alpha * z)

    @staticmethod
    def leaky_relu_derivative(z: np.ndarray, alpha: float = 0.01) -> np.ndarray:
        """Leaky ReLU 的导数。"""
        return np.where(z > 0, 1, alpha)

    @staticmethod
    def softmax(z: np.ndarray) -> np.ndarray:
        """
        Softmax 激活函数（用于多分类输出层）。

        Parameters
        ----------
        z : np.ndarray, shape (..., n_classes)
            输入值

        Returns
        -------
        np.ndarray
            概率分布，每行和为 1
        """
        # 数值稳定：减去最大值
        z_shifted = z - np.max(z, axis=-1, keepdims=True)
        exp_z = np.exp(z_shifted)
        return exp_z / np.sum(exp_z, axis=-1, keepdims=True)
```

# 0.12.4 多层感知机 (MLP)

既然单层感知机无法解决 XOR，我们需要 **多层结构**：

1. **隐藏层**：学习中间表示
2. **非线性激活**：使每层都能学习非线性变换
3) **层层堆叠**：逐步提取更抽象的特征

**直观理解 XOR 的解决方案**：

* 隐藏层神经元 1：检测 " $x_1 \text{OR} x_2$"
* 隐藏层神经元 2：检测 " $x_1 \text{AND} x_2$"
* 输出层："OR 为真" 且 "AND 为假" → XOR 为真

## MLP 结构

一个 $L$ 层的 MLP（不含输入层）：

$\mathbf{a}^{(0)} = \mathbf{x}$

$\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}, \quad l = 1, \ldots, L$

$\mathbf{a}^{(l)} = \phi^{(l)}(\mathbf{z}^{(l)}), \quad l = 1, \ldots, L$

$\hat{\mathbf{y}} = \mathbf{a}^{(L)}$

其中：

* $\mathbf{W}^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}$：第 $l$ 层权重矩阵
* $\mathbf{b}^{(l)} \in \mathbb{R}^{n_l}$：第 $l$ 层偏置向量
* $\phi^{(l)}$：第 $l$ 层激活函数

## 万能近似定理 (Universal Approximation Theorem)

> 一个具有有限神经元的单隐藏层前馈网络，可以以任意精度逼近 $\mathbb{R}^n$ 的紧子集上的任意连续函数。

**含义**：

* MLP 理论上可以学习任何函数
* 但定理没有告诉我们需要多少神经元
* 也没有告诉我们如何找到正确的权重

```python
class MLP:
    """
    多层感知机的手写实现。

    Parameters
    ----------
    layer_sizes : list of int
        各层神经元数量，包括输入层和输出层
    activation : str
        隐藏层激活函数，可选 'sigmoid', 'tanh', 'relu'
    learning_rate : float
        学习率

    Attributes
    ----------
    weights : list of np.ndarray
        各层权重矩阵
    biases : list of np.ndarray
        各层偏置向量
    """

    def init(self, layer_sizes: list, activation: str = 'sigmoid',
                 learning_rate: float = 0.1):
        self.layer_sizes = layer_sizes
        self.n_layers = len(layer_sizes) - 1  # 不含输入层
        self.learning_rate = learning_rate

        # 设置激活函数
        self.activation_name = activation
        act = ActivationFunctions()
        if activation == 'sigmoid':
            self.activation = act.sigmoid
            self.activation_derivative = act.sigmoid_derivative
        elif activation == 'tanh':
            self.activation = act.tanh
            self.activation_derivative = act.tanh_derivative
        elif activation == 'relu':
            self.activation = act.relu
            self.activation_derivative = act.relu_derivative
        else:
            raise ValueError(f"未知激活函数: {activation}")

        # 初始化权重和偏置
        self.weights = []
        self.biases = []
        for i in range(self.n_layers):
            # Xavier 初始化
            scale = np.sqrt(2.0 / (layer_sizes[i] + layer_sizes[i+1]))
            W = np.random.randn(layer_sizes[i+1], layer_sizes[i]) * scale
            b = np.zeros((layer_sizes[i+1], 1))
            self.weights.append(W)
            self.biases.append(b)

        # 训练历史
        self.loss_history = []

    def forward(self, X: np.ndarray) -> tuple:
        """
        前向传播。

        Parameters
        ----------
        X : np.ndarray, shape (n_features, n_samples)
            输入数据（注意：列是样本）

        Returns
        -------
        tuple
            (activations, pre_activations) - 各层激活值和激活前的值
        """
        activations = [X]  # a[0] = X
        pre_activations = []  # z[l]

        a = X
        for l in range(self.n_layers):
            z = self.weights[l] @ a + self.biases[l]
            pre_activations.append(z)

            # 最后一层使用 sigmoid（二分类）
            if l == self.n_layers - 1:
                a = ActivationFunctions.sigmoid(z)
            else:
                a = self.activation(z)
            activations.append(a)

        return activations, pre_activations

    def backward(self, X: np.ndarray, y: np.ndarray,
                 activations: list, pre_activations: list) -> tuple:
        """
        反向传播计算梯度。

        Parameters
        ----------
        X : np.ndarray
            输入数据
        y : np.ndarray
            真实标签
        activations : list
            各层激活值
        pre_activations : list
            各层激活前的值

        Returns
        -------
        tuple
            (dW_list, db_list) - 各层权重和偏置的梯度
        """
        m = X.shape[1]  # 样本数
        dW_list = [None] * self.n_layers
        db_list = [None] * self.n_layers

        # 输出层的误差（使用交叉熵损失的梯度）
        delta = activations[-1] - y  # dL/da * da/dz

        for l in range(self.n_layers - 1, -1, -1):
            # 计算梯度
            dW_list[l] = (1/m) * delta @ activations[l].T
            db_list[l] = (1/m) * np.sum(delta, axis=1, keepdims=True)

            # 传播到前一层（如果不是第一层）
            if l > 0:
                delta = (self.weights[l].T @ delta) * self.activation_derivative(pre_activations[l-1])

        return dW_list, db_list

    def update_parameters(self, dW_list: list, db_list: list):
        """
        使用梯度更新参数。
        """
        for l in range(self.n_layers):
            self.weights[l] -= self.learning_rate * dW_list[l]
            self.biases[l] -= self.learning_rate * db_list[l]

    def compute_loss(self, y_pred: np.ndarray, y_true: np.ndarray) -> float:
        """
        计算二元交叉熵损失。
        """
        epsilon = 1e-15  # 避免 log(0)
        y_pred = np.clip(y_pred, epsilon, 1 - epsilon)
        loss = -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))
        return loss

    def fit(self, X: np.ndarray, y: np.ndarray, epochs: int = 1000,
            verbose: bool = True) -> 'MLP':
        """
        训练 MLP。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            标签 (0 或 1)
        epochs : int
            训练轮数
        verbose : bool
            是否打印训练信息

        Returns
        -------
        self : MLP
            训练好的模型
        """
        # 转置数据：(n_features, n_samples)
        X_T = X.T
        y_T = y.reshape(1, -1)

        self.loss_history = []

        for epoch in range(epochs):
            # 前向传播
            activations, pre_activations = self.forward(X_T)

            # 计算损失
            loss = self.compute_loss(activations[-1], y_T)
            self.loss_history.append(loss)

            # 反向传播
            dW_list, db_list = self.backward(X_T, y_T, activations, pre_activations)

            # 更新参数
            self.update_parameters(dW_list, db_list)

            if verbose and (epoch + 1) % (epochs // 10) == 0:
                acc = self.accuracy(X, y)
                print(f"Epoch {epoch+1}/{epochs}, Loss: {loss:.4f}, Accuracy: {acc:.2%}")

        return self

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        """
        预测概率。
        """
        X_T = X.T
        activations, _ = self.forward(X_T)
        return activations[-1].flatten()

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测类别。
        """
        proba = self.predict_proba(X)
        return (proba >= 0.5).astype(int)

    def accuracy(self, X: np.ndarray, y: np.ndarray) -> float:
        """
        计算准确率。
        """
        predictions = self.predict(X)
        return np.mean(predictions == y)
```

# 总结

1. **感知机**：最简单的神经网络单元，只能解决线性可分问题
2. **XOR 问题**：揭示了单层感知机的根本局限性
3) **激活函数**：引入非线性，使神经网络能学习复杂模式
4) **多层感知机**：通过隐藏层和非线性激活解决线性不可分问题
> "神经网络的力量不在于单个神经元，而在于它们的组合方式和非线性激活的引入。"
