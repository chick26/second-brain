### 4.1 RNN 与时间反向传播

**RNN 前向传播**：

$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$

**梯度消失问题**：

$\frac{\partial h_t}{\partial h_0} = \prod_{k=1}^{t} \frac{\partial h_k}{\partial h_{k-1}} = \prod_{k=1}^{t} W_{hh} \cdot \text{diag}(\tanh'(z_k))$

当 $\|W_{hh}\| < 1$ 时，梯度指数衰减。

#### 理论推导：BPTT 算法

**展开 RNN**：将时间步展开为前馈网络

$h_0 \xrightarrow{W_{hh}} h_1 \xrightarrow{W_{hh}} h_2 \xrightarrow{W_{hh}} \cdots \xrightarrow{W_{hh}} h_T$

**损失函数**（序列到序列）：

$L = \sum_{t=1}^{T} L_t(h_t, y_t)$

**梯度计算**（对 $W_{hh}$）：

$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \sum_{k=1}^{t} \frac{\partial L_t}{\partial h_t} \cdot \frac{\partial h_t}{\partial h_k} \cdot \frac{\partial h_k}{\partial W_{hh}}$

**关键项**： $\frac{\partial h_t}{\partial h_k}$ 是 `Jacobian` 矩阵的乘积

$\frac{\partial h_t}{\partial h_k} = \prod_{i=k+1}^{t} \frac{\partial h_i}{\partial h_{i-1}} = \prod_{i=k+1}^{t} W_{hh}^T \cdot \text{diag}(\tanh'(z_i))$

#### 梯度消失/爆炸的数学证明

**谱半径分析**：

设 $W_{hh}$ 的最大特征值为 $\lambda_{\max}$（谱半径），则：

$\left\| \prod_{i=k+1}^{t} \frac{\partial h_i}{\partial h_{i-1}} \right\| \leq \left( \|\tanh'\| \cdot \|W_{hh}\| \right)^{t-k} \leq (\lambda_{\max})^{t-k}$

**三种情况**：

1. $\lambda_{\max} < 1$：梯度消失（ $\approx \lambda^T \to 0$）
2. $\lambda_{\max} > 1$：梯度爆炸（ $\approx \lambda^T \to \infty$）
3) $\lambda_{\max} = 1$：边界情况（难以维持）

**数值示例**： $T=100$, $\lambda=0.9$

$\text{梯度衰减} \approx 0.9^{100} \approx 2.7 \times 10^{-5}$

#### 解决方案

1. **梯度裁剪**

$\text{if } \|\nabla\| > \theta: \quad \nabla \leftarrow \frac{\theta \nabla}{\|\nabla\|}$

* **门控机制**（LSTM/GRU）：引入线性梯度路径
* **正交初始化**：初始化 $W_{hh}$ 为正交矩阵（ $\lambda_{\max} = 1$）

#### 核心实现

```python
class RNN(Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        self.W_xh = Tensor(np.random.randn(input_size, hidden_size) * 0.01, True)
        self.W_hh = Tensor(np.random.randn(hidden_size, hidden_size) * 0.01, True)
        self.b_h = Tensor(np.zeros(hidden_size), True)

    def forward(self, x, h_prev=None):
        """
        x: (batch, seq_len, input_size)
        返回: (batch, seq_len, hidden_size)
        """
        batch_size, seq_len, _ = x.shape
        if h_prev is None:
            h_prev = np.zeros((batch_size, self.hidden_size))

        outputs = []
        h_t = h_prev

        for t in range(seq_len):
            x_t = x[:, t, :]  # (batch, input_size)
            h_t = np.tanh(x_t @ self.W_xh.data + h_t @ self.W_hh.data + self.b_h.data)
            outputs.append(h_t)

        outputs = np.stack(outputs, axis=1)  # (batch, seq_len, hidden)
        return Tensor(outputs, requires_grad=True), h_t
```

### 4.2 门控机制 (LSTM/GRU)

**LSTM 门控单元**：

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) \quad \text{(遗忘门)} \\
i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) \quad \text{(输入门)} \\
\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C) \quad \text{(候选值)} \\
C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \quad \text{(细胞状态)} \\
o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) \quad \text{(输出门)} \\
h_t = o_t \odot \tanh(C_t)$$

**关键优势**：细胞状态 $C_t$ 提供线性梯度通路，缓解长期依赖问题。

#### 理论推导：常数误差轮播 (Constant Error Carousel)

**核心思想**：细胞状态 $C_t$ 通过 **加性更新** 实现线性梯度流。

**梯度反向传播**（对 $C_t$ ）：

$\frac{\partial L}{\partial C_{t-1}} = \frac{\partial L}{\partial C_t} \cdot \frac{\partial C_t}{\partial C_{t-1}} = \frac{\partial L}{\partial C_t} \cdot f_t$

**关键特性**：

* 如果 $f_t \approx 1$（遗忘门打开），梯度几乎无损传播
* 无矩阵乘法，避免梯度消失/爆炸

**对比 RNN**：

$\frac{\partial h_t}{\partial h_{t-1}} = W_{hh}^T \cdot \text{diag}(\tanh'(z_t)) \quad \text{(矩阵乘法链)}$

**LSTM 的优势**：

$\frac{\partial C_t}{\partial C_{t-1}} = f_t \quad \text{(对角矩阵，元素级乘法)}$

#### 门控的直觉解释

1\. **遗忘门** $f_t$：决定保留多少旧记忆（$f\_t=1$ 完全保留，$f\_t=0$ 完全遗忘）

2\. **输入门** $i_t$：决定接受多少新信息

3\. **输出门** $o_t$：决定输出多少信息到隐藏状态

**数学上**：门控值 $\in (0, 1)$（sigmoid），实现软开关。

#### GRU 简化版本

**GRU 公式**（参数更少）：

$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t]) \quad \text{(更新门)} \\
r_t = \sigma(W_r \cdot [h_{t-1}, x_t]) \quad \text{(重置门)} \\
\tilde{h}_t = \tanh(W \cdot [r_t \odot h_{t-1}, x_t]) \\
h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

**对比 LSTM**：

* LSTM：3 个门 + 细胞状态（4 个状态变量）
* GRU：2 个门（更简洁，性能相近）

#### 核心实现

```python
class LSTM(Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        # 4 个门的权重（合并为一个矩阵加速计算）
        self.W = Tensor(np.random.randn(input_size + hidden_size, 4 * hidden_size) * 0.01, True)
        self.b = Tensor(np.zeros(4 * hidden_size), True)

    def forward(self, x, states=None):
        batch_size, seq_len, _ = x.shape
        if states is None:
            h_prev = np.zeros((batch_size, self.hidden_size))
            c_prev = np.zeros((batch_size, self.hidden_size))
        else:
            h_prev, c_prev = states

        outputs = []
        for t in range(seq_len):
            x_t = x[:, t, :]
            # 拼接输入和隐藏状态
            combined = np.concatenate([h_prev, x_t], axis=1)
            gates = combined @ self.W.data + self.b.data

            # 分割 4 个门
            i_t, f_t, g_t, o_t = np.split(gates, 4, axis=1)
            i_t = sigmoid(i_t)  # 输入门
            f_t = sigmoid(f_t)  # 遗忘门
            g_t = np.tanh(g_t)  # 候选值
            o_t = sigmoid(o_t)  # 输出门

            # 更新细胞状态（关键：线性路径）
            c_t = f_t * c_prev + i_t * g_t
            h_t = o_t * np.tanh(c_t)

            outputs.append(h_t)
            h_prev, c_prev = h_t, c_t

        outputs = np.stack(outputs, axis=1)
        return Tensor(outputs, True), (h_t, c_t)

def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```
