> > "Support Vector Machines are the most elegant supervised learning algorithm." — Vladimir Vapnik (SVM 发明者)
> 支持向量机是一种基于最大间隔的判别式分类器。它的核心思想是找到一个能够最大化类别间隔的决策边界。通过核技巧，SVM 可以处理非线性可分的数据

# 0.7.1 最大间隔分类器

> 想象你要在两组点之间画一条分割线。有无数种画法，哪种最好？
> SVM 的回答：选择 **间隔最大** 的那条线！
> 为什么？
> * 间隔大 → 对噪声更鲁棒
> * 间隔大 → 泛化能力更强
> * 统计学习理论保证：间隔越大，VC 维越小，泛化误差上界越低
* **决策边界：** 超平面：$\mathbf{w}^T\mathbf{x} + b = 0$，分类决策：$\hat{y} = \text{sign}(\mathbf{w}^T\mathbf{x} + b)$
* **几何间隔：** 点 $\mathbf{x}$ 到超平面的距离：$\text{distance} = \frac{|\mathbf{w}^T\mathbf{x} + b|}{\|\mathbf{w}\|}$
* **间隔（Margin）：** 间隔是离超平面 **最近** 的点的距离的两倍：$\text{margin} = \frac{2}{\|\mathbf{w}\|}$（通过缩放使得最近点满足 $|\mathbf{w}^T\mathbf{x} + b| = 1$）

# 0.7.2 硬间隔 SVM

* **优化问题：** 最大化间隔 = 最小化 $\|\mathbf{w}\|$：$\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2$
* **约束条件（所有点被正确分类且在间隔外）：** $y^{(i)}(\mathbf{w}^T\mathbf{x}^{(i)} + b) \geq 1, \quad \forall i$
* **拉格朗日对偶：** 引入拉格朗日乘子 $\alpha_i \geq 0$：

$\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_{i=1}^{n} \alpha_i [y^{(i)}(\mathbf{w}^T\mathbf{x}^{(i)} + b) - 1]$

* **对偶问题：** $\max_{\boldsymbol{\alpha}} \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y^{(i)} y^{(j)} \mathbf{x}^{(i)T}\mathbf{x}^{(j)}$，约束： $\alpha_i \geq 0$, $\sum_i \alpha_i y^{(i)} = 0$
* **KKT 条件与支持向量：** $\alpha_i [y^{(i)}(\mathbf{w}^T\mathbf{x}^{(i)} + b) - 1] = 0$
  * 如果 $\alpha_i > 0$，则 $y^{(i)}(\mathbf{w}^T\mathbf{x}^{(i)} + b) = 1$（点在间隔边界上）
  * 这些点就是 **支持向量**！

# 0.7.3 软间隔 SVM 与 Hinge Loss

> 现实中数据很少完美线性可分。我们需要允许一些「违规」：
> * 有些点可能在间隔内
> * 有些点甚至可能被错误分类
> **软间隔 SVM** 在最大化间隔和最小化分类错误之间做权衡。

* **松弛变量：** 引入 $\xi_i \geq 0$ 允许违规：$y^{(i)}(\mathbf{w}^T\mathbf{x}^{(i)} + b) \geq 1 - \xi_i$
* **软间隔优化问题：** $\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^{n}\xi_i$，约束： $y^{(i)}(\mathbf{w}^T\mathbf{x}^{(i)} + b) \geq 1 - \xi_i$, $\xi_i \geq 0$，其中 $C > 0$ 是正则化参数
* **Hinge Loss：** 等价的无约束形式（Hinge Loss）：

$\min_{\mathbf{w}, b} \frac{1}{n}\sum_{i=1}^{n} \max(0, 1 - y^{(i)}(\mathbf{w}^T\mathbf{x}^{(i)} + b)) + \lambda\|\mathbf{w}\|^2$，其中 $\lambda = \frac{1}{2nC}$

# 0.7.5 核技巧 (Kernel Trick)

> 当数据在原始空间不是线性可分时怎么办？
> **解决方案**：将数据映射到高维空间，在高维空间中线性可分！
> 例如：圆形分布的数据 → 添加 $x_1^2 + x_2^2$ 特征 → 在 3D 中变成线性可分
> **核技巧的魔力**：不需要显式计算高维特征，只需计算 **核函数**

* **特征映射：** 映射函数 $\phi: \mathbb{R}^d \rightarrow \mathbb{R}^D$ 将数据映射到高维空间。
* **核函数**：核函数计算高维空间中的内积，而不需要显式计算 $\phi$：$K(\mathbf{x}, \mathbf{z}) = \phi(\mathbf{x})^T \phi(\mathbf{z})$
* **常用核函数：**



| 核函数 | 公式 |
| --- | --- |
| 线性核 | $K(\mathbf{x}, \mathbf{z}) = \mathbf{x}^T\mathbf{z}$ |
| 多项式核 | $K(\mathbf{x}, \mathbf{z}) = (\gamma\mathbf{x}^T\mathbf{z} + r)^d$ |
| RBF/高斯核 | $K(\mathbf{x}, \mathbf{z}) = \exp(-\gamma\vert{}\mathbf{x}-\mathbf{z}\vert{}^2)$ |
| Sigmoid核 | $K(\mathbf{x}, \mathbf{z}) = \tanh(\gamma\mathbf{x}^T\mathbf{z} + r)$ |



* **对偶问题中的核：** $\max_{\boldsymbol{\alpha}} \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y^{(i)} y^{(j)} K(\mathbf{x}^{(i)}, \mathbf{x}^{(j)})$

# 0.7.7 SMO 算法简介

> SMO 的核心思想：Sequential Minimal Optimization (SMO) 是求解 SVM 对偶问题的高效算法。
> **核心思想**：每次只优化两个拉格朗日乘子，将原问题分解为一系列最小优化子问题。
> **为什么是两个？** 因为约束 $\sum_i \alpha_i y_i = 0$ 要求至少改变两个 $\alpha$。
![[_Attachments/Images/0.7 ML 支持向量机与核方法 (SVM and Kernels)-image-1.png]]

SMO 算法要点:

1. 每次选择两个 alpha 进行优化
2. 优化沿着等式约束线进行
3) 有解析解，不需要迭代
4) 启发式选择违反 KKT 条件最严重的变量

# 总结

1. **最大间隔分类器**: 找到「最宽」的分割超平面
2. **硬间隔 vs 软间隔**: 从严格分类到允许一些错误
3) **Hinge Loss**: SVM 的损失函数
4) **核技巧**: 隐式映射到高维空间
5. **常用核函数**: 线性、多项式、RBF
6. **SMO 算法**: 高效求解 SVM 对偶问题
> "SVM 的优雅在于：通过最大化间隔，它不仅关注分类正确，更追求分类'自信'。核技巧则让这种优雅延伸到非线性世界。"

SVM 的优缺点

**优点**

* 在高维空间中高效
* 内存高效（只需存储支持向量）
* 通用性强（不同核函数适应不同问题）
* 有坚实的理论基础

**缺点**:

* 对大规模数据训练慢
* 对参数敏感（C, gamma）
* 不直接提供概率输出
