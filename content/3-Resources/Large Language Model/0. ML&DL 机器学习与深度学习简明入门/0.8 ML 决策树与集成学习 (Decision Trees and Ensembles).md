> > "A single decision tree is like one expert opinion; an ensemble is like a committee of experts." — Leo Breiman
> 决策树是一种直观的、基于规则的分类器。集成学习则通过组合多个弱学习器来构建强学习器。本节将从决策树的基础出发，逐步介绍 Random Forest 和 AdaBoost 等强大的集成方法

# 0.8.1 信息熵与不确定性

> **熵**（Entropy）衡量一个集合的 混乱程度 或 不确定性。
> * 一个全是猫的集合：不确定性 = 0（你肯定知道下一个是猫）
> * 一半猫一半狗的集合：不确定性最大（完全猜不到下一个是什么）
> 决策树的目标：找到能 **最大程度减少不确定性** 的划分方式。

* **信息熵：** 对于一个包含 $K$ 类的集合，第 $k$ 类的比例为 $p_k$：$H = -\sum_{k=1}^{K} p_k \log_2 p_k$，约定：$0 \log_2 0 = 0$
* **性质：**
  * $H \geq 0$
  * $H = 0$ 当且仅当所有样本属于同一类
  * $H$ 在均匀分布时达到最大值 $\log_2 K$
* **信息增益：** $\text{信息增益} = H(\text{父节点}) - \sum_{i} \frac{|S_i|}{|S|} H(S_i)$，其中 $S_i$ 是划分后的子集。

```python
def entropy(y: np.ndarray) -> float:
    """
    计算信息熵。

    Parameters
    ----------
    y : np.ndarray
        类别标签

    Returns
    -------
    float
        熵值
    """
    if len(y) == 0:
        return 0.0

    # 计算每个类别的比例
    _, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)

    # 计算熵
    return -np.sum(probs * np.log2(probs + 1e-10))

def gini_impurity(y: np.ndarray) -> float:
    """
    计算基尼不纯度。

    Parameters
    ----------
    y : np.ndarray
        类别标签

    Returns
    -------
    float
        基尼不纯度
    """
    if len(y) == 0:
        return 0.0

    _, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)

    return 1 - np.sum(probs ** 2)
```

# 0.8.2 CART 决策树算法

> CART (Classification and Regression Trees) 是一种贪心算法：
> 1. 在当前节点，尝试所有可能的特征和阈值
> 2. 选择能 **最大程度减少不纯度** 的划分
> 3) 递归地在子节点上重复
> 4) 直到满足停止条件（深度、样本数等）
* **最佳划分准则：** 对于特征 $j$ 和阈值 $t$，计算划分质量：$Q(j, t) = \frac{|S_L|}{|S|} H(S_L) + \frac{|S_R|}{|S|} H(S_R)$
  其中：
  * $S_L = \{(\mathbf{x}, y) : x_j \leq t\}$
  * $S_R = \{(\mathbf{x}, y) : x_j > t\}$
  选择使 $Q(j, t)$ 最小的 $(j^*, t^*)$。
* **停止条件：**
  * 达到最大深度
  * 节点样本数少于阈值
  * 节点纯度足够高
  * 无法找到有效划分

```python
class DecisionTreeNode:
    """
    决策树节点。

    Attributes
    ----------
    feature_index : int
        划分特征索引
    threshold : float
        划分阈值
    left : DecisionTreeNode
        左子树
    right : DecisionTreeNode
        右子树
    value : int or float
        叶节点的预测值
    impurity : float
        节点不纯度
    n_samples : int
        节点样本数
    """

    def init(self):
        self.feature_index = None
        self.threshold = None
        self.left = None
        self.right = None
        self.value = None
        self.impurity = None
        self.n_samples = None
        self.class_distribution = None

class DecisionTreeClassifier:
    """
    CART 决策树分类器（从零实现）。

    Parameters
    ----------
    max_depth : int
        最大深度
    min_samples_split : int
        分裂所需最小样本数
    min_samples_leaf : int
        叶节点最小样本数
    criterion : str
        划分准则 ('gini' or 'entropy')
    """

    def init(self, max_depth: int = None, min_samples_split: int = 2,
                 min_samples_leaf: int = 1, criterion: str = 'gini'):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.min_samples_leaf = min_samples_leaf
        self.criterion = criterion
        self.root = None
        self.n_features = None
        self.n_classes = None
        self.feature_importances_ = None

    def _impurity(self, y: np.ndarray) -> float:
        """计算不纯度。"""
        if self.criterion == 'gini':
            return gini_impurity(y)
        else:
            return entropy(y)

    def _best_split(self, X: np.ndarray, y: np.ndarray):
        """
        找到最佳划分。

        Returns
        -------
        best_feature, best_threshold, best_gain
        """
        n_samples, n_features = X.shape

        if n_samples < self.min_samples_split:
            return None, None, 0

        parent_impurity = self._impurity(y)
        best_gain = 0
        best_feature = None
        best_threshold = None

        for feature_idx in range(n_features):
            # 获取该特征的所有唯一值作为候选阈值
            thresholds = np.unique(X[:, feature_idx])

            for threshold in thresholds:
                # 划分
                left_mask = X[:, feature_idx] <= threshold
                right_mask = ~left_mask

                if np.sum(left_mask) < self.min_samples_leaf or \
                   np.sum(right_mask) < self.min_samples_leaf:
                    continue

                # 计算加权不纯度
                n_left = np.sum(left_mask)
                n_right = np.sum(right_mask)

                impurity_left = self._impurity(y[left_mask])
                impurity_right = self._impurity(y[right_mask])

                weighted_impurity = (n_left * impurity_left + n_right * impurity_right) / n_samples

                # 信息增益
                gain = parent_impurity - weighted_impurity

                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature_idx
                    best_threshold = threshold

        return best_feature, best_threshold, best_gain

    def _build_tree(self, X: np.ndarray, y: np.ndarray, depth: int = 0) -> DecisionTreeNode:
        """
        递归构建树。
        """
        node = DecisionTreeNode()
        node.n_samples = len(y)
        node.impurity = self._impurity(y)

        # 类别分布
        unique, counts = np.unique(y, return_counts=True)
        node.class_distribution = dict(zip(unique, counts))

        # 多数类
        node.value = unique[np.argmax(counts)]

        # 检查停止条件
        if (self.max_depth is not None and depth >= self.max_depth) or \
           len(np.unique(y)) == 1 or \
           len(y) < self.min_samples_split:
            return node

        # 找最佳划分
        best_feature, best_threshold, best_gain = self._best_split(X, y)

        if best_feature is None or best_gain == 0:
            return node

        # 划分数据
        left_mask = X[:, best_feature] <= best_threshold
        right_mask = ~left_mask

        node.feature_index = best_feature
        node.threshold = best_threshold

        # 递归构建子树
        node.left = self._build_tree(X[left_mask], y[left_mask], depth + 1)
        node.right = self._build_tree(X[right_mask], y[right_mask], depth + 1)

        # 更新特征重要性
        if self.feature_importances_ is not None:
            self.feature_importances_[best_feature] += best_gain * len(y)

        return node

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'DecisionTreeClassifier':
        """
        训练决策树。
        """
        self.n_features = X.shape[1]
        self.n_classes = len(np.unique(y))
        self.feature_importances_ = np.zeros(self.n_features)

        self.root = self._build_tree(X, y)

        # 归一化特征重要性
        if np.sum(self.feature_importances_) > 0:
            self.feature_importances_ /= np.sum(self.feature_importances_)

        return self

    def _predict_single(self, x: np.ndarray, node: DecisionTreeNode):
        """
        单样本预测。
        """
        if node.left is None and node.right is None:
            return node.value

        if x[node.feature_index] <= node.threshold:
            return self._predict_single(x, node.left)
        else:
            return self._predict_single(x, node.right)

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测类别。
        """
        return np.array([self._predict_single(x, self.root) for x in X])
```

# 0.8.4 Random Forest（随机森林）

> 单棵决策树容易过拟合。怎么办？
> **随机森林**：训练多棵「不同」的树，然后投票！
> 如何让树「不同」？
> 1. **Bootstrap 采样**：每棵树在不同的数据子集上训练
> 2. **随机特征选择**：每次分裂只考虑部分特征

## Bagging (Bootstrap Aggregating)

1. 从原数据集有放回地抽取 $n$ 个样本（约 63.2% 的原样本会出现）
2. 在这个 bootstrap 样本上训练一棵树
3) 重复 $T$ 次
* 预测：$\hat{y} = \text{mode}(h_1(\mathbf{x}), h_2(\mathbf{x}), ..., h_T(\mathbf{x}))$
* 随机特征选择：每次分裂时，只从随机选择的 $m$ 个特征中选最佳划分：
  * 分类：$m = \sqrt{d}$
  * 回归：$m = d/3$

```python
class RandomForest:
    """
    随机森林分类器（从零实现）。

    Parameters
    ----------
    n_estimators : int
        树的数量
    max_depth : int
        每棵树的最大深度
    max_features : int or str
        每次分裂考虑的特征数 ('sqrt', 'log2', int)
    bootstrap : bool
        是否使用 bootstrap 采样
    """

    def init(self, n_estimators: int = 100, max_depth: int = None,
                 max_features: str = 'sqrt', bootstrap: bool = True):
        self.n_estimators = n_estimators
        self.max_depth = max_depth
        self.max_features = max_features
        self.bootstrap = bootstrap
        self.trees = []
        self.feature_indices = []  # 每棵树使用的特征索引

    def _get_max_features(self, n_features):
        """计算每次分裂的特征数。"""
        if self.max_features == 'sqrt':
            return max(1, int(np.sqrt(n_features)))
        elif self.max_features == 'log2':
            return max(1, int(np.log2(n_features)))
        elif isinstance(self.max_features, int):
            return self.max_features
        else:
            return n_features

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'RandomForest':
        """
        训练随机森林。
        """
        n_samples, n_features = X.shape
        max_features = self._get_max_features(n_features)

        self.trees = []
        self.feature_indices = []

        for _ in range(self.n_estimators):
            # Bootstrap 采样
            if self.bootstrap:
                indices = np.random.choice(n_samples, n_samples, replace=True)
                X_sample = X[indices]
                y_sample = y[indices]
            else:
                X_sample = X
                y_sample = y

            # 随机特征选择
            feature_idx = np.random.choice(n_features, max_features, replace=False)
            self.feature_indices.append(feature_idx)

            # 训练树
            tree = DecisionTreeClassifier(max_depth=self.max_depth)
            tree.fit(X_sample[:, feature_idx], y_sample)
            self.trees.append(tree)

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测类别（多数投票）。
        """
        # 收集所有树的预测
        predictions = np.zeros((X.shape[0], self.n_estimators))

        for i, (tree, feature_idx) in enumerate(zip(self.trees, self.feature_indices)):
            predictions[:, i] = tree.predict(X[:, feature_idx])

        # 多数投票
        final_predictions = []
        for i in range(X.shape[0]):
            votes = predictions[i, :]
            final_predictions.append(Counter(votes).most_common(1)[0][0])

        return np.array(final_predictions)

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        """
        预测概率（投票比例）。
        """
        predictions = np.zeros((X.shape[0], self.n_estimators))

        for i, (tree, feature_idx) in enumerate(zip(self.trees, self.feature_indices)):
            predictions[:, i] = tree.predict(X[:, feature_idx])

        # 计算类别 1 的投票比例
        prob_class_1 = np.mean(predictions, axis=1)
        return np.column_stack([1 - prob_class_1, prob_class_1])
```

# 0.8.5 AdaBoost

> Boosting 的核心思想：**让后续的模型专注于之前模型犯错的样本**。
> AdaBoost (Adaptive Boosting)：
> 1. 初始时所有样本权重相等
> 2. 训练一个弱学习器
> 3) 增加被错误分类样本的权重
> 4) 训练下一个学习器（更关注困难样本）
> 5. 最终通过加权投票组合所有学习器

#### 算法流程
>
> 初始化：$w_i^{(1)} = \frac{1}{n}$，对 $t = 1, 2, ..., T$：
> 1. 用权重 $\mathbf{w}^{(t)}$ 训练弱学习器 $h_t$
> 2. 计算加权错误率：$\epsilon_t = \sum_{i: h_t(x_i) \neq y_i} w_i^{(t)}$
> 3) 计算学习器权重：$\alpha_t = \frac{1}{2}\ln\left(\frac{1-\epsilon_t}{\epsilon_t}\right)$
> 4) 更新样本权重：$w_i^{(t+1)} = w_i^{(t)} \cdot \exp(-\alpha_t y_i h_t(x_i))$
> 5. 归一化权重
>
#### 最终预测
>
> $H(\mathbf{x}) = \text{sign}\left(\sum_{t=1}^{T} \alpha_t h_t(\mathbf{x})\right)$

```python
class DecisionStump:
    """
    决策树桩（深度为 1 的决策树）。

    作为 AdaBoost 的弱学习器。
    """

    def init(self):
        self.feature_index = None
        self.threshold = None
        self.polarity = 1  # 1 或 -1

    def fit(self, X: np.ndarray, y: np.ndarray, weights: np.ndarray):
        """
        训练决策树桩。

        Parameters
        ----------
        X : np.ndarray
            特征数据
        y : np.ndarray
            标签 (-1 或 +1)
        weights : np.ndarray
            样本权重
        """
        n_samples, n_features = X.shape
        min_error = float('inf')

        for feature_idx in range(n_features):
            thresholds = np.unique(X[:, feature_idx])

            for threshold in thresholds:
                for polarity in [1, -1]:
                    # 预测
                    predictions = np.ones(n_samples)
                    if polarity == 1:
                        predictions[X[:, feature_idx] < threshold] = -1
                    else:
                        predictions[X[:, feature_idx] >= threshold] = -1

                    # 计算加权错误
                    error = np.sum(weights * (predictions != y))

                    if error < min_error:
                        min_error = error
                        self.feature_index = feature_idx
                        self.threshold = threshold
                        self.polarity = polarity

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测。
        """
        n_samples = X.shape[0]
        predictions = np.ones(n_samples)

        if self.polarity == 1:
            predictions[X[:, self.feature_index] < self.threshold] = -1
        else:
            predictions[X[:, self.feature_index] >= self.threshold] = -1

        return predictions

class AdaBoost:
    """
    AdaBoost 分类器（从零实现）。

    Parameters
    ----------
    n_estimators : int
        弱学习器数量
    """

    def init(self, n_estimators: int = 50):
        self.n_estimators = n_estimators
        self.stumps = []
        self.alphas = []
        self.training_errors = []
        self.weights_history = []  # 用于可视化

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'AdaBoost':
        """
        训练 AdaBoost。

        Parameters
        ----------
        X : np.ndarray
            特征数据
        y : np.ndarray
            标签 (-1 或 +1)
        """
        n_samples = X.shape[0]

        # 初始化样本权重
        weights = np.ones(n_samples) / n_samples

        self.stumps = []
        self.alphas = []
        self.training_errors = []
        self.weights_history = [weights.copy()]

        for t in range(self.n_estimators):
            # 训练弱学习器
            stump = DecisionStump()
            stump.fit(X, y, weights)
            predictions = stump.predict(X)

            # 计算加权错误率
            error = np.sum(weights * (predictions != y))
            error = np.clip(error, 1e-10, 1 - 1e-10)  # 避免 log(0)

            # 计算学习器权重
            alpha = 0.5 * np.log((1 - error) / error)

            # 更新样本权重
            weights = weights * np.exp(-alpha * y * predictions)
            weights = weights / np.sum(weights)  # 归一化

            # 保存
            self.stumps.append(stump)
            self.alphas.append(alpha)
            self.weights_history.append(weights.copy())

            # 计算当前集成的训练错误
            ensemble_pred = self.predict(X)
            train_error = np.mean(ensemble_pred != y)
            self.training_errors.append(train_error)

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测类别。
        """
        n_samples = X.shape[0]
        weighted_predictions = np.zeros(n_samples)

        for stump, alpha in zip(self.stumps, self.alphas):
            weighted_predictions += alpha * stump.predict(X)

        return np.sign(weighted_predictions)
```

# 总结

1. **信息熵与基尼系数**: 衡量节点不纯度
2. **CART 算法**: 贪心地选择最佳划分
3) **决策树的特点**: 可解释、易过拟合、轴对齐边界
4) **Random Forest**: Bagging + 随机特征选择
5. **AdaBoost**: 迭代地关注困难样本
> "决策树简单直观，但容易过拟合。集成学习通过'三个臭皮匠赛过诸葛亮'的思想，将多个弱学习器组合成强学习器。"

| 特点 | Bagging | Boosting |
| ------ | -------------- | -------------- |
| 训练方式 | 并行训练（独立） | 串行训练（依赖前一个） |
| 数据采样 | Bootstrap（有放回） | 加权采样 |
| 学习器权重 | 相等 | 根据表现加权 |
| 目标 | 降低方差 | 降低偏差 |
| 过拟合风险 | 较低 | 较高 |
| 对噪声敏感度 | 较低 | 较高 |
| 代表算法 | Random Forest | AdaBoost, GBDT |

* **实践建议**

| 场景 | 推荐算法 |
| ------ | ------------------------------------- |
| 需要可解释性 | 浅决策树 |
| 高维数据 | Random Forest |
| 追求最高精度 | Gradient Boosting (XGBoost, LightGBM) |
| 在线学习 | AdaBoost |
