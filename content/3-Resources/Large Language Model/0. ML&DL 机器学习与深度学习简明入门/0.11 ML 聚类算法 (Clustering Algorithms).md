# 0.11.1 聚类直觉

***什么是聚类？***

聚类的目标是将数据点分成若干组（簇），使得：

* **簇内相似性高**：同一簇内的点彼此接近
* **簇间差异性大**：不同簇的点彼此远离

***K-Means 的直觉***

想象你有一群人站在操场上，你要把他们分成 K 个小组：

1. **随机指定 K 个组长的位置**
2. **每个人走向最近的组长**
3) **每个组长移动到自己组员的中心**
4) **重复步骤 2-3，直到稳定**

# 0.11.2 K-Means 算法

K-Means 的目标是最小化 **簇内平方和 (Within-Cluster Sum of Squares, WCSS)**：

$J = \sum_{k=1}^{K} \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$

其中：

* $K$ 是簇的数量
* $C_k$ 是第 $k$ 个簇中的点集
* $\mu_k$ 是第 $k$ 个簇的中心（均值）

**Lloyd 算法**

1. **初始化**：随机选择 K 个初始质心
2. **分配步骤 (E-step)**：将每个点分配到最近的质心
   $c_i = \arg\min_k \|x_i - \mu_k\|^2$
3) **更新步骤 (M-step)**：重新计算每个簇的质心
   $\mu_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i$
4) **重复** 2-3 直到收敛

```python
class KMeans:
    """
    K-Means 聚类算法。

    Parameters
    ----------
    n_clusters : int
        簇的数量
    max_iter : int
        最大迭代次数
    tol : float
        收敛容差
    random_state : int, optional
        随机种子
    """

    def __init__(self, n_clusters: int = 3, max_iter: int = 100,
                 tol: float = 1e-4, random_state: int = None):
        self.n_clusters = n_clusters
        self.max_iter = max_iter
        self.tol = tol
        self.random_state = random_state

        self.centroids = None
        self.labels_ = None
        self.inertia_ = None  # WCSS
        self.n_iter_ = 0
        self.history_ = []  # 用于可视化

    def _init_centroids(self, X: np.ndarray) -> np.ndarray:
        """
        随机初始化质心。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            数据点

        Returns
        -------
        np.ndarray, shape (n_clusters, n_features)
            初始质心
        """
        if self.random_state is not None:
            np.random.seed(self.random_state)

        n_samples = X.shape[0]
        indices = np.random.choice(n_samples, self.n_clusters, replace=False)
        return X[indices].copy()

    def _compute_distances(self, X: np.ndarray, centroids: np.ndarray) -> np.ndarray:
        """
        计算每个点到每个质心的距离。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            数据点
        centroids : np.ndarray, shape (n_clusters, n_features)
            质心

        Returns
        -------
        np.ndarray, shape (n_samples, n_clusters)
            距离矩阵
        """
        n_samples = X.shape[0]
        n_clusters = centroids.shape[0]

        distances = np.zeros((n_samples, n_clusters))
        for k in range(n_clusters):
            # 计算到第 k 个质心的欧氏距离的平方
            diff = X - centroids[k]
            distances[:, k] = np.sum(diff ** 2, axis=1)

        return distances

    def _assign_clusters(self, X: np.ndarray, centroids: np.ndarray) -> np.ndarray:
        """
        将每个点分配到最近的质心。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            数据点
        centroids : np.ndarray, shape (n_clusters, n_features)
            质心

        Returns
        -------
        np.ndarray, shape (n_samples,)
            簇标签
        """
        distances = self._compute_distances(X, centroids)
        return np.argmin(distances, axis=1)

    def _update_centroids(self, X: np.ndarray, labels: np.ndarray) -> np.ndarray:
        """
        更新质心为簇内点的均值。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            数据点
        labels : np.ndarray, shape (n_samples,)
            簇标签

        Returns
        -------
        np.ndarray, shape (n_clusters, n_features)
            新的质心
        """
        n_features = X.shape[1]
        new_centroids = np.zeros((self.n_clusters, n_features))

        for k in range(self.n_clusters):
            mask = labels == k
            if np.sum(mask) > 0:
                new_centroids[k] = X[mask].mean(axis=0)
            else:
                # 如果簇为空，保持原来的质心
                new_centroids[k] = self.centroids[k]

        return new_centroids

    def _compute_inertia(self, X: np.ndarray, labels: np.ndarray,
                          centroids: np.ndarray) -> float:
        """
        计算 WCSS (惯性)。
        """
        inertia = 0
        for k in range(self.n_clusters):
            mask = labels == k
            if np.sum(mask) > 0:
                diff = X[mask] - centroids[k]
                inertia += np.sum(diff ** 2)
        return inertia

    def fit(self, X: np.ndarray) -> 'KMeans':
        """
        拟合 K-Means 模型。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据

        Returns
        -------
        self
        """
        # 初始化质心
        self.centroids = self._init_centroids(X)
        self.history_ = [self.centroids.copy()]

        for iteration in range(self.max_iter):
            # E-step: 分配簇
            self.labels_ = self._assign_clusters(X, self.centroids)

            # M-step: 更新质心
            new_centroids = self._update_centroids(X, self.labels_)

            # 记录历史
            self.history_.append(new_centroids.copy())

            # 检查收敛
            shift = np.linalg.norm(new_centroids - self.centroids)
            self.centroids = new_centroids
            self.n_iter_ = iteration + 1

            if shift < self.tol:
                break

        # 计算最终的惯性
        self.inertia_ = self._compute_inertia(X, self.labels_, self.centroids)

        return self

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测新数据点的簇标签。
        """
        return self._assign_clusters(X, self.centroids)

    def fit_predict(self, X: np.ndarray) -> np.ndarray:
        """
        拟合并返回簇标签。
        """
        self.fit(X)
        return self.labels_
```

# 0.11.3 K-Means++ 初始化

随机初始化可能导致：

* 收敛到局部最优
* 某些簇可能为空
* 结果不稳定

**K-Means++ 算法**

核心思想：选择彼此距离较远的初始质心

1. 随机选择第一个质心
2. 对于每个数据点，计算它到最近已选质心的距离 $D(x)$
3) 以概率 $\frac{D(x)^2}{\sum_x D(x)^2}$ 选择下一个质心
4) 重复 2-3 直到选够 K 个质心

```python
class KMeansPlusPlus(KMeans):
    """
    使用 K-Means++ 初始化的 K-Means 聚类。
    """

    def _init_centroids(self, X: np.ndarray) -> np.ndarray:
        """
        K-Means++ 初始化。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            数据点

        Returns
        -------
        np.ndarray, shape (n_clusters, n_features)
            初始质心
        """
        if self.random_state is not None:
            np.random.seed(self.random_state)

        n_samples, n_features = X.shape
        centroids = np.zeros((self.n_clusters, n_features))

        # 1. 随机选择第一个质心
        first_idx = np.random.randint(n_samples)
        centroids[0] = X[first_idx]

        # 2. 选择剩余的质心
        for k in range(1, self.n_clusters):
            # 计算每个点到最近已选质心的距离平方
            distances = self._compute_distances(X, centroids[:k])
            min_distances = np.min(distances, axis=1)  # 到最近质心的距离

            # 3. 按距离平方的概率选择下一个质心
            probabilities = min_distances / np.sum(min_distances)
            next_idx = np.random.choice(n_samples, p=probabilities)
            centroids[k] = X[next_idx]

        return centroids
```

# 0.11.4 选择最优 K - 肘部法则

K-Means 需要预先指定 K。常用方法：

1. **肘部法则 (Elbow Method)**：绘制 WCSS vs K，找"肘部"
2. **轮廓系数 (Silhouette Score)**：衡量聚类质量
3) **领域知识**：根据业务需求

```python
def elbow_method(X, k_range=range(1, 11)):
    """
    使用肘部法则选择最优 K。
    """
    inertias = []

    for k in k_range:
        km = KMeansPlusPlus(n_clusters=k, random_state=42)
        km.fit(X)
        inertias.append(km.inertia_)

    # 可视化

    ax.plot(list(k_range), inertias, 'o-', color=COLORS['primary'],
            linewidth=2, markersize=8)

    # 标记肘部（简单方法：找二阶导数最大的点）
    # 这里假设真实 K=3

    ax.scatter([elbow_k], [inertias[elbow_k-1]], color=COLORS['danger'],
```

# 0.11.5 DBSCAN 算法

* **基于密度的聚类**
  K-Means 的局限：
  * 假设簇是球形的
  * 需要预先指定 K
  * 对噪声敏感
  **DBSCAN** (Density-Based Spatial Clustering of Applications with Noise) 的优点：
  * 可以发现任意形状的簇
  * 自动识别噪声点
  * 不需要指定簇的数量
* **核心概念**
  * ** $\epsilon$ (eps)**：邻域半径
  * **MinPts**：形成核心点所需的最小邻居数
  * **核心点 (Core Point)**：$\epsilon$ 邻域内至少有 MinPts 个点
  * **边界点 (Border Point)**：不是核心点，但在某核心点的邻域内
  * **噪声点 (Noise Point)**：既不是核心点也不是边界点

```python
class DBSCAN:
    """
    DBSCAN 聚类算法。

    Parameters
    ----------
    eps : float
        邻域半径
    min_samples : int
        形成核心点所需的最小样本数
    """

    def __init__(self, eps: float = 0.5, min_samples: int = 5):
        self.eps = eps
        self.min_samples = min_samples
        self.labels_ = None
        self.core_sample_indices_ = None

    def _compute_neighbors(self, X: np.ndarray, point_idx: int) -> np.ndarray:
        """
        找到指定点的所有邻居。

        Parameters
        ----------
        X : np.ndarray
            数据点
        point_idx : int
            查询点的索引

        Returns
        -------
        np.ndarray
            邻居的索引
        """
        distances = np.sqrt(np.sum((X - X[point_idx])**2, axis=1))
        return np.where(distances <= self.eps)[0]

    def fit(self, X: np.ndarray) -> 'DBSCAN':
        """
        拟合 DBSCAN 模型。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据

        Returns
        -------
        self
        """
        n_samples = X.shape[0]

        # -1 表示未访问，-2 表示噪声
        self.labels_ = np.full(n_samples, -1)

        # 找出所有核心点
        core_samples = []
        neighbors_list = []

        for i in range(n_samples):
            neighbors = self._compute_neighbors(X, i)
            neighbors_list.append(neighbors)
            if len(neighbors) >= self.min_samples:
                core_samples.append(i)

        self.core_sample_indices_ = np.array(core_samples)

        # 聚类
        cluster_id = 0

        for i in range(n_samples):
            # 跳过已访问的点
            if self.labels_[i] != -1:
                continue

            # 如果不是核心点，标记为噪声（可能后续变成边界点）
            if i not in core_samples:
                self.labels_[i] = -2  # 暂时标记为噪声
                continue

            # 从核心点开始扩展簇
            self._expand_cluster(X, i, neighbors_list[i], cluster_id,
                                 core_samples, neighbors_list)
            cluster_id += 1

        # 将剩余的噪声点标记为 -1
        self.labels_[self.labels_ == -2] = -1

        return self

    def _expand_cluster(self, X, point_idx, neighbors, cluster_id,
                        core_samples, neighbors_list):
        """
        扩展簇。
        """
        self.labels_[point_idx] = cluster_id

        # 使用队列进行广度优先搜索
        queue = list(neighbors)
        i = 0

        while i < len(queue):
            neighbor_idx = queue[i]
            i += 1

            # 如果是噪声点，变成边界点
            if self.labels_[neighbor_idx] == -2:
                self.labels_[neighbor_idx] = cluster_id

            # 如果已经属于某个簇，跳过
            if self.labels_[neighbor_idx] != -1:
                continue

            # 标记为当前簇
            self.labels_[neighbor_idx] = cluster_id

            # 如果是核心点，扩展其邻居
            if neighbor_idx in core_samples:
                neighbor_neighbors = neighbors_list[neighbor_idx]
                queue.extend(neighbor_neighbors)

    def fit_predict(self, X: np.ndarray) -> np.ndarray:
        """
        拟合并返回簇标签。
        """
        self.fit(X)
        return self.labels_
```

# 0.11.6 层次聚类

层次聚类构建簇的层级结构，可以是：

* **自底向上（凝聚式）**：开始时每个点是一个簇，逐步合并
* **自顶向下（分裂式）**：开始时所有点在一个簇，逐步分裂

链接方法 (Linkage)：

定义簇间距离的方法：

* **单链接 (Single)**：最近点之间的距离
* **全链接 (Complete)**：最远点之间的距离
* **平均链接 (Average)**：所有点对距离的平均
* **Ward 链接**：最小化簇内方差

```python
class AgglomerativeClustering:
    """
    凝聚式层次聚类。

    Parameters
    ----------
    n_clusters : int
        目标簇数量
    linkage : str
        链接方法 ('single', 'complete', 'average', 'ward')
    """

    def __init__(self, n_clusters: int = 2, linkage: str = 'ward'):
        self.n_clusters = n_clusters
        self.linkage = linkage
        self.labels_ = None
        self.linkage_matrix_ = None

    def _compute_distance_matrix(self, X: np.ndarray) -> np.ndarray:
        """
        计算点之间的距离矩阵。
        """
        n_samples = X.shape[0]
        dist_matrix = np.zeros((n_samples, n_samples))

        for i in range(n_samples):
            for j in range(i + 1, n_samples):
                dist = np.sqrt(np.sum((X[i] - X[j])**2))
                dist_matrix[i, j] = dist
                dist_matrix[j, i] = dist

        return dist_matrix

    def _cluster_distance(self, cluster1_indices, cluster2_indices,
                          X, dist_matrix):
        """
        计算两个簇之间的距离。
        """
        if self.linkage == 'single':
            # 最小距离
            min_dist = np.inf
            for i in cluster1_indices:
                for j in cluster2_indices:
                    if dist_matrix[i, j] < min_dist:
                        min_dist = dist_matrix[i, j]
            return min_dist

        elif self.linkage == 'complete':
            # 最大距离
            max_dist = 0
            for i in cluster1_indices:
                for j in cluster2_indices:
                    if dist_matrix[i, j] > max_dist:
                        max_dist = dist_matrix[i, j]
            return max_dist

        elif self.linkage == 'average':
            # 平均距离
            total_dist = 0
            count = 0
            for i in cluster1_indices:
                for j in cluster2_indices:
                    total_dist += dist_matrix[i, j]
                    count += 1
            return total_dist / count

        elif self.linkage == 'ward':
            # Ward: 合并后方差增量
            c1_points = X[list(cluster1_indices)]
            c2_points = X[list(cluster2_indices)]

            c1_mean = np.mean(c1_points, axis=0)
            c2_mean = np.mean(c2_points, axis=0)

            n1, n2 = len(cluster1_indices), len(cluster2_indices)

            # Ward 距离公式
            return np.sqrt(2 * n1 * n2 / (n1 + n2) * np.sum((c1_mean - c2_mean)**2))

    def fit(self, X: np.ndarray) -> 'AgglomerativeClustering':
        """
        拟合层次聚类模型。

        始终构建完整层次结构（合并到 1 个簇），以便生成
        与 scipy dendrogram 兼容的 linkage_matrix_。
        然后通过回放合并历史来分配 n_clusters 个簇的标签。
        """
        n_samples = X.shape[0]

        # 计算距离矩阵
        dist_matrix = self._compute_distance_matrix(X)

        # 初始化：每个点是一个簇
        clusters = {i: {i} for i in range(n_samples)}
        active_clusters = set(range(n_samples))

        # 链接矩阵：scipy 格式 [c1, c2, distance, size]
        # 第 i 行的合并创建簇 ID = n_samples + i
        linkage_rows = []
        next_cluster_id = n_samples
        cluster_sizes = {i: 1 for i in range(n_samples)}

        # 完整合并直到只剩 1 个簇（生成 n_samples - 1 行）
        while len(active_clusters) > 1:
            # 找到最近的两个簇
            min_dist = np.inf
            merge_pair = None

            active_list = sorted(list(active_clusters))
            for idx, c1 in enumerate(active_list):
                for c2 in active_list[idx+1:]:
                    dist = self._cluster_distance(clusters[c1], clusters[c2],
                                                   X, dist_matrix)
                    if dist < min_dist:
                        min_dist = dist
                        merge_pair = (c1, c2)

            if merge_pair is None:
                break

            # 合并两个簇
            c1, c2 = merge_pair
            new_cluster = clusters[c1].union(clusters[c2])
            clusters[next_cluster_id] = new_cluster
            new_size = cluster_sizes[c1] + cluster_sizes[c2]
            cluster_sizes[next_cluster_id] = new_size

            # 记录链接矩阵行（确保 c1 < c2）
            lc1, lc2 = min(c1, c2), max(c1, c2)
            linkage_rows.append([float(lc1), float(lc2), min_dist, float(new_size)])

            # 更新活跃簇
            active_clusters.remove(merge_pair[0])
            active_clusters.remove(merge_pair[1])
            active_clusters.add(next_cluster_id)

            next_cluster_id += 1

        self.linkage_matrix_ = np.array(linkage_rows)

        # 从完整层次结构中提取 n_clusters 个簇的标签
        # 回放合并历史，在合并 n_samples - n_clusters 步后停止
        replay_clusters = {i: {i} for i in range(n_samples)}
        replay_active = set(range(n_samples))
        replay_next_id = n_samples

        n_merges_needed = n_samples - self.n_clusters
        for row_idx in range(n_merges_needed):
            row = self.linkage_matrix_[row_idx]
            c1, c2 = int(row[0]), int(row[1])
            new_set = replay_clusters.get(c1, set()).union(replay_clusters.get(c2, set()))
            replay_clusters[replay_next_id] = new_set
            replay_active.discard(c1)
            replay_active.discard(c2)
            replay_active.add(replay_next_id)
            replay_next_id += 1

        # 分配标签
        self.labels_ = np.zeros(n_samples, dtype=int)
        for label, cluster_id in enumerate(sorted(replay_active)):
            for point_idx in replay_clusters[cluster_id]:
                self.labels_[point_idx] = label

        return self

    def fit_predict(self, X: np.ndarray) -> np.ndarray:
        self.fit(X)
        return self.labels_
```

# 0.11.7 聚类评估 - 轮廓系数

* **轮廓系数的定义：** 对于每个样本 $i$：$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$
  其中：
  * $a(i)$：样本 $i$ 到同簇其他样本的平均距离（**簇内距离**）
  * $b(i)$：样本 $i$ 到最近其他簇所有样本的平均距离（**最近簇距离**）
  轮廓系数范围：$[-1, 1]$
  * $s \approx 1$：样本远离其他簇，聚类良好
  * $s \approx 0$：样本在簇边界
  * $s \approx -1$：样本可能被分错簇

```python
def silhouette_score(X: np.ndarray, labels: np.ndarray) -> float:
    """
    计算轮廓系数。

    Parameters
    ----------
    X : np.ndarray, shape (n_samples, n_features)
        数据点
    labels : np.ndarray, shape (n_samples,)
        簇标签

    Returns
    -------
    float
        平均轮廓系数
    """
    n_samples = len(X)
    unique_labels = np.unique(labels)

    # 如果只有一个簇，返回 0
    if len(unique_labels) == 1:
        return 0.0

    silhouettes = np.zeros(n_samples)

    for i in range(n_samples):
        # 当前点的簇
        current_cluster = labels[i]

        # 计算 a(i)：簇内平均距离
        same_cluster_mask = (labels == current_cluster)
        same_cluster_mask[i] = False  # 排除自己

        if np.sum(same_cluster_mask) > 0:
            same_cluster_points = X[same_cluster_mask]
            a_i = np.mean(np.sqrt(np.sum((same_cluster_points - X[i])**2, axis=1)))
        else:
            a_i = 0

        # 计算 b(i)：最近其他簇的平均距离
        b_i = np.inf
        for label in unique_labels:
            if label == current_cluster:
                continue

            other_cluster_points = X[labels == label]
            avg_dist = np.mean(np.sqrt(np.sum((other_cluster_points - X[i])**2, axis=1)))

            if avg_dist < b_i:
                b_i = avg_dist

        # 计算轮廓系数
        if max(a_i, b_i) > 0:
            silhouettes[i] = (b_i - a_i) / max(a_i, b_i)
        else:
            silhouettes[i] = 0

    return np.mean(silhouettes), silhouettes

def silhouette_samples(X: np.ndarray, labels: np.ndarray) -> np.ndarray:
    """
    返回每个样本的轮廓系数。
    """
    _, samples = silhouette_score(X, labels)
    return samples
```

```python
def select_k_by_silhouette(X, k_range=range(2, 10)):
    """
    使用轮廓系数选择最优 K。
    """
    scores = []

    for k in k_range:
        km = KMeansPlusPlus(n_clusters=k, random_state=42)
        labels = km.fit_predict(X)
        score, _ = silhouette_score(X, labels)
        scores.append(score)

    # 标记最优 K
    best_k_idx = np.argmax(scores)
    best_k = list(k_range)[best_k_idx]

    return best_k
```

# K-Means 是否保证收敛？收敛到什么？

1. K-Means 保证收敛（在有限步内）
   证明：
   * 目标函数 $J = Σ||x_i - μ_{c_i}||²$ 是有下界的（≥0）
   * 每次迭代（E步或M步）都不会增加 J
   * 划分方案的数量是有限的（K^n 种）
   * 因此算法必然收敛
2. 收敛到 **局部最优**，不一定是全局最优
   * 目标函数是非凸的
   * 结果依赖于初始化
   * K-Means++ 初始化可以改善结果
3) 实践建议：
   * 多次运行，取最优结果
   * 使用 K-Means++ 初始化
   * 设置最大迭代次数作为保险

# 总结

### 关键要点

1. **K-Means**：
   * 简单高效，适用于球形簇
   * 需要预先指定 K
   * K-Means++ 初始化可显著改善结果
2. **DBSCAN**：
   * 基于密度，可发现任意形状簇
   * 自动识别噪声点
   * 不需要指定簇数量，但需要 eps 和 min\_samples
3) **层次聚类**：
   * 产生树状结构
   * 不同链接方法适用于不同场景
   * 可视化友好（树状图）
4) **评估指标**：
   * 轮廓系数：衡量簇的紧密度和分离度
   * 肘部法则：选择最优 K

### 算法选择指南

| 场景 | 推荐算法 |
| -------- | ------------------ |
| 球形簇，已知 K | K-Means |
| 任意形状，有噪声 | DBSCAN |
| 需要层级结构 | 层次聚类 |
| 大规模数据 | Mini-Batch K-Means |
