# 0.1.1 梯度的几何观

想象你站在山坡上，想要找到最低点（谷底），梯度就是指向 **最陡上升方向** 的向量

* **梯度的方向**：函数增长最快的方向
* **梯度的大小**：该方向上的增长率
* **负梯度**：下降最快的方向（这就是为什么我们沿负梯度方向更新参数）

关键洞察：*梯度始终与等高线垂直！*

## 梯度的基本定义与运算

* **偏导数与梯度：** 对于多变量函数 $f: \mathbb{R}^n \to \mathbb{R}$，在点 $\mathbf{x} = (x_1, x_2, \ldots, x_n)$ 的 **梯度** 定义为：$\nabla f(\mathbf{x}) = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \frac{\partial f}{\partial x_2} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{bmatrix}$
* **方向导数：** 沿单位向量 $\mathbf{u}$ 方向的 **方向导数**：$D_{\mathbf{u}} f(\mathbf{x}) = \nabla f(\mathbf{x}) \cdot \mathbf{u} = \|\nabla f(\mathbf{x})\| \cos\theta$，其中 $\theta$ 是 $\nabla f$ 与 $\mathbf{u}$ 的夹角
* **结论**：
  * 当 $\theta = 0$（沿梯度方向），方向导数最大
  * 当 $\theta = \pi$（沿负梯度方向），方向导数最小
  * 当 $\theta = \pi/2$（垂直于梯度），方向导数为零（等高线方向）

```python
def numerical_gradient(f, x, eps=1e-7):
    """
    使用中心差分法计算数值梯度。

    Parameters
    ----------
    f : callable
        目标函数
    x : np.ndarray
        计算梯度的点
    eps : float
        差分步长

    Returns
    -------
    np.ndarray
        数值梯度
    """
    x = np.array(x, dtype=float)
    grad = np.zeros_like(x)

    for i in range(len(x)):
        x_plus = x.copy()
        x_minus = x.copy()
        x_plus[i] += eps
        x_minus[i] -= eps
        grad[i] = (f(x_plus) - f(x_minus)) / (2 * eps)

    return grad
```

# 0.1.2 Hessian 矩阵与二阶信息

> 如果梯度告诉我们"坡度有多陡"，那么 Hessian 告诉我们"坡度变化有多快"

* **正定 Hessian**：像碗底，四面上升 → 局部最小值
* **负定 Hessian**：像山顶，四面下降 → 局部最大值
* **不定 Hessian**：像马鞍，有些方向上升，有些下降 → 鞍点

**Hessian 矩阵定义：** 对于 $f: \mathbb{R}^n \to \mathbb{R}$，**Hessian 矩阵** $\mathbf{H}$ 是二阶偏导数组成的矩阵：

$$\mathbf{H} = \nabla^2 f = \begin{bmatrix}
\frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots & \frac{\partial^2 f}{\partial x_1 \partial x_n} \\
\frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \cdots & \frac{\partial^2 f}{\partial x_2 \partial x_n} \\
\vdots & \vdots & \ddots & \vdots \\
\frac{\partial^2 f}{\partial x_n \partial x_1} & \frac{\partial^2 f}{\partial x_n \partial x_2} & \cdots & \frac{\partial^2 f}{\partial x_n^2}
\end{bmatrix}$$

**泰勒展开（二阶）：** $f(\mathbf{x} + \mathbf{d}) \approx f(\mathbf{x}) + \nabla f(\mathbf{x})^T \mathbf{d} + \frac{1}{2} \mathbf{d}^T \mathbf{H} \mathbf{d}$

**二阶条件（临界点分类）：** 在临界点 $\mathbf{x}^*$（$\nabla f(\mathbf{x}^*) = \mathbf{0}$）处：



| Hessian 特性 | 结论 |
| --- | --- |
| 正定 ($\mathbf{H} \succ 0$) | 严格局部最小值 |
| 负定 ($\mathbf{H} \prec 0$) | 严格局部最大值 |
| 不定 | 鞍点 |
| 半定 | 需要更高阶分析 |

# 0.1.3 凸函数与凸优化

凸函数就像一个碗：

* 任何两点之间的"弦"都在函数图像"上方"
* 只有一个最低点（全局最小值）
* 从任何地方"滚下去"都会到达同一个底部

为什么凸性如此重要？

> 凸优化问题的局部最优就是全局最优！

* **凸集：** 集合 $C$ 是 **凸集**，当且仅当对于任意 $\mathbf{x}, \mathbf{y} \in C$ 和 $\theta \in [0, 1]$：$\theta \mathbf{x} + (1-\theta) \mathbf{y} \in C$
* **凸函数：** 函数 $f: C \to \mathbb{R}$（ $C$ 是凸集）是 **凸函数**，当且仅当：$f(\theta \mathbf{x} + (1-\theta) \mathbf{y}) \leq \theta f(\mathbf{x}) + (1-\theta) f(\mathbf{y})$
* **凸函数的等价条件：** 对于二阶可微函数，以下条件等价：
  1. **定义条件**：上述不等式成立
  2. **一阶条件**：$f(\mathbf{y}) \geq f(\mathbf{x}) + \nabla f(\mathbf{x})^T (\mathbf{y} - \mathbf{x})$
  3) **二阶条件**： $\mathbf{H} = \nabla^2 f(\mathbf{x}) \succeq 0$（Hessian 半正定）
* **强凸函数：** 函数 $f$ 是 ** $m$-强凸** 的，如果：$f(\mathbf{y}) \geq f(\mathbf{x}) + \nabla f(\mathbf{x})^T (\mathbf{y} - \mathbf{x}) + \frac{m}{2} \|\mathbf{y} - \mathbf{x}\|^2$，等价地：$\mathbf{H} \succeq m\mathbf{I}$

## 梯度下降算法

梯度下降就像在雾中下山：

1. 感受脚下最陡峭的下坡方向（计算负梯度）
2. 沿该方向走一小步（更新参数）
3) 重复直到到达谷底（收敛）

关键决策：每步走多远？（学习率 $\alpha$）

* **基本梯度下降：**

更新规则：$\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha \nabla f(\mathbf{x}_t)$，其中 $\alpha > 0$ 是学习率（步长）

* **收敛条件：** 对于 $L$-光滑的凸函数（ $\|\nabla f(\mathbf{x}) - \nabla f(\mathbf{y})\| \leq L\|\mathbf{x} - \mathbf{y}\|$）：当 $\alpha \leq \frac{1}{L}$ 时，保证收敛，且：$f(\mathbf{x}_t) - f(\mathbf{x}^*) \leq \frac{\|\mathbf{x}_0 - \mathbf{x}^*\|^2}{2\alpha t}$
* **强凸函数的加速收敛：** 对于 $m$-强凸、 $L$-光滑的函数：$\|\mathbf{x}_t - \mathbf{x}^*\|^2 \leq \left(1 - \frac{m}{L}\right)^t \|\mathbf{x}_0 - \mathbf{x}^*\|^2$

收敛速度取决于 **条件数** $$
\kappa = L/m$$

```python
class GradientDescent:
    """
    梯度下降优化器。

    Parameters
    ----------
    learning_rate : float
        学习率
    max_iter : int
        最大迭代次数
    tol : float
        收敛容差
    """

    def __init__(self, learning_rate: float = 0.1, max_iter: int = 1000,
                 tol: float = 1e-6):
        self.learning_rate = learning_rate
        self.max_iter = max_iter
        self.tol = tol
        self.history = []

    def optimize(self, f, grad_f, x0):
        """
        执行梯度下降优化。

        Parameters
        ----------
        f : callable
            目标函数
        grad_f : callable
            梯度函数
        x0 : np.ndarray
            初始点

        Returns
        -------
        np.ndarray
            最优解
        """
        x = np.array(x0, dtype=float)
        self.history = [{'x': x.copy(), 'f': f(x), 'grad_norm': np.linalg.norm(grad_f(x))}]

        for i in range(self.max_iter):
            grad = grad_f(x)
            grad_norm = np.linalg.norm(grad)

            # 检查收敛
            if grad_norm < self.tol:
                break

            # 更新
            x = x - self.learning_rate * grad

            # 记录历史
            self.history.append({
                'x': x.copy(),
                'f': f(x),
                'grad_norm': np.linalg.norm(grad_f(x))
            })

        return x

    def get_trajectory(self):
        """
        获取优化轨迹。

        Returns
        -------
        np.ndarray
            轨迹点数组，shape (n_steps, n_dims)
        """
        return np.array([h['x'] for h in self.history])
```

```python
def rosenbrock(x):
    """
    Rosenbrock 函数（香蕉函数）：f(x,y) = (1-x)² + 100(y-x²)²
```

# 0.1.4 动量法与自适应学习率

## 动量法 (Momentum)

> 想象一个球在山坡上滚动：
> * 它有"惯性"，会积累速度
> * 在平坦区域保持速度，加快收敛
> * 在陡峭区域减速，避免过冲

$\mathbf{v}_{t+1} = \beta \mathbf{v}_t + \nabla f(\mathbf{x}_t)$, $\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha \mathbf{v}_{t+1}$, 其中 $\beta \in [0, 1)$ 是动量系数。

```python
class MomentumGD:
    """
    带动量的梯度下降。

    Parameters
    ----------
    learning_rate : float
        学习率
    momentum : float
        动量系数
    max_iter : int
        最大迭代次数
    tol : float
        收敛容差
    """

    def __init__(self, learning_rate: float = 0.01, momentum: float = 0.9,
                 max_iter: int = 1000, tol: float = 1e-6):
        self.learning_rate = learning_rate
        self.momentum = momentum
        self.max_iter = max_iter
        self.tol = tol
        self.history = []

    def optimize(self, f, grad_f, x0):
        """
        执行带动量的梯度下降。
        """
        x = np.array(x0, dtype=float)
        v = np.zeros_like(x)  # 初始速度为零

        self.history = [{'x': x.copy(), 'f': f(x)}]

        for i in range(self.max_iter):
            grad = grad_f(x)

            if np.linalg.norm(grad) < self.tol:
                break

            # 更新速度和位置
            v = self.momentum * v + grad
            x = x - self.learning_rate * v

            self.history.append({'x': x.copy(), 'f': f(x)})

        return x

    def get_trajectory(self):
        return np.array([h['x'] for h in self.history])
```

## Adam 优化器

Adam 结合了动量和自适应学习率的优点:

* 一阶矩估计（动量）：$\mathbf{m}_t = \beta_1 \mathbf{m}_{t-1} + (1 - \beta_1) \nabla f(\mathbf{x}_t)$
* 二阶矩估计（自适应学习率）：$\mathbf{v}_t = \beta_2 \mathbf{v}_{t-1} + (1 - \beta_2) (\nabla f(\mathbf{x}_t))^2$
* 偏差修正：$\hat{\mathbf{m}}_t = \frac{\mathbf{m}_t}{1 - \beta_1^t}, \quad \hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1 - \beta_2^t}$
* 更新：$\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha \frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon}$

```python
class Adam:
    """
    Adam 优化器。

    Parameters
    ----------
    learning_rate : float
        学习率
    beta1 : float
        一阶矩衰减率
    beta2 : float
        二阶矩衰减率
    epsilon : float
        数值稳定项
    max_iter : int
        最大迭代次数
    tol : float
        收敛容差
    """

    def __init__(self, learning_rate: float = 0.01, beta1: float = 0.9,
                 beta2: float = 0.999, epsilon: float = 1e-8,
                 max_iter: int = 1000, tol: float = 1e-6):
        self.learning_rate = learning_rate
        self.beta1 = beta1
        self.beta2 = beta2
        self.epsilon = epsilon
        self.max_iter = max_iter
        self.tol = tol
        self.history = []

    def optimize(self, f, grad_f, x0):
        """
        执行 Adam 优化。
        """
        x = np.array(x0, dtype=float)
        m = np.zeros_like(x)  # 一阶矩
        v = np.zeros_like(x)  # 二阶矩

        self.history = [{'x': x.copy(), 'f': f(x)}]

        for t in range(1, self.max_iter + 1):
            grad = grad_f(x)

            if np.linalg.norm(grad) < self.tol:
                break

            # 更新一阶矩和二阶矩
            m = self.beta1 * m + (1 - self.beta1) * grad
            v = self.beta2 * v + (1 - self.beta2) * grad**2

            # 偏差修正
            m_hat = m / (1 - self.beta1**t)
            v_hat = v / (1 - self.beta2**t)

            # 更新参数
            x = x - self.learning_rate * m_hat / (np.sqrt(v_hat) + self.epsilon)

            self.history.append({'x': x.copy(), 'f': f(x)})

        return x

    def get_trajectory(self):
        return np.array([h['x'] for h in self.history])
```

# 0.1.5 牛顿法与二阶优化

牛顿法利用二阶信息（曲率）来选择更好的步长和方向：

* 在曲率大的方向走小步
* 在曲率小的方向走大步
* 理想情况下一步到位

**牛顿法更新：** $\mathbf{x}_{t+1} = \mathbf{x}_t - [\mathbf{H}(\mathbf{x}_t)]^{-1} \nabla f(\mathbf{x}_t)$

**推导（二阶泰勒展开）：**

* 在 $\mathbf{x}_t$ 处二阶泰勒展开：$f(\mathbf{x}) \approx f(\mathbf{x}_t) + \nabla f(\mathbf{x}_t)^T (\mathbf{x} - \mathbf{x}_t) + \frac{1}{2} (\mathbf{x} - \mathbf{x}_t)^T \mathbf{H} (\mathbf{x} - \mathbf{x}_t)$
* 对 $\mathbf{x}$ 求导并令其为零：$\nabla f(\mathbf{x}_t) + \mathbf{H}(\mathbf{x} - \mathbf{x}_t) = \mathbf{0}$
* 解得：$\mathbf{x} = \mathbf{x}_t - \mathbf{H}^{-1} \nabla f(\mathbf{x}_t)$

```python
class NewtonMethod:
    """
    牛顿法优化器。

    Parameters
    ----------
    max_iter : int
        最大迭代次数
    tol : float
        收敛容差
    """

    def __init__(self, max_iter: int = 100, tol: float = 1e-8):
        self.max_iter = max_iter
        self.tol = tol
        self.history = []

    def optimize(self, f, grad_f, hess_f, x0):
        """
        执行牛顿法优化。

        Parameters
        ----------
        f : callable
            目标函数
        grad_f : callable
            梯度函数
        hess_f : callable
            Hessian 函数
        x0 : np.ndarray
            初始点
        """
        x = np.array(x0, dtype=float)
        self.history = [{'x': x.copy(), 'f': f(x)}]

        for i in range(self.max_iter):
            grad = grad_f(x)

            if np.linalg.norm(grad) < self.tol:
                break

            H = hess_f(x)

            # 牛顿步
            try:
                step = np.linalg.solve(H, grad)
            except np.linalg.LinAlgError:
                # Hessian 奇异，回退到梯度下降
                step = 0.01 * grad

            x = x - step
            self.history.append({'x': x.copy(), 'f': f(x)})

        return x

    def get_trajectory(self):
        return np.array([h['x'] for h in self.history])
```

# 0.1.6实现带线搜索的梯度下降

实现使用 Armijo 条件的回溯线搜索

```python
# 练习 3 答案
def armijo_line_search(f, grad_f, x, direction, alpha_init=1.0, c=0.1, rho=0.5):
    """
    Armijo 回溯线搜索。

    Parameters
    ----------
    f : callable
        目标函数
    grad_f : callable
        梯度函数
    x : np.ndarray
        当前点
    direction : np.ndarray
        搜索方向（通常是负梯度）
    alpha_init : float
        初始步长
    c : float
        Armijo 常数
    rho : float
        步长缩减因子

    Returns
    -------
    float
        满足 Armijo 条件的步长
    """
    alpha = alpha_init
    fx = f(x)
    grad = grad_f(x)
    slope = np.dot(grad, direction)

    while f(x + alpha * direction) > fx + c * alpha * slope:
        alpha *= rho
        if alpha < 1e-10:
            break

    return alpha

class GradientDescentWithLineSearch:
    """
    带线搜索的梯度下降。
    """

    def __init__(self, max_iter=1000, tol=1e-6):
        self.max_iter = max_iter
        self.tol = tol
        self.history = []

    def optimize(self, f, grad_f, x0):
        x = np.array(x0, dtype=float)
        self.history = [{'x': x.copy(), 'f': f(x)}]

        for i in range(self.max_iter):
            grad = grad_f(x)

            if np.linalg.norm(grad) < self.tol:
                break

            # 搜索方向（负梯度）
            direction = -grad

            # 线搜索
            alpha = armijo_line_search(f, grad_f, x, direction)

            # 更新
            x = x + alpha * direction
            self.history.append({'x': x.copy(), 'f': f(x)})

        return x

    def get_trajectory(self):
        return np.array([h['x'] for h in self.history])

# 测试
```
