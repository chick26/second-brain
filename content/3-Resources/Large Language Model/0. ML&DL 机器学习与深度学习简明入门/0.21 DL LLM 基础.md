### 7.1 分词算法

**Byte-Pair Encoding (BPE)**：

1. 初始化：每个字节作为一个 token
2. 迭代：合并频率最高的相邻 token 对
3) 重复直到达到目标词表大小

**优势**：平衡词表大小和序列长度，处理未登录词。

#### 理论分析：压缩率权衡

**词表大小的影响**

* 小词表（如 256）：序列长，计算慢
* 大词表（如 100k）：嵌入矩阵大，罕见词泛化差

**BPE 的贪心策略**：每次选择频率最高的 pair 合并

$\text{score}(a, b) = \frac{\text{count}(a, b)}{\text{count}(a) \times \text{count}(b)}$

**压缩率**：

$\text{Compression} = \frac{\text{原始字符数}}{\text{token 数}}$

通常 BPE 可达 $3\sim5$ 倍压缩（英文）。

#### 核心实现

```python
class BPETokenizer:
    def __init__(self, vocab_size=1000):
        self.vocab_size = vocab_size
        self.vocab = {}
        self.merges = []

    def train(self, texts):
        """训练 BPE"""
        # 初始化：每个字节作为 token
        word_freqs = {}
        for text in texts:
            for word in text.split():
                word_freqs[word] = word_freqs.get(word, 0) + 1

        # 将单词拆分为字符
        splits = {word: list(word) for word in word_freqs.keys()}

        # 迭代合并
        while len(self.vocab) < self.vocab_size:
            # 统计相邻 token 对的频率
            pair_freqs = {}
            for word, freq in word_freqs.items():
                split = splits[word]
                for i in range(len(split) - 1):
                    pair = (split[i], split[i+1])
                    pair_freqs[pair] = pair_freqs.get(pair, 0) + freq

            if not pair_freqs:
                break

            # 选择频率最高的 pair
            best_pair = max(pair_freqs, key=pair_freqs.get)
            self.merges.append(best_pair)

            # 合并
            for word in word_freqs:
                split = splits[word]
                i = 0
                while i < len(split) - 1:
                    if (split[i], split[i+1]) == best_pair:
                        split[i] = split[i] + split[i+1]
                        del split[i+1]
                    else:
                        i += 1
                splits[word] = split

    def encode(self, text):
        """编码文本为 token IDs"""
        tokens = list(text)
        for pair in self.merges:
            i = 0
            while i < len(tokens) - 1:
                if (tokens[i], tokens[i+1]) == pair:
                    tokens[i] = tokens[i] + tokens[i+1]
                    del tokens[i+1]
                else:
                    i += 1
        return [self.vocab.get(t, 0) for t in tokens]
```

### 7.2 参数高效微调

**低秩分解**：

$W' = W_0 + \Delta W = W_0 + BA$

其中 $B \in \mathbb{R}^{d \times r}$， $A \in \mathbb{R}^{r \times k}$，$r \ll \min(d, k)$

**参数量对比**：

$$\text{Full Fine-tuning: } d \times k \\
\text{LoRA: } (d + k) \times r$$

#### 理论基础：低秩假设

**核心假设**：微调时权重更新 $\Delta W$ 的内在维度很低。

**证明直觉**：

* 预训练模型已学习通用特征
* 微调只需调整少量方向（任务特定）

**秩 r 的选择**：

* $r=1$：单个方向（过于简单）
* $r=8$：典型选择（平衡性能和参数）
* $r=64$：接近全量微调

**参数减少比例**：

对于 GPT-3 的单层（ $d=12288, k=12288$）：

$\frac{(d+k) \times r}{d \times k} = \frac{24576 \times 8}{12288^2} \approx 0.013 \quad (1.3\%)$

**推理优势**：可以将 $BA$ 合并到 $W_0$，无额外计算开销！

#### 核心实现

```python
class LoRALinear(Module):
    def __init__(self, in_features, out_features, rank=8, alpha=16):
        super().__init__()
        # 冻结的预训练权重
        self.weight = Tensor(np.random.randn(in_features, out_features) * 0.01, False)

        # LoRA 低秩分解
        self.lora_A = Tensor(np.random.randn(in_features, rank) * 0.01, True)
        self.lora_B = Tensor(np.zeros((rank, out_features)), True)

        self.rank = rank
        self.alpha = alpha
        self.scaling = alpha / rank

    def forward(self, x):
        # 原始输出
        result = x @ self.weight.data

        # LoRA 增量
        lora_output = (x @ self.lora_A.data) @ self.lora_B.data
        result += lora_output * self.scaling

        return Tensor(result, requires_grad=True)

    def merge_weights(self):
        """推理时合并权重"""
        delta_W = self.lora_A.data @ self.lora_B.data * self.scaling
        self.weight.data += delta_W
        # 清空 LoRA 参数
        self.lora_A = None
        self.lora_B = None

class LoRATransformer(Module):
    def __init__(self, base_model, rank=8):
        super().__init__()
        self.base_model = base_model

        # 只对 Attention 的 Q, V 矩阵应用 LoRA
        for block in base_model.blocks:
            block.attn.W_q = LoRALinear.from_linear(block.attn.W_q, rank)
            block.attn.W_v = LoRALinear.from_linear(block.attn.W_v, rank)

    def trainable_parameters(self):
        """只返回 LoRA 参数"""
        params = []
        for block in self.base_model.blocks:
            params.extend([block.attn.W_q.lora_A, block.attn.W_q.lora_B])
            params.extend([block.attn.W_v.lora_A, block.attn.W_v.lora_B])
        return params
```
