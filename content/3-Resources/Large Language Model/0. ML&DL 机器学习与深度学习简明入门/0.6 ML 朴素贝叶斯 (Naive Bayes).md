> > "Despite its simplicity, Naive Bayes often outperforms more sophisticated classification methods." — Andrew Ng
> 朴素贝叶斯是一种基于贝叶斯定理的生成式分类器。它朴素地假设特征之间相互独立，但这种简化带来了高效的计算和出人意料的好效果

# 0.6.1 贝叶斯定理

贝叶斯定理回答了一个核心问题：**当我们观察到一些证据后，如何更新我们的信念？**

日常例子：

* 下雨的概率是 30%（先验）
* 你看到乌云（证据）
* 现在下雨的概率是多少？（后验）

贝叶斯定理给出了 **从先验到后验的更新规则**。

**贝叶斯定理：** $P(y|\mathbf{x}) = \frac{P(\mathbf{x}|y) \cdot P(y)}{P(\mathbf{x})}$

各项含义：

* $P(y|\mathbf{x})$：**后验概率** — 给定特征 $\mathbf{x}$，类别为 $y$ 的概率
* $P(\mathbf{x}|y)$：**似然** — 给定类别 $y$，观察到特征 $\mathbf{x}$ 的概率
* $P(y)$：**先验概率** — 类别 $y$ 的初始概率
* $P(\mathbf{x})$：**证据** — 特征 $\mathbf{x}$ 的总概率（归一化常数）

分类决策：由于 $P(\mathbf{x})$ 对所有类别相同，分类时只需比较：$\hat{y} = \arg\max_y P(y|\mathbf{x}) = \arg\max_y P(\mathbf{x}|y) \cdot P(y)$

# 0.6.2 条件独立假设

问题：如果有 $d$ 个特征，估计 $P(\mathbf{x}|y) = P(x_1, x_2, ..., x_d|y)$ 需要指数级的参数

**朴素假设**：给定类别 $y$，各特征 **条件独立**。

这意味着：知道一个人患流感后，他的「发烧」和「咳嗽」是独立的。

* 现实中这不完全正确（咳嗽可能导致发烧加重）
* 但这种简化大大减少了参数数量
* 实践中效果出奇地好
* **条件独立假设：** $P(\mathbf{x}|y) = P(x_1, x_2, ..., x_d|y) = \prod_{j=1}^{d} P(x_j|y)$
* **朴素贝叶斯分类器：** $\hat{y} = \arg\max_y P(y) \prod_{j=1}^{d} P(x_j|y)$
* **取对数避免数值下溢：** $\hat{y} = \arg\max_y \left[ \log P(y) + \sum_{j=1}^{d} \log P(x_j|y) \right]$
* **参数数量对比：**



| 方法 | 参数数量 |
| --- | --- |
| 完整联合分布 | $O(K \cdot V^d)$ |
| 朴素贝叶斯 | $O(K \cdot d \cdot V)$ |



其中 $K$ 是类别数， $d$ 是特征数， $V$ 是每个特征的取值数。

# 0.6.3 高斯朴素贝叶斯

当特征是连续值时，我们假设每个类别下的每个特征服从 **高斯（正态）分布**。

对每个类别 $y$ 和特征 $j$，我们估计：

* 均值 $\mu_{yj}$
* 方差 $\sigma_{yj}^2$

**似然函数：** $P(x_j|y) = \frac{1}{\sqrt{2\pi\sigma_{yj}^2}} \exp\left(-\frac{(x_j - \mu_{yj})^2}{2\sigma_{yj}^2}\right)$

**参数估计（最大似然）：**

$\mu_{yj} = \frac{1}{n_y} \sum_{i: y^{(i)}=y} x_j^{(i)}$，$\sigma_{yj}^2 = \frac{1}{n_y} \sum_{i: y^{(i)}=y} (x_j^{(i)} - \mu_{yj})^2$，$P(y) = \frac{n_y}{n}$，其中 $n_y$ 是类别 $y$ 的样本数。

# 0.6.4 多项式朴素贝叶斯

多项式朴素贝叶斯适用于 **计数数据**，如：

* 文本分类：词频统计
* 每个特征是某个事件的出现次数

经典应用：垃圾邮件过滤

**多项式分布**

$P(\mathbf{x}|y) = \frac{(\sum_j x_j)!}{\prod_j x_j!} \prod_{j=1}^{d} \theta_{yj}^{x_j}$

其中 $\theta_{yj}$ 是类别 $y$ 下特征 $j$ 的概率，满足 $\sum_j \theta_{yj} = 1$

**参数估计（最大似然）**

$\theta_{yj} = \frac{N_{yj}}{N_y}$

其中：

* $N_{yj}$ = 类别 $y$ 中特征 $j$ 的总计数
* $N_y$ = 类别 $y$ 的所有特征总计数

# 0.6.5 拉普拉斯平滑

> 问题：如果某个特征在训练集中从未出现在某个类别，会怎样？
> $P(x_j|y) = 0 \Rightarrow P(y|\mathbf{x}) = 0$
> 即使其他特征强烈支持这个类别，一个零概率就会「杀死」整个后验，**拉普拉斯平滑**（又称加一平滑）：假设每个特征至少出现过一次

**拉普拉斯平滑：** $\theta_{yj} = \frac{N_{yj} + \alpha}{N_y + \alpha d}$

其中：

* $\alpha$ 是平滑参数（通常为 1）
* $d$ 是特征数（词汇表大小）

效果：

* 当 $N_{yj} = 0$ 时，$\theta_{yj} = \frac{\alpha}{N_y + \alpha d} > 0$
* 避免了零概率问题
![](<../images/0.6 ML 朴素贝叶斯 (Naive Bayes)-image-5.png>)

观察:

1. alpha=0 时，零计数特征概率为 0（危险！）
2. alpha 增大，分布趋向均匀
3) alpha=1 是常用的加一平滑

# 比较不同朴素贝叶斯变体

朴素贝叶斯变体比较

| 变体 | 特征类型 | 似然分布 | 典型应用 |
| -------- | ------- | ----- | --------- |
| 高斯朴素贝叶斯 | 连续值 | 高斯分布 | 传感器数据、图像 |
| 多项式朴素贝叶斯 | 计数值 | 多项式分布 | 文本分类（词频） |
| 伯努利朴素贝叶斯 | 二值（0/1） | 伯努利分布 | 文本（词出现与否） |

  选择建议:
1. 如果特征是连续的（如身高、温度）→ 高斯朴素贝叶斯
2. 如果特征是词频/计数 → 多项式朴素贝叶斯
3. 如果只关心特征是否出现（不关心频率）→ 伯努利朴素贝叶斯

# 总结

1. **贝叶斯定理**: 从先验到后验的概率更新规则
2. **条件独立假设**: 简化计算的关键假设
3) **高斯朴素贝叶斯**: 适用于连续特征
4) **多项式朴素贝叶斯**: 适用于计数特征（文本分类）
5. **拉普拉斯平滑**: 避免零概率问题
> "朴素贝叶斯的'朴素'假设虽然不符合现实，但它简化了计算并且往往效果出奇地好。这是机器学习中'简单模型不一定差'的典型例子。"

**朴素贝叶斯的优缺点：**

**优点**:

* 训练和预测都非常快
* 需要的数据量相对较少
* 对高维数据表现良好
* 可解释性强

**缺点**:

* 条件独立假设通常不成立
* 概率估计可能不准确（虽然分类可能正确）
