# 0.3.1 距离度量

KNN 的核心思想是"近朱者赤，近墨者黑"。但什么是"近"？

在不同的问题中，"距离"的定义可能不同：

* 地理距离：直线距离（欧几里得）
* 城市街区：只能走横竖（曼哈顿）
* 象棋国王：可以走斜线（切比雪夫）

## Minkowski 距离族

给定两点 $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$，**Minkowski 距离** 定义为：$d_p(\mathbf{x}, \mathbf{y}) = \left( \sum_{i=1}^n |x_i - y_i|^p \right)^{1/p}$



| p | 名称 | 公式 | 几何意义 |
| --- | --- | --- | --- |
| 1 | 曼哈顿距离 | $\sum_i \vert{}x_i - y_i\vert{}$ | 沿坐标轴的路径长度 |
| 2 | 欧几里得距离 | $\sqrt{\sum_i (x_i - y_i)^2}$ | 直线距离 |
| ∞ | 切比雪夫距离 | $\max_i \vert{}x_i - y_i\vert{}$ | 各维度最大差异 |



## 距离度量的性质

一个合格的距离度量 $d(\mathbf{x}, \mathbf{y})$ 必须满足：

1. **非负性**：$d(\mathbf{x}, \mathbf{y}) \geq 0$
2. **同一性**：$d(\mathbf{x}, \mathbf{y}) = 0 \Leftrightarrow \mathbf{x} = \mathbf{y}$
3) **对称性**：$d(\mathbf{x}, \mathbf{y}) = d(\mathbf{y}, \mathbf{x})$
4) **三角不等式**：$d(\mathbf{x}, \mathbf{z}) \leq d(\mathbf{x}, \mathbf{y}) + d(\mathbf{y}, \mathbf{z})$

```python
def minkowski_distance(x: np.ndarray, y: np.ndarray, p: float = 2) -> float:
    """
    计算 Minkowski 距离。

    Parameters
    ----------
    x : np.ndarray
        第一个点
    y : np.ndarray
        第二个点
    p : float
        距离参数，p=1 为曼哈顿，p=2 为欧几里得，p=inf 为切比雪夫

    Returns
    -------
    float
        Minkowski 距离
    """
    diff = np.abs(x - y)

    if p == np.inf:
        return np.max(diff)
    else:
        return np.sum(diff ** p) ** (1 / p)

def euclidean_distance(x: np.ndarray, y: np.ndarray) -> float:
    """欧几里得距离（L2 范数）。"""
    return np.sqrt(np.sum((x - y) ** 2))

def manhattan_distance(x: np.ndarray, y: np.ndarray) -> float:
    """曼哈顿距离（L1 范数）。"""
    return np.sum(np.abs(x - y))

def chebyshev_distance(x: np.ndarray, y: np.ndarray) -> float:
    """切比雪夫距离（L∞ 范数）。"""
    return np.max(np.abs(x - y))
```

* 余弦距离和相关性距离

```python
def cosine_distance(x: np.ndarray, y: np.ndarray) -> float:
    """
    余弦距离：1 - cos(θ)
    """
    dot_product = np.dot(x, y)
    norm_x = np.linalg.norm(x)
    norm_y = np.linalg.norm(y)

    if norm_x == 0 or norm_y == 0:
        return 1.0

    cosine_similarity = dot_product / (norm_x * norm_y)
    return 1 - cosine_similarity

def correlation_distance(x: np.ndarray, y: np.ndarray) -> float:
    """
    相关性距离：1 - correlation
    """
    x_centered = x - np.mean(x)
    y_centered = y - np.mean(y)

    return cosine_distance(x_centered, y_centered)
```

# 0.3.2 K 近邻算法

KNN 的核心思想非常简单：

1. 给定一个新样本，找到训练集中与它最近的 K 个样本
2. **分类**：让这 K 个邻居投票，多数决
3) **回归**：取这 K 个邻居的平均值

KNN 是一种"懒惰学习"(Lazy Learning)算法：

* 没有显式的训练过程
* 所有计算都在预测时进行

**KNN 分类：** 给定训练集 $\{(\mathbf{x}_i, y_i)\}_{i=1}^n$，对于新样本 $\mathbf{x}$：

1. 计算 $\mathbf{x}$ 到所有训练样本的距离
2. 找到距离最近的 K 个样本，记为 $N_K(\mathbf{x})$
3) 预测标签：$\hat{y} = \arg\max_c \sum_{i \in N_K(\mathbf{x})} \mathbb{1}(y_i = c)$

**加权 KNN：** 可以根据距离给邻居加权，距离越近权重越大：

$\hat{y} = \arg\max_c \sum_{i \in N_K(\mathbf{x})} w_i \cdot \mathbb{1}(y_i = c)$

常用权重： $w_i = \frac{1}{d(\mathbf{x}, \mathbf{x}_i)}$ 或 $w_i = \frac{1}{d(\mathbf{x}, \mathbf{x}_i)^2}$

```python
class KNNClassifier:
    """
    K 近邻分类器。

    Parameters
    ----------
    k : int
        近邻数量
    distance_metric : str
        距离度量，可选 'euclidean', 'manhattan', 'chebyshev'
    weights : str
        权重方式，'uniform' 或 'distance'
    """

    def __init__(self, k: int = 5, distance_metric: str = 'euclidean',
                 weights: str = 'uniform'):
        self.k = k
        self.distance_metric = distance_metric
        self.weights = weights
        self.X_train = None
        self.y_train = None

        # 选择距离函数
        if distance_metric == 'euclidean':
            self._distance = euclidean_distance
        elif distance_metric == 'manhattan':
            self._distance = manhattan_distance
        elif distance_metric == 'chebyshev':
            self._distance = chebyshev_distance
        else:
            raise ValueError(f"未知距离度量: {distance_metric}")

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'KNNClassifier':
        """
        "训练"模型（实际只是存储数据）。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            训练数据
        y : np.ndarray, shape (n_samples,)
            训练标签

        Returns
        -------
        self
        """
        self.X_train = np.array(X)
        self.y_train = np.array(y)
        return self

    def _get_neighbors(self, x: np.ndarray) -> tuple:
        """
        获取单个样本的 K 个最近邻。

        Parameters
        ----------
        x : np.ndarray
            查询样本

        Returns
        -------
        tuple
            (距离数组, 索引数组)
        """
        # 计算到所有训练样本的距离
        distances = np.array([self._distance(x, x_train)
                              for x_train in self.X_train])

        # 找到 K 个最近邻的索引
        k_indices = np.argsort(distances)[:self.k]
        k_distances = distances[k_indices]

        return k_distances, k_indices

    def predict_single(self, x: np.ndarray) -> int:
        """
        预测单个样本的类别。

        Parameters
        ----------
        x : np.ndarray
            查询样本

        Returns
        -------
        int
            预测类别
        """
        k_distances, k_indices = self._get_neighbors(x)
        k_labels = self.y_train[k_indices]

        if self.weights == 'uniform':
            # 简单投票
            vote_counts = Counter(k_labels)
            return vote_counts.most_common(1)[0][0]
        else:
            # 加权投票
            # 避免除以零
            k_distances = np.maximum(k_distances, 1e-10)
            weights = 1.0 / k_distances

            # 对每个类别计算加权投票
            unique_labels = np.unique(k_labels)
            weighted_votes = {}
            for label in unique_labels:
                mask = k_labels == label
                weighted_votes[label] = np.sum(weights[mask])

            return max(weighted_votes, key=weighted_votes.get)

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测多个样本的类别。

        Parameters
        ----------
        X : np.ndarray, shape (n_samples, n_features)
            查询样本

        Returns
        -------
        np.ndarray
            预测类别
        """
        return np.array([self.predict_single(x) for x in X])

    def score(self, X: np.ndarray, y: np.ndarray) -> float:
        """
        计算分类准确率。

        Parameters
        ----------
        X : np.ndarray
            测试数据
        y : np.ndarray
            真实标签

        Returns
        -------
        float
            准确率
        """
        predictions = self.predict(X)
        return np.mean(predictions == y)
# 生成测试数据
def generate_classification_data(n_samples=200, n_classes=3, random_state=42):
    """
    生成用于分类的合成数据。

    Parameters
    ----------
    n_samples : int
        样本总数
    n_classes : int
        类别数
    random_state : int
        随机种子

    Returns
    -------
    X : np.ndarray
        特征数据
    y : np.ndarray
        标签
    """
    np.random.seed(random_state)

    # 每个类别的中心
    centers = np.array([[0, 0], [3, 3], [0, 4]][:n_classes])

    samples_per_class = n_samples // n_classes
    X = []
    y = []

    for i, center in enumerate(centers):
        # 生成高斯分布的数据
        X_class = np.random.randn(samples_per_class, 2) * 0.8 + center
        X.append(X_class)
        y.extend([i] * samples_per_class)

    return np.vstack(X), np.array(y)

# 生成数据
X, y = generate_classification_data(n_samples=300, n_classes=3)

# 划分训练集和测试集
n_train = int(0.8 * len(X))
indices = np.random.permutation(len(X))

print(f"训练集大小: {len(X_train)}")
```

# 0.3.4 KD-Tree 加速

暴力 KNN 的时间复杂度是 $O(nd)$，其中 $n$ 是训练样本数，$d$ 是维度。对于大数据集，这太慢了

KD-Tree（K 维树）是一种空间划分数据结构：

* 类似于二叉搜索树，但在多维空间中
* 通过递归地按不同维度划分空间
* 查询时可以剪枝，跳过不可能包含最近邻的区域

***KD-Tree 构建***

1. 选择一个维度（通常是方差最大的维度，或者循环选择）
2. 找到该维度的中位数点作为分割点
3) 递归地对左右子空间构建子树

***最近邻查询***

1. 从根节点开始，递归下降到包含查询点的叶节点
2. 回溯时，检查兄弟子树是否可能包含更近的点
3) 剪枝条件：如果查询点到分割超平面的距离大于当前最近距离，则跳过

时间复杂度：平均 $O(\log n)$，最坏 $O(n)$

```python
class KDTreeNode:
    """
    KD-Tree 节点。

    Attributes
    ----------
    point : np.ndarray
        节点存储的点
    label : int
        点的标签
    axis : int
        分割维度
    left : KDTreeNode
        左子树
    right : KDTreeNode
        右子树
    """

    def __init__(self, point=None, label=None, axis=0, left=None, right=None):
        self.point = point
        self.label = label
        self.axis = axis
        self.left = left
        self.right = right

class KDTree:
    """
    KD-Tree 数据结构。

    Parameters
    ----------
    X : np.ndarray, shape (n_samples, n_features)
        数据点
    y : np.ndarray, shape (n_samples,)
        标签
    """

    def __init__(self, X: np.ndarray, y: np.ndarray = None):
        self.n_dims = X.shape[1]
        if y is None:
            y = np.arange(len(X))
        self.root = self._build(X, y, depth=0)

    def _build(self, X: np.ndarray, y: np.ndarray, depth: int) -> KDTreeNode:
        """
        递归构建 KD-Tree。

        Parameters
        ----------
        X : np.ndarray
            当前子集的数据点
        y : np.ndarray
            当前子集的标签
        depth : int
            当前深度

        Returns
        -------
        KDTreeNode
            子树根节点
        """
        if len(X) == 0:
            return None

        # 选择分割维度（循环选择）
        axis = depth % self.n_dims

        # 按该维度排序，找到中位数
        sorted_indices = np.argsort(X[:, axis])
        median_idx = len(sorted_indices) // 2

        # 获取中位数点
        median_point_idx = sorted_indices[median_idx]

        # 分割数据
        left_indices = sorted_indices[:median_idx]
        right_indices = sorted_indices[median_idx + 1:]

        # 递归构建子树
        return KDTreeNode(
            point=X[median_point_idx],
            label=y[median_point_idx],
            axis=axis,
            left=self._build(X[left_indices], y[left_indices], depth + 1),
            right=self._build(X[right_indices], y[right_indices], depth + 1)
        )

    def query(self, point: np.ndarray, k: int = 1) -> list:
        """
        查询 K 个最近邻。

        Parameters
        ----------
        point : np.ndarray
            查询点
        k : int
            近邻数量

        Returns
        -------
        list
            [(距离, 标签), ...] 的列表
        """
        # 使用最大堆维护 K 个最近邻（负距离，因为 heapq 是最小堆）
        best = []  # (-distance, label) 的堆

        def _search(node, depth=0):
            if node is None:
                return

            # 计算到当前节点的距离
            dist = euclidean_distance(point, node.point)

            # 更新最近邻
            if len(best) < k:
                heapq.heappush(best, (-dist, node.label, node.point))
            elif dist < -best[0][0]:
                heapq.heapreplace(best, (-dist, node.label, node.point))

            # 决定先访问哪个子树
            axis = node.axis
            diff = point[axis] - node.point[axis]

            if diff < 0:
                first, second = node.left, node.right
            else:
                first, second = node.right, node.left

            # 先访问更可能包含最近邻的子树
            _search(first, depth + 1)

            # 检查是否需要访问另一个子树
            # 如果堆未满，或者到分割超平面的距离小于当前最远的近邻
            if len(best) < k or abs(diff) < -best[0][0]:
                _search(second, depth + 1)

        _search(self.root)

        # 返回结果（转换为正距离）
        return [(-d, label, pt) for d, label, pt in sorted(best, reverse=True)]
```

# 0.3.5 维度灾难

在高维空间中，"距离"变得不那么有意义：

1. **所有点都变得"远"**：高维空间大部分体积集中在"角落"
2. **最近邻和最远邻的距离差异变小**
3) **数据变得稀疏**：相同数量的数据在高维空间中覆盖的比例指数级下降

***高维球体的体积***

d 维单位球体的体积：

$V_d = \frac{\pi^{d/2}}{\Gamma(d/2 + 1)}$

当 $d \to \infty$ 时， $V_d \to 0$！

***距离集中现象***

在高维空间中，如果点均匀分布在单位超立方体中，则：$\frac{d_{max} - d_{min}}{d_{min}} \to 0 \text{ as } d \to \infty$

这意味着最近邻和最远邻的距离几乎相同！

# 0.3.6 KNN 回归

KNN 也可以用于回归问题

```python
class KNNRegressor:
    """
    K 近邻回归器。

    Parameters
    ----------
    k : int
        近邻数量
    weights : str
        权重方式，'uniform' 或 'distance'
    """

    def __init__(self, k: int = 5, weights: str = 'uniform'):
        self.k = k
        self.weights = weights
        self.X_train = None
        self.y_train = None

    def fit(self, X: np.ndarray, y: np.ndarray) -> 'KNNRegressor':
        """
        "训练"模型。
        """
        self.X_train = np.array(X)
        self.y_train = np.array(y)
        return self

    def predict_single(self, x: np.ndarray) -> float:
        """
        预测单个样本的值。
        """
        # 计算距离
        distances = np.array([euclidean_distance(x, x_train)
                              for x_train in self.X_train])

        # 找到 K 个最近邻
        k_indices = np.argsort(distances)[:self.k]
        k_distances = distances[k_indices]
        k_values = self.y_train[k_indices]

        if self.weights == 'uniform':
            return np.mean(k_values)
        else:
            # 距离加权平均
            k_distances = np.maximum(k_distances, 1e-10)
            weights = 1.0 / k_distances
            return np.sum(weights * k_values) / np.sum(weights)

    def predict(self, X: np.ndarray) -> np.ndarray:
        """
        预测多个样本。
        """
        return np.array([self.predict_single(x) for x in X])
```

# 为什么 KNN 需要特征缩放？

* KNN 基于距离计算，如果特征的尺度差异很大，大尺度的特征会主导距离计算，使小尺度特征失去影响力
* 例如：
  * 特征1：年龄（0-100）
  * 特征2：收入（0-1000000）
  不缩放时，收入的差异会完全掩盖年龄的差异。

```python
class StandardScaler:
    """
    标准化缩放器。

    将特征缩放到均值为0，标准差为1。
    """

    def __init__(self):
        self.mean_ = None
        self.std_ = None

    def fit(self, X: np.ndarray) -> 'StandardScaler':
        """
        计算均值和标准差。
        """
        self.mean_ = np.mean(X, axis=0)
        self.std_ = np.std(X, axis=0)
        # 防止除以零
        self.std_[self.std_ == 0] = 1
        return self

    def transform(self, X: np.ndarray) -> np.ndarray:
        """
        应用标准化。
        """
        return (X - self.mean_) / self.std_

    def fit_transform(self, X: np.ndarray) -> np.ndarray:
        """
        拟合并转换。
        """
        return self.fit(X).transform(X)
```

# 关键思想

> "KNN 是最简单的机器学习算法，但它揭示了一个深刻的思想：相似的输入应该产生相似的输出。"

KNN 的优缺点：

* **优点**：
  * 简单直观，易于理解和实现
  * 无需训练，适合在线学习
  * 对非线性决策边界建模能力强
* **缺点**：
  * 预测时计算成本高
  * 对维度灾难敏感
  * 需要存储所有训练数据
  * 对异常值敏感
