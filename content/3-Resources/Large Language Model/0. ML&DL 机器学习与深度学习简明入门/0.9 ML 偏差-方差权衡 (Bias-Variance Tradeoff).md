> > "All models are wrong, but some are useful." — George Box
> 理解模型为何会犯错是机器学习的核心问题。本节深入剖析 **泛化误差** 的组成，揭示过拟合与欠拟合的本质

# 0.9.1 偏差-方差的直觉 (The Intuition)

> 一个简单的比喻：射箭，想象你在练习射箭，目标是正中靶心（真实函数 $f(x)$）
> * **偏差 (Bias)**：你的平均射击位置离靶心有多远？
> * 高偏差 = 系统性偏离（瞄准歪了）
> * 低偏差 = 平均而言瞄得准
> * **方差 (Variance)**：你的射击有多分散？
> * 高方差 = 射击点散得很开（手不稳）
> * 低方差 = 射击点集中



| 射箭 | 机器学习 |
| --- | --- |
| 靶心 | 真实函数 f(x) |
| 每次射击 | 在不同训练集上学到的模型 $\hat{f}(x)$ |
| 平均射击位置 | $\mathbb{E}[\hat{f}(x)]$ |
| 偏差 | $\mathbb{E}[\hat{f}(x)] - f(x)$ |
| 方差 | $\text{Var}[\hat{f}(x)]$ |



![](<../images/0.9 ML 偏差-方差权衡 (Bias-Variance Tradeoff)-image.png>)

关键洞察：

* 低偏差低方差：每次都能命中靶心附近（理想模型）
* 低偏差高方差：平均在靶心，但每次差异大（过拟合）
* 高偏差低方差：稳定地打偏（欠拟合，模型太简单）
* 高偏差高方差：既打偏又不稳定（最差情况）

# 0.9.2 数学推导

* **问题设置：** 假设真实数据生成过程为：$y = f(x) + \epsilon$，其中：
  * $f(x)$ 是真实的（未知的）函数
  * $\epsilon$ 是噪声， $\mathbb{E}[\epsilon] = 0$，$\text{Var}[\epsilon] = \sigma^2$
  我们使用训练数据 $\mathcal{D}$ 学习一个模型 $\hat{f}(x; \mathcal{D})$。
* **泛化误差分解：** 对于一个新的测试点 $x$，期望平方误差为：$\mathbb{E}_{\mathcal{D}, \epsilon}\left[(y - \hat{f}(x))^2\right]$ 这个期望是对 **所有可能的训练集** 和 **噪声** 取的
* **详细推导：** 令 $\bar{f}(x) = \mathbb{E}_{\mathcal{D}}[\hat{f}(x)]$ 表示模型的期望预测。
  $\text{Error} = \mathbb{E}\left[(y - \hat{f})^2\right] \\ = \mathbb{E}\left[(f + \epsilon - \hat{f})^2\right] \\ = \mathbb{E}\left[((f - \bar{f}) + (\bar{f} - \hat{f}) + \epsilon)^2\right]$
  展开并利用 $\mathbb{E}[\epsilon] = 0$ 和 $\mathbb{E}[\hat{f} - \bar{f}] = 0$：
  $\boxed{\text{Error} = \underbrace{(f(x) - \bar{f}(x))^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}[(\hat{f}(x) - \bar{f}(x))^2]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{Irreducible Error}}}$
![](<../images/0.9 ML 偏差-方差权衡 (Bias-Variance Tradeoff)-image-8.png>)

误差分解解读：

1. Bias²：模型的系统性偏差（模型能力不足导致）
2. Variance：模型对训练数据的敏感程度（过度敏感 = 过拟合）
3) Noise：数据本身的随机噪声（不可消除）
* **偏差-方差权衡：**

关键洞察：**复杂度增加时，偏差下降但方差上升**

| 模型复杂度 | 偏差 | 方差 | 总误差 |
| ------- | -- | -- | ------ |
| 过低（欠拟合） | 高 | 低 | 高 |
| 适中 | 中 | 中 | **最低** |
| 过高（过拟合） | 低 | 高 | 高 |

这就是为什么我们需要 **正则化**、**交叉验证** 等技术来找到最佳复杂度

# 0.9.3 实验验证

## 多项式回归实验

我们通过多项式回归来实际验证偏差-方差权衡。

* 真实函数：$f(x) = \sin(2\pi x)$
* 训练多个不同阶次的多项式模型
* 在多个随机训练集上训练，计算偏差和方差

```python
class PolynomialRegression:
    """
    多项式回归模型。

    Parameters
    ----------
    degree : int
        多项式阶次
    """

    def init(self, degree: int):
        self.degree = degree
        self.coefficients = None

    def _polynomial_features(self, x: np.ndarray) -> np.ndarray:
        """
        生成多项式特征。

        Parameters
        ----------
        x : np.ndarray, shape (n_samples,)
            输入数据

        Returns
        -------
        np.ndarray, shape (n_samples, degree + 1)
            多项式特征矩阵 [1, x, x², ..., x^degree]
        """
        n_samples = len(x)
        X_poly = np.zeros((n_samples, self.degree + 1))
        for d in range(self.degree + 1):
            X_poly[:, d] = x ** d
        return X_poly

    def fit(self, x: np.ndarray, y: np.ndarray) -> 'PolynomialRegression':
        """
        拟合多项式回归。

        使用最小二乘法：w = (X^T X)^{-1} X^T y
        """
        X_poly = self._polynomial_features(x)
        # 使用伪逆以增强数值稳定性
        self.coefficients = np.linalg.lstsq(X_poly, y, rcond=None)[0]
        return self

    def predict(self, x: np.ndarray) -> np.ndarray:
        """
        预测。
        """
        X_poly = self._polynomial_features(x)
        return X_poly @ self.coefficients
def true_function(x):
    """真实函数：正弦波。"""
    return np.sin(2 * np.pi * x)
def generate_data(n_samples, noise_std=0.3, random_state=None):
    """
    生成带噪声的数据。

    Parameters
    ----------
    n_samples : int
        样本数量
    noise_std : float
        噪声标准差
    random_state : int, optional
        随机种子

    Returns
    -------
    x, y : np.ndarray
        特征和标签
    """
    if random_state is not None:
        np.random.seed(random_state)
    x = np.random.uniform(0, 1, n_samples)
    y = true_function(x) + np.random.randn(n_samples) * noise_std
    return x, y
```

* degree=3: 较好的拟合
* degree=9: 开始过拟合
* degree=15: 严重过拟合（剧烈震荡）

## 实际计算偏差和方差

为了真正验证偏差-方差分解，我们需要：

1. 在多个不同的训练集上训练模型
2. 计算预测的期望（用于计算偏差）
3) 计算预测的方差

```python
def compute_bias_variance(degrees, n_datasets=100, n_train=20, noise_std=0.3):
    """
    计算不同多项式阶次的偏差和方差。

    Parameters
    ----------
    degrees : list
        多项式阶次列表
    n_datasets : int
        生成的数据集数量（用于估计期望）
    n_train : int
        每个数据集的训练样本数
    noise_std : float
        噪声标准差

    Returns
    -------
    dict
        包含 bias², variance, total_error 的字典
    """
    # 测试点
    x_test = np.linspace(0.01, 0.99, 50)
    y_true = true_function(x_test)

    results = {'degrees': degrees, 'bias_squared': [], 'variance': [],
               'total_error': [], 'noise': noise_std**2}

    for degree in degrees:
        # 存储所有数据集上的预测
        all_predictions = np.zeros((n_datasets, len(x_test)))

        for i in range(n_datasets):
            # 生成新的训练集
            x_train, y_train = generate_data(n_train, noise_std, random_state=i)

            # 训练模型
            model = PolynomialRegression(degree=degree)
            model.fit(x_train, y_train)

            # 预测
            all_predictions[i] = model.predict(x_test)

        # 计算期望预测：E[f_hat(x)]
        mean_prediction = np.mean(all_predictions, axis=0)

        # 偏差²: (f(x) - E[f_hat(x)])²
        bias_squared = np.mean((y_true - mean_prediction)**2)

        # 方差: E[(f_hat(x) - E[f_hat(x)])²]
        variance = np.mean(np.var(all_predictions, axis=0))

        # 总误差 = Bias² + Variance + Noise
        total_error = bias_squared + variance + noise_std**2

        results['bias_squared'].append(bias_squared)
        results['variance'].append(variance)
        results['total_error'].append(total_error)

    return results

# 计算偏差和方差
degrees_to_test = list(range(1, 16))
results = compute_bias_variance(degrees_to_test, n_datasets=200)
```

* 低复杂度时：高偏差，低方差（欠拟合）
* 高复杂度时：低偏差，高方差（过拟合）
* 最优复杂度：degree = 3

# 0.9.4 Bootstrap 方法

Bootstrap 是一种 **重采样方法**，用于估计统计量的分布。

核心思想：

* 从原始数据集中 **有放回地** 抽样，生成多个"伪"数据集
* 在每个伪数据集上计算统计量
* 统计量的分布近似于真实分布

## Bootstrap 的数学原理

给定样本 $$
\{x_1, x_2, ..., x_n\}$$：

1. 有放回抽样 $n$ 个样本，得到 bootstrap 样本 $\{x_1^*, x_2^*, ..., x_n^*\}$
2. 计算感兴趣的统计量 $\hat{\theta}^*$
3) 重复 $B$ 次，得到 $\{\hat{\theta}^*_1, \hat{\theta}^*_2, ..., \hat{\theta}^*_B\}$
4) 用这个分布估计 $\hat{\theta}$ 的方差、置信区间等

```python
def bootstrap_resample(data: np.ndarray, n_bootstrap: int = 1000,
                       statistic=np.mean, random_state: int = None):
    """
    Bootstrap 重采样。

    Parameters
    ----------
    data : np.ndarray
        原始数据
    n_bootstrap : int
        bootstrap 次数
    statistic : callable
        要估计的统计量函数
    random_state : int, optional
        随机种子

    Returns
    -------
    np.ndarray
        bootstrap 统计量数组
    """
    if random_state is not None:
        np.random.seed(random_state)

    n_samples = len(data)
    bootstrap_stats = np.zeros(n_bootstrap)

    for i in range(n_bootstrap):
        # 有放回抽样
        indices = np.random.randint(0, n_samples, size=n_samples)
        bootstrap_sample = data[indices]

        # 计算统计量
        bootstrap_stats[i] = statistic(bootstrap_sample)

    return bootstrap_stats

def bootstrap_confidence_interval(data: np.ndarray, statistic=np.mean,
                                   confidence: float = 0.95, n_bootstrap: int = 1000):
    """
    使用 Bootstrap 计算置信区间。

    Parameters
    ----------
    data : np.ndarray
        原始数据
    statistic : callable
        统计量函数
    confidence : float
        置信水平
    n_bootstrap : int
        bootstrap 次数

    Returns
    -------
    tuple
        (点估计, 下界, 上界)
    """
    bootstrap_stats = bootstrap_resample(data, n_bootstrap, statistic)

    # 百分位法
    alpha = (1 - confidence) / 2
    lower = np.percentile(bootstrap_stats, alpha * 100)
    upper = np.percentile(bootstrap_stats, (1 - alpha) * 100)

    return statistic(data), lower, upper, bootstrap_stats
```

## 使用 Bootstrap 估计模型方差

```python
def bootstrap_model_variance(x_train, y_train, x_test, model_class,
                              n_bootstrap=100, **model_params):
    """
    使用 Bootstrap 估计模型预测的方差。

    Parameters
    ----------
    x_train, y_train : np.ndarray
        训练数据
    x_test : np.ndarray
        测试点
    model_class : class
        模型类
    n_bootstrap : int
        bootstrap 次数

    Returns
    -------
    mean_pred, std_pred : np.ndarray
        平均预测和标准差
    """
    n_train = len(x_train)
    n_test = len(x_test)

    all_predictions = np.zeros((n_bootstrap, n_test))

    for i in range(n_bootstrap):
        # Bootstrap 采样
        indices = np.random.randint(0, n_train, size=n_train)
        x_boot = x_train[indices]
        y_boot = y_train[indices]

        # 训练模型
        model = model_class(**model_params)
        model.fit(x_boot, y_boot)

        # 预测
        all_predictions[i] = model.predict(x_test)

    mean_pred = np.mean(all_predictions, axis=0)
    std_pred = np.std(all_predictions, axis=0)

    return mean_pred, std_pred, all_predictions
```

观察：置信带宽度反映了模型的方差

* 低阶多项式：窄置信带（低方差）
* 高阶多项式：宽置信带（高方差）

# 0.9.5 学习曲线

学习曲线展示了模型性能如何随 **训练集大小** 变化。

* **训练误差**：在训练集上的误差
* **验证误差**：在独立验证集上的误差

## 诊断过拟合与欠拟合

| 情况 | 训练误差 | 验证误差 | 两者关系 |
| ---- | ---- | ---- | ---- |
| 欠拟合 | 高 | 高 | 接近 |
| 过拟合 | 低 | 高 | 差距大 |
| 良好拟合 | 低 | 低 | 接近 |

```python
def compute_learning_curve(model_class, x_full, y_full, train_sizes,
                            n_repeats=20, val_ratio=0.3, **model_params):
    """
    计算学习曲线。

    Parameters
    ----------
    model_class : class
        模型类
    x_full, y_full : np.ndarray
        完整数据集
    train_sizes : list
        训练集大小列表
    n_repeats : int
        每个大小重复次数
    val_ratio : float
        验证集比例

    Returns
    -------
    dict
        包含训练和验证误差的字典
    """
    n_total = len(x_full)
    n_val = int(n_total * val_ratio)

    results = {
        'train_sizes': train_sizes,
        'train_errors_mean': [],
        'train_errors_std': [],
        'val_errors_mean': [],
        'val_errors_std': [],
    }

    for n_train in train_sizes:
        train_errors = []
        val_errors = []

        for _ in range(n_repeats):
            # 随机划分数据
            indices = np.random.permutation(n_total)
            train_idx = indices[:n_train]
            val_idx = indices[n_train:n_train + n_val]

            x_train, y_train = x_full[train_idx], y_full[train_idx]
            x_val, y_val = x_full[val_idx], y_full[val_idx]

            # 训练模型
            model = model_class(**model_params)
            model.fit(x_train, y_train)

            # 计算误差
            train_pred = model.predict(x_train)
            val_pred = model.predict(x_val)

            train_errors.append(np.mean((y_train - train_pred)**2))
            val_errors.append(np.mean((y_val - val_pred)**2))

        results['train_errors_mean'].append(np.mean(train_errors))
        results['train_errors_std'].append(np.std(train_errors))
        results['val_errors_mean'].append(np.mean(val_errors))
        results['val_errors_std'].append(np.std(val_errors))

    return results
```

![](<../images/0.9 ML 偏差-方差权衡 (Bias-Variance Tradeoff)-image-3.png>)

学习曲线解读：

* 欠拟合：训练和验证误差都高，且接近（增加数据无帮助）
* 过拟合：训练误差低，验证误差高，差距大（增加数据有帮助）
* 适当拟合：两者都低且接近

## 学习曲线的实践指导

| 观察到的现象 | 诊断 | 解决方案 |
| ------------ | -------- | -------------- |
| 训练和验证误差都高且接近 | 高偏差（欠拟合） | 增加模型复杂度、添加特征 |
| 训练误差低，验证误差高 | 高方差（过拟合） | 增加数据、正则化、降低复杂度 |
| 验证误差随数据增加而下降 | 可受益于更多数据 | 收集更多数据 |
| 验证误差趋于平稳 | 数据量已足够 | 关注模型改进 |

# 0.9.6 过拟合与欠拟合的深入理解

* 过拟合的本质：过拟合发生在模型"记住"了训练数据中的噪声，而非学习真实的模式
![](<../images/0.9 ML 偏差-方差权衡 (Bias-Variance Tradeoff)-image-1.png>)

* 防止过拟合的策略：
  1. **正则化**：L1, L2, Elastic Net
  2. **早停 (Early Stopping)**：在验证误差开始上升时停止训练
  3) **交叉验证**：使用 K-fold CV 选择超参数
  4) **数据增强**：人工增加训练数据
  5. **集成方法**：Bagging, Boosting
  6. **Dropout**（深度学习）：随机丢弃神经元

# 证明：对于固定的模型类，增加训练数据量会减少方差但不会改变偏差

**提示**：考虑样本均值的方差如何随样本量变化。

考虑线性回归的情况。设真实函数为 $f(x)$，模型为 f\_hat(x) = x^T w。

1. 偏差分析：

Bias = E\[f\_hat(x)] - f(x)

偏差取决于模型的假设空间。如果真实函数是非线性的，

而我们用线性模型拟合，无论数据量多大，偏差都不会变。

这是模型选择的问题，不是数据量的问题。

2. 方差分析：

对于 OLS 估计：w\_hat = (X^T X)^{-1} X^T y

Var(w\_hat) = σ² (X^T X)^{-1}

当样本量 n 增加时，(X^T X)^{-1} ≈ (n \* Σ\_X)^{-1} → 0

因此方差随 n 增加而减少，大约以 O(1/n) 的速度。

结论：更多数据只能减少方差，不能减少偏差！

要减少偏差，需要使用更复杂（表达能力更强）的模型。

# 总结

## 关键要点

1. **泛化误差分解**：
   $\text{Error} = \text{Bias}^2 + \text{Variance} + \text{Noise}$
2. **偏差-方差权衡**：
   * 简单模型：高偏差，低方差（欠拟合）
   * 复杂模型：低偏差，高方差（过拟合）
   * 目标：找到最佳复杂度
3) **Bootstrap**：强大的重采样方法，用于估计统计量的不确定性
4) **学习曲线**：诊断模型问题的有效工具
> "当你的模型表现不佳时，先诊断是偏差问题还是方差问题，再对症下药。"

* 高偏差 → 增加模型复杂度
* 高方差 → 增加数据或正则化
