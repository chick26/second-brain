> [!NOTE]
> CIDR（无类别域间路由）和子网掩码都是用于管理 IP 网络和划分子网的技术，但它们采用的表示方式和一些细节有所不同。

## 子网掩码

### 基本概念

子网掩码是与 IP 地址结合使用的一种方法，用于指示 IP 地址中哪些部分代表网络地址，哪些部分代表主机地址。子网掩码与 IP 地址长度相同，并通过 1 和 0 的组合来分隔网络和主机部分：网络部分全为 1，主机部分全为0。

### 表示方式

子网掩码通常以点分十进制表示，如 `255.255.255.0`。在这个例子中，前三个八位字节（255.255.255）代表网络部分，最后一个八位字节（0）代表主机部分。

### 功能

使用子网掩码可以将一个大的 IP 网络划分为多个小的子网，这有助于网络组织和管理，同时也能有效利用 IP 地址资源。

## CIDR

### 基本概念

CIDR 是一种更灵活的方法来表示 IP 地址和其对应的网络。它摒弃了传统的 A、B、C 类地址划分，允许更精细的网络划分。

### 表示方式

CIDR 使用斜杠（/）后面跟一个数字来表示。这个数字指的是网络部分的位数。例如，`192.168.1.0/24` 表示在这个 32 位的地址中，前 24 位是网络地址，剩下的 8 位是主机地址。这等同于子网掩码 `255.255.255.0`。

### 功能

CIDR 允许更灵活的网络大小划分，有助于更有效地分配和使用 IP 地址空间。它也简化了路由表的大小，使互联网的路由更加高效。

## 对比

### 表示方式

子网掩码使用点分十进制表示，而 CIDR 直接在 IP 地址后使用斜杠表示网络部分的位数。

### 灵活性

CIDR 提供了比传统子网掩码更大的灵活性和精确性，允许创建各种大小的网络。

### 用途

虽然两者都用于 IP 网络划分，但 CIDR 特别适用于互联网路由，因为它简化了路由聚合和地址分配。子网掩码则更常用于组织内部网络的划分和管理。

总的来说，CIDR 是对传统子网掩码方法的一种改进和扩展，它提供了更大的灵活性和更有效的 IP 地址利用率，这在当今 IP 地址资源日益紧张的情况下尤为重要。
