# 自媒体运营学习

这个专题用于沉淀 AI 辅助内容生产、视频处理、剪辑自动化和更高级的自媒体运营学习材料。

## 当前入口

- [[Palmier Pro]]：AI-native 视频编辑器工具卡，重点是 MCP 让 Agent 进入剪辑时间线。
- [[AI 视频制作工具链]]：从脚本、分镜、程序化视频、剪辑、配音、配乐到发布复盘的候选工具链。

## 学习路线

1. **选题与脚本**：明确目标受众、内容角度、脚本结构和素材需求。
2. **分镜与素材**：把脚本拆成镜头、画面、字幕、配音、BGM 和素材清单。
3. **视频生成 / 程序化渲染**：适合批量、模板化、数据可视化或产品演示视频。
4. **剪辑与后期**：时间线、字幕、转场、音轨、特效、版本管理。
5. **发布与复盘**：标题、封面、分发渠道、数据指标、复盘改进。

## 维护原则

- 工具条目分成“已核验”“待核验”“不适合当前环境”。
- 不复制平台文章里的星标数或“必备”口号，除非回到官方 repo / docs 核验。
- 涉及账号、版权、声音克隆、商用音乐和素材授权的工具，先看费用和合规边界。
