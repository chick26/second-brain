# 金融投研 Agent 工作流

> [!warning] 证据与边界
> 这份笔记只沉淀投研学习和研究流程，不构成投资建议。2026-W27 已对来源做公开回源和图片 OCR；具体投资判断必须回到公司 IR、公告、财报、电话会、SEC / 监管披露、行情和可追溯数据。

## 核心流程

把投研 Agent 拆成三个连续问题，而不是让 AI 直接回答“买谁”：

1. **线索是否成立？**
   - 新闻或市场信息只是入口。
   - 继续追问真实需求、产业链传导、受益环节、财务影响和后续验证指标。
2. **估值是否被增长质量支撑？**
   - 不只看单一 PE。
   - 同时检查 TAM 与渗透率、增长持续性、定价与利润兑现、竞争和毛利压力。
3. **走势是否健康？**
   - 基本面不错不代表趋势健康。
   - 用 20/50/100/200 日均线等结构做趋势状态检查，只作为研究状态信号，不替代交易决策。

## 三段式 Skill 架构

| 环节 | Skill / 模块 | 回答的问题 | 输出 |
|---|---|---|---|
| 线索层 | Serenity Alpha | 这条新闻影响了谁？真实需求和受益链条是什么？ | 产业链假设、受益环节、待验证数据 |
| 估值层 | TAM-Adj-PEG | 增长质量能否支撑当前估值？ | 估值区间、关键假设、反证点 |
| 趋势层 | GF-DMA Health Index | 当前走势是健康、过热还是走弱？ | 趋势状态、均线结构、风险提示 |

## 数据源闸门

使用 Agent 前先限定资料源。优先级如下：

1. 公司 IR、公告、财报、电话会。
2. SEC 文件与监管披露。
3. TAM 报告、一致预期、行业协会和官方统计，用于交叉核验。
4. 可靠财经媒体只作为线索入口。

如果输入是烂数据，装再多 Skill 也没用。

## 输出格式

每次研究输出应尽量保持这个结构：

```markdown
## 研究对象
- 公司 / 行业 / 事件：
- 当前问题：

## 线索假设
- 触发信息：
- 真实需求：
- 可能受益环节：
- 需要验证的数据：

## 估值检查
- TAM / 渗透率：
- 增长持续性：
- 定价与利润兑现：
- 竞争与毛利压力：

## 趋势健康度
- 20 / 50 / 100 / 200 日均线结构：
- 当前状态：healthy / hot / weak
- 需要复核的风险：

## 结论边界
- 研究假设：
- 反证条件：
- 后续跟踪：
- 不构成投资建议。
```

## Agent 边界

- Agent 可以做资料收集、表格整理、假设对比和风险清单。
- 不应自动生成买卖建议。
- 涉及投资判断时，必须标注来源、日期和不确定性。
- 技术面 / 均线只能作为状态检查，不应覆盖基本面和风险判断。
