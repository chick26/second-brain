# 投资学习

这个目录用于沉淀投资学习、公司研究、行业研究和投研 Agent 工作流。这里的内容默认是学习和研究框架，不构成投资建议。

## 当前入口

- [[金融投研 Agent 工作流]]：用 Agent 辅助“线索 → 估值 → 趋势健康度 → 数据验证”的研究流程。
- [[3-Resources/Investment Learning/CFA/The Time Value of Money|The Time Value of Money]]：CFA / 金融基础知识。
- [[3-Resources/Investment Learning/CFA/境外收入个税汇算|境外收入个税汇算]]：境外收入与税务处理经验，使用前仍需回到官方口径。

## 子目录

- `CFA/`：金融基础、CFA 课程笔记、税务与合规相关资料。
- 根目录：投资学习入口、投研 Agent 工作流、未来的公司/行业研究框架。

## 学习范围

1. 金融基础：货币时间价值、风险收益、财务报表、估值方法。
2. 公司研究：商业模式、财务质量、管理层、竞争格局。
3. 行业研究：产业链、供需、渗透率、周期、监管。
4. 投研工作流：资料源、假设生成、验证清单、跟踪指标。
5. 风险与合规：不把学习笔记写成买卖建议，保留来源日期和不确定性。

## 资料源优先级

1. 公司 IR、公告、财报、电话会、SEC / 监管披露。
2. 官方统计、行业协会、交易所和监管机构数据。
3. TAM 报告、一致预期、券商或研究机构资料，用于交叉核验。
4. 可靠财经媒体只作为线索入口，不作为最终事实来源。
