## 四、URL参数化查询接口

> [!tip] 重要发现
> 以下页面支持URL参数化查询，可直接构造URL获取特定数据。

### 4.1 POP点详情查询

```
#/popOverviewDetail?siteCode={POP编码}
```

**参数说明**：
- `siteCode`：POP点编码，如 `HK01`

**返回数据**：
- POP点基本信息（中英文名称、编码、地址）
- 各网络类型的设备数量、端口使用情况

### 4.2 海缆类型列表查询

```
#/participateSubmarine?name={海缆类型}
```

**参数说明**：
- `name`：海缆类型，如 `参建海缆`、`在建海缆`、`外租海缆`

**返回数据**：
- 该类型海缆的总容量统计
- 海缆列表（名称、里程、配置率、使用率等）

### 4.3 海缆容量详情查询

```
#/participateSubmarineCapacity?name={海缆名称}&type={海缆类型}
```

**参数说明**：
- `name`：海缆英文名称，如 `APCN2`
- `type`：海缆类型，如 `参建海缆`

**返回数据**：
- 海缆总容量、已用容量、剩余容量
- 缆段详情（登陆站、时延、容量分配等）

## 五、数据字段说明

### 5.1 POP点详情字段

| 字段名 | 说明 |
|-------|------|
| POP名称中文名 | POP点的中文名称 |
| POP名称英文 | POP点的英文名称 |
| POP CODE | POP点编码 |
| 地址 | POP点物理地址 |
| 设备数量 | 各网络类型的设备台数 |
| 已使用端口数量 | 已占用的端口数 |
| 空闲端口数量 | 可用的端口数 |
| 端口使用率 | 端口占用百分比 |

### 5.2 海缆容量详情字段

| 字段名 | 说明 |
|-------|------|
| 海/陆缆名称 | 缆段名称 |
| A端登陆站 | 缆段起点 |
| Z端登陆站 | 缆段终点 |
| 里程长度 | 缆段物理长度 |
| 时延(ms) | 信号传输延迟 |
| 权益容量(G) | 拥有的容量权益 |
| 配置容量(G) | 已配置的容量 |
| 使用容量(G) | 实际使用的容量 |
| 剩余容量(G) | 可用的剩余容量 |
| 配置率 | 配置容量/权益容量 |
| 使用率 | 使用容量/配置容量 |
