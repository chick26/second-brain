最近看了 Pi 这个开源 Agent 项目，感觉它对个人开发者挺友好。  
它不是那种一上来就很重的 Agent 框架，也不是把所有东西都封装好的黑盒产品。Pi 更像一个比较轻的 Agent 底座：模型适配、工具调用、上下文处理、事件循环、终端交互、安全执行，都拆得比较清楚。  

如果你想自己做一个 Coding Agent，或者想研究 Agent 到底怎么跑，我觉得 Pi 比很多大框架更适合作为起点。  

Pi 的核心其实就是 LLM + 工具 + 循环，再加上一套比较清晰的上下文管理和工具执行机制。  

默认工具也很克制，主要就是 Read / Write / Edit / Bash。工具少不代表弱，反而更方便做权限控制和沙箱隔离。  

尤其是如果你想让 Agent 真正去改代码、跑命令，就一定要考虑安全问题。Pi 生态里的 Gondolin 就是一个比较有意思的方向，用微虚拟机把执行环境隔离起来，避免 Agent 直接污染宿主机。  

所以如果你现在也想自己开发 Agent，我会建议不要一上来就追复杂框架。可以先从 Pi 这种简单、可控、方便二次开发的项目开始看。
