# LLMRouter: 一个统一的LLM Router框架

再发个图文版本，宣传一下我们最近开发的一个Open-source Proiect LLMRouter。欢迎大家多多关注点Star，感谢\[皱眉R\]。以下是原文：  

"在过去一段时间里，我们先后完成了 GraphRouter（ICLR'25）、Router-R1（NeurIPS'25） 和 PersonalizedRouter（TMLR'25）。  
在反复设计和复现不同 LLM Router 方法的过程中，我们逐渐意识到一个比较普遍但被忽视的问题：  
👉 现有 LLM Router 往往需要为每个方法单独定制输入输出形式、训练流程和评测环境  
这不仅增加了使用和复现成本，也让不同 router 之间的公平比较变得很困难。  
基于这些真实的工程和实验经验，我们最近开源了一个统一框架：🚀LLMRouter。  
该框架：  
统一支持 single-round / multi-round / agentic / personalized routers  
提供统一的训练与评测接口，可一行命令运行不同 router  
避免为每个方法重复搭建环境  
同时支持用户扩展 自定义 router / task / metric  
也非常欢迎大家将自己的 router 集成进来，共同减少重复工程成本，并提升方法的可比较性和可见度。  
希望能和社区一起，把它逐步打造成一个全面、好用、标准化的 LLM routing 工具库，欢迎交流与讨论 🤝"
